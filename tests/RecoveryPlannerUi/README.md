# RecoveryPlannerUi

廃品回収の18画面を1920×1080のRenderTargetへ描画する隔離UI回帰。実行中のゲームやセーブは操作せず、テスト世界と画面外の専用ウィンドウを使う。

状況一覧→受け取り地点の地図→確認専用格納庫→欲しい品の形・素材・汚損条件→出発地点→回収員→回収と搬入の到達可否→回収対象→最終確認→予約→状況詳細を検証する。受け取り・出発・対象の地図は地星儀／展開図を切り替え、実クリックで選択する。全質問の中止とEscが未確定入力だけを破棄すること、予約済み回収班を保持すること、最大６班と品物の重複防止、選択候補の３配色と、地図の当たり判定が拡大率に追従することも確認する。

GameDllとRuntimeDirを指定してNASへビルドする。SDL2.dllをテスト実行フォルダーへ配置。環境変数GAME_RUNTIMEは今回の画像素材を含むゲーム出力、OLD_RUNTIMEはコンパイル済みContentを含む実行環境、PROBE_FONTは今回生成したContent/UiFont.xnbの親。画像出力フォルダーを引数に渡す。新しい質問に必要な字形を追加しているため、PROBE_FONTには更新したフォントを指定する。

2026-11-22の検証出力：NASの`tmp/delete-after-2026-11-23/recovery-destination{,-tests}/`と`recovery-font/`。日本時間2026-11-23まで保持し、翌日から削除候補。原資料とセーブは変更しない。
