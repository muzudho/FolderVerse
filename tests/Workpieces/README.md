# Workpieces

９素材×結合２種の仕掛品を制御fixtureで検証する。８製造素材の16件は中断→実回収依頼→搬入→再開予約/取消→保存→確定→完成と原料保存を確認する。ブリキ２件は分解/回収/保存を確認し、既存カタログで再開不可を期待する。段ボールを頭・胴・脚に含む２件は混成素材。

物理的な分解/再結合、加工合成予約の取消と保存後実行、完成品＋余り仕掛品、作業員解除時の一度だけの廃品化も確認する。診断fixtureは在庫・容量・レーンを調整するため自然なCPUプレイの収束調査ではない。

AGENTS.mdに従い、dotnet build/runの出力はNASの作業別artifacts-pathへ。PublishedGameで固定DLLの指定が可能。実セーブを読み書きしない。
