# NoEmptyBuffer

意図的な空き枠の撤去、セーブ形式、地図の３配色の隔離回帰検証。

- 9枠中8枠使用時に最後の1枠へ採取できる。実際の満杯、帰還予約、製造品入荷予約は引き続き保護する。
- 新規セーブは Version=3。互換範囲は MinimumSupportedVersion〜CurrentVersion。互換を維持できない変更では最低対応番号を上げる。Versionがないものも非対応とする。
- 旧版の空き枠指定は読み捨てる。非対応のセーブは「このセーブファイルは読め込めなくなりました」を表示し、元ファイルを保持する。
- 廃止したドロップダウンが反応しないこと、３配色とホバーのHUD輪が選択可否と整合することを検証する。地形・夜間・HUD描画の検証は ../MapUiRules/ を参照。

GameDllとRuntimeDirを指定してNASへビルドし、実行フォルダーへSDL2.dllを配置。GAME_RUNTIMEはゲーム出力、OLD_RUNTIMEはContentのある実行環境。第1引数は検証出力フォルダー。

出力先：NASの tmp/delete-after-2026-11-23/remove-empty-buffer/。日本時間2026-11-23まで保持し翌日から削除候補。実行中ゲームと利用者のセーブは変更しない。
