# CPU製造管理と再任命の回帰

製造員・製造重点型の材料待ち解除確率、製造員不在時の用途解除を独立して確認する。取引・原料出荷予定を待つこと、採取員／製造員の通常予約による再任命、予約保存復元後の採取と実製造、採取場との配送経路に基づく２つの立地重みと新設定の保存／欠落互換も検証する。

AGENTS.mdに従い出力はNASへ向け、`dotnet run --project tests/ComputerFactoryManagement --artifacts-path <NAS出力> -p:PublishedGame=<隔離ゲームDLLディレクトリー>` で実行する。`FOLDERVERSE_PROBE_CONTENT_BASE` に隔離用Contentのあるディレクトリーを指定する。試験で保存復元後の用途コールバックを接続し、実際の優遇工期で生産する。

再任命は未予約で調練条件を満たす自国の完全体、レーン上限、採取／製造の需要や材料、出荷先の空きに従う。前線の最後の出撃可能機と倉庫管理人は候補にしない。材料待ちの解除と同じターンの再任命は既存の予約ロックで防ぐ。製造立地の数値は確率でなく0〜100の重み。

通し運転での征服ターン改善は別途比較する。行動試験の成功だけでは収束改善と断定しない。
