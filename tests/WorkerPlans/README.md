# 工場作業員と製造候補

- モデル検証：`dotnet run --project tests/WorkerPlans`
- 実描画・入力検証：`dotnet run --project tests/WorkerPlans -- --ui`

部位別の他国色50％、安物作業員による正規候補数の半減と切り上げ、通常レーンの維持、別Idや履歴を使った再任命の引き直し防止、地点・所属国・等価状態による再現、任命時スナップショット、組み換えと製造進捗、実際の完成品、一体型、損傷を製品へ渡さないこと、監督の計画選択、現行／旧セーブを確認する。

UI検証では実際のGame1に1080p／540pのクリックを送り、追加レーンの候補表示・選択・製造後の格納庫を描画する。検証画像は既存出力先のworker-plans-0.png～4.png。利用者のセーブデータは使用しない。
