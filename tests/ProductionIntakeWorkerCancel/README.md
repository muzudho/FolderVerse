# 製造員解除後の完成品入荷

９素材でPPを使った製造を完了させ、満杯で入荷待ちの間に最後の製造員を解除する。入荷先変更の前後２順序、予約保存復元、完成品と消費済み原料の保全、追加製造なし、一度だけの実入荷を確認する。

工場タブ判定から、工場下部の「完成品の入荷待ち」ボタン、待機品一覧、既存の入荷先ピッカーの実入力まで回帰する。Game1の入力メソッドを隔離オブジェクトで呼び、実ゲームや元セーブには触れない。

AGENTS.mdに従いNASへ出力する。`dotnet run --project tests/ProductionIntakeWorkerCancel --artifacts-path <NAS出力> -p:PublishedGame=<隔離DLLディレクトリー>`。`FOLDERVERSE_PROBE_CONTENT_BASE` は隔離用Contentのあるディレクトリー。任意の第１引数にNAS上のファイル名を渡すと、レーンがなく完成品だけが残る途中状態を保存できる。

待機品10件の診断配置で、２ページ目の対象一致、ページ境界、Esc・閉じる、背景クリックの入力遮断も確認する。追加の待機品はUI試験後に除き、元の消費・配送モデル回帰と分ける。
