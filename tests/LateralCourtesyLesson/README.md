# 戦訓#19：斜め前の味方との交差

敵が近くにいない場所で、縦移動と横（X軸）移動の味方２体が同じ空きマスへ進み、両方が衝突して戻された経験を戦訓にする。生存した目撃者が帰還し、研究した国にだけ効果が付く。

研究後は縦（Y軸）移動側が１手待ち、横移動側を先に通す。同時移動の解決順序そのものは変更しない。左右・上下の４方向の組合せに対応。相手側の国が未研究でも、研究済みの縦移動側は譲れる。

適用条件：敵とのマンハッタン距離が、両者の出発地点と交差先からすべて５以上。同じ移動先への進入がちょうど２体で、移動先は最初に空いていて両者が通行可能。国旗への進入、退却中、撤退中の軍、クイーン、３体以上の競合は対象外。縦移動側が未研究なら横移動側の研究だけでは譲歩しない。

取得・研究・保存復元、未取得時の衝突、４方向、次手の前進、同盟国、敵近接・旗・壁・退却の除外を `tests/LateralCourtesyLesson` で確認。既存 `tests/BattleLessons` も通過。NAS検証出力：`tmp/delete-after-2026-11-24/lateral-courtesy-lesson/`。
