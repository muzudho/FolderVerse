# 一体型隊長の９素材・４方向描画回帰

遠隔製造品の保存/到着Visual一致を前提に、頭胴一体型隊長を９素材×４方向、48×72で描画する。各方向でPP基準と残る８素材に画素差があり、機体の外側が変わらないことを確認。36画像は引数の出力フォルダーへ保存する。配送モデルの９素材個別試験ではない。

NASへ --artifacts-path で隔離ビルドし、GameDll/RuntimeDirを指定する。実行先のゲームDLLを明示コピーしてSHA-256を確認する。FOLDERVERSE_PROBE_CONTENT_BASEはフォント/カタログを含む実行素材のルート（末尾区切り付き）、FOLDERVERSE_ART_CONTENT_BASEは検証するContent/Images/Robotsを持つルート。後者は現行FolderVerseディレクトリーの読取参照でもよい。引数１つはNAS画像出力先。元ゲームは起動しない。

全役職・全混成・実戦UI全体の回帰は別。
