# MapUiRules

地星儀と展開図の共通ルールを実際の描画環境で検証する隔離テスト。実行中のゲームは操作しない。

操作不能の配色と輪抑止、ホバー時の通常色とHUD、チュートリアル明滅、選択の優先順位と無効化を確認。地形の任意減光・夜間打消しがないこと、選択した足元の１タイルだけが変わること、昼夜適用後の色、解除時の復元、雪の明度余裕を検証する。

HUD輪の内部・外側が透過であることと濃淡アニメーションを画素で検証。地星儀・展開図の建物の投影範囲への追従、ズーム、最低面積、海路の水色に対する暖色と縁取りの視認性を確認する。地形と大気を同じクリップで描画し、外側の画素が変わらないことを確認する。内政画面とインスペクター表示時の宇宙の左右端、採用したガイドアイコンの透明度と無彩色化も検証する。

GameDllとRuntimeDirにゲーム出力を指定してビルドする。SDL2.dllを実行フォルダーへ配置。GAME_RUNTIMEは実行素材のあるゲーム出力、OLD_RUNTIMEはContentのある既存実行環境。出力フォルダーを第1引数に指定する。

NAS出力：tmp/delete-after-2026-11-23/map-ui-rules/。日本時間2026-11-23まで保持し、翌日から削除候補。

リング修正の出力：tmp/delete-after-2026-11-24/hud-ring-zoom/。日本時間2026-11-24まで保持。
