# エキシビジョンのフォーカス切替

HandleInputに実ログの画面外座標（3471,-451 / 2497,707）をactive=trueで渡す。新聞・内政・産業・伝播・戦闘の各画面で、画面外と非アクティブなクリックはメニューを開かず、フォーカス復帰時に押したままのボタンも新規クリックにしない。ゲーム内のクリックとEscは従来どおり一時停止する。

GameDllとRuntimeDirを指定してビルドし、CONTENT_RUNTIMEを素材を持つゲーム出力へ設定して実行する。SDL2.dllとopenal.dllを検証ホストへコピーする。出力はAGENTS.mdに従いNASの期限付き作業フォルダーを使用する。利用者の保存は無効化する。

実Update側は、MonoGameのIsActiveに加えてWindowsの前面ウィンドウの所有プロセスを確認する。テストは入力処理へ状態を注入する回帰検証であり、Visual Studioを実マウスで操作するテストではない。
