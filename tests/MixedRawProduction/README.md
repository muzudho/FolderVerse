# 混合原材料の製造消費

９素材の実製造作業員予約で作られたレーンを使い、５原料を跨ぐ２種類の混成製品を検証する。１原料だけ足りない間は全原料未消費、格納庫満杯で完成できない間は全消費を巻き戻し、保存復元後に１枠空くと各必要量を一度だけ消費する。

Materials104729・配役1・領地2・運否3、2CPU・25／25から局所診断配置を作る。倉庫管理人２体、作業員１体を置き、常設レーン０・WorkerAt一致を検査する。混成レシピ・工期３・容量と外国製ブロッカーは境界を作るための診断設定で、ゲームの費用や初期配置仕様を変更しない。

`dotnet run --project tests/MixedRawProduction --artifacts-path <NAS出力> -p:PublishedGame=<隔離DLLフォルダー>`

`FOLDERVERSE_PROBE_CONTENT_BASE` に隔離Contentのあるディレクトリーを指定する。実ゲームや元セーブを読まず、必要な途中状態はメモリー上で保存復元する。
