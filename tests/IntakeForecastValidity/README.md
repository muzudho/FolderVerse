# 完成品入荷予測の戦闘解除回帰

製造作業員の解除・保存復元・入荷先変更後、受取地点の戦闘と順逆両方向の経路戦闘が予測を止め、戦闘終了だけで予測が再計算されることを確認する。明示Invalidateや実配送によるStatus変更を挟まない。解除後の実配送は１個だけとなる。

`GameDll` に検証するゲームDLL、`RuntimeDir` と環境変数 `FOLDERVERSE_PROBE_CONTENT_BASE` にその実行素材を指定する。出力はAGENTS.mdに従いNASの `--artifacts-path` へ置く。実行先へ対象DLLを明示コピーし、ハッシュを照合してから実行する。

部品や原料の無償追加を製品へ実装する試験ではない。表示・クリック・実ゲームの通し操作は対象外。

所有国変更と上下関係による同盟化/解除だけでも、入荷予測が再計算されることを追加確認する。予測操作だけでは完成品を消費/配送しない。戦闘18＋所有/同盟７の計25項目。
