# tmp から移した検証ソース

2026-10-28整理。再利用する検証コードは tests/ で管理し、tmp/ は破棄・再生成できるローカル作業物だけに使う。

- DestinationChecks: 移動先表示・新聞の駒の描画確認。
- LandSetupChecks: 領土選択・内政画面の確認。Model.cs.txt と Ui.cs.txt は以前の検証ソースを記録した補助資料。
- MobUi: モブの読み込みと描画確認。
- NewspaperChecks: 戦況新聞の見出し・描画確認。
- PropagationChecks: 伝播経路の確認。
- RatePieChecks: 輸送比率円グラフの確認。
- ReservationLogChecks: fixtures/clicks.json に保存した操作を再現する診断。引数で別の入力JSONも指定できる。
- LocationResume: 指定したセーブの再開画面を確認する診断。セーブの絶対パスを引数に渡す。個人の既定セーブをハードコードしない。

これらは過去の調査用ソースで、現在のUIや非公開APIに対する全件の実行成功を保証する回帰テスト群ではない。画面位置や内部名が変わった場合は、その目的に応じて更新して使う。

.exe・.dll・Contentコピー・実行ログは再生成物。tmp/ に残っている過去の画面キャプチャはローカルの参考であり、永続的な制作資料に採用する場合は用途の決まったフォルダーへ移す。tmp/ 全体はGitの対象外とする。

移動後の８プロジェクトは参照先と入力JSONを確認し、コンパイル成功（警告・エラー０）を確認した。UIの全件実行や実セーブを使う診断の実行は、この配置整理では行っていない。
