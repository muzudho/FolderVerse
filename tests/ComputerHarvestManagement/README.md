# CPU採取管理の回帰試験

４確率の独立性（枯渇／予定なし × 採取員／採取重点型）、0%／100%、実際の解除予約と保存復元後のレーン削除、同ターン再抽選の安定性、旧設定セーブの欠落フィールドを確認する。
選択済みの製造レシピと配送可能性、交換相手の需要と役立つ返礼品から採取予定を判断する。採取予約の残骸だけでは予定にしない。手動地点の保護も確認する。

実行時は AGENTS.md に従い `--artifacts-path` をNASの作業別ディレクトリーへ向ける。`-p:PublishedGame=<隔離ビルドのFolderVerse.dllとMonoGame.Framework.dllのあるディレクトリー>` で実ゲームや通常ビルドを変更せず実行できる。`FOLDERVERSE_PROBE_CONTENT_BASE` は隔離用Contentのあるディレクトリー。

これは管理動作の回帰試験であり、征服ターンの改善やキャラクター配分の最適性は保証しない。
