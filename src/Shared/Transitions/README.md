# 共通の画面トランジション

FallingTilePattern は1920×1080を30×30の64列×36行、計2304枚に分ける映像用モデル。ゲーム世界の地形・重力・保存・乱数とは独立。表示専用seedに対して剥離遅延・水平速度・３軸角速度・裏面５色を固定する。

- 左から右へ1.65秒＋各行0〜0.18秒のばらつきで剥離。未剥離の板は元位置を維持。
- 剥離後は y = y0 - 65t + 1000t²、水平は x = x0 + drift×t。板は厚み4pxの立体で３軸回転する。
- FallingTileRenderer は旧画面Texture2Dを表面へUV貼付し、裏面を玩具色、側面を濃色で描く。裏返った板は表の映像を描かない。
- 影は次画面に重ねる４層の半透明クアッドによる演出的な投影。光源・接触・屈折・板同士の衝突をシミュレーションするものではない。
- 3.1秒で全板が画面外へ落ちる。描画用バッファを再利用。静止した次画面を先に描き、旧画面の板をその前に描く。

新聞への接続、２枚のRenderTargetのキャプチャと破棄、演出のタイミング・クリック・効果音はビュー側Game1.NewspaperTiles.cs。再利用先は独自の旧/新Texture2Dと時間を与える。画面のHUDは別に描いて操作可能に保つ。

赤カーテンは既存の番組入退場用として維持。今回の板落下は新聞内の場面転換に適用し、他フェーズへ一律適用しない。新聞では走るロボットを追加済み。

TransitionRunner は完全体・非仕掛品の所持機を表示専用seedで選ぶ。country=-1なら無所属機のみ。新聞は読者本人のOwnerを対象に全地点とポケットから選び、不在なら自国クイーン。所属・配置・保存は変更しない。素材、部位旗、汚損、帽子、一体型は既存格納庫描画で画像化する。脚が独立する機体は脚の左右を交互に振り、胴脚一体型とクイーンは一体で跳ねる。
剥離開始0.45秒前から1.65秒で画面を横断し、常に崩壊波より先を進む。登場時だけ脚素材別の0.28秒PCM音（9種、クイーンはブリキ系）。足音の反復なし、パネル音開始まで0.17秒空ける。クリック等で登場を飛ばした場合は遅延再生しない。SE音量を尊重。画像は背景より先に準備してRenderTargetのDiscardによる画面消失を避け、開始/アンロード時に破棄する。
