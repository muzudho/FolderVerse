# 共通の画像処理

`GaussianBlur.Apply(pixels, width, height, sigmaPixels)` は乗算済みRGBA画像にガウスぼかしを適用する。入力配列は変更せず、結果を新しい配列として返す。

- `sigmaPixels`：入力画像のピクセル単位の標準偏差 σ。0 はぼかしなし、大きいほど強い。負数・非有限値は受け付けない。
- 重みは exp(-x² / (2σ²)) を正規化。半径 ceil(3σ) のカーネルを横・縦に分けて適用し、画像端は最端画素を延長する。
- CPU並列度は最大2。描画処理やテクスチャのキャッシュは各ビューが担当する。

世界征服状況フェーズでは、承認された「ボカシ５０」の見本に近い設定をフルHD論理座標で σ=7px とした。生成画像の「５０」と数学的に同じ量という意味ではない。右ペーンを半解像度640×540で描き、σ=3.5px、処理半径11pxでぼかして1280×1080へ表示する。解像度変更時はσも同じ倍率で換算する。
