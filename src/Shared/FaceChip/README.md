# FaceChip

顔、本人のエントリー番号、円形の縁、縦軸回転風の共通描画。
地図と平和移動バスは回転あり、戦場のクイーンは判別用の静止表示。
配置・紐・盤面からの座標変換・表示条件は各ビューに残す。
原画の生成や加工は行わず、既存のPortraitRendererを使用する。

## 戦闘研究の取得者表示（2026-11-22）

所属関係図と戦闘研究の角丸の顔＋エントリーナンバーカードを Game1.RulerFaceCard.cs に共通化。所属関係図では従来の順位も表示する。戦闘研究では同じ戦訓を取得した全員を１ページに並べ、名前はホバー時に表示。１～20人は100px、21～60人は70pxで最大10列６行。取得処理は全員に適用し、表示だけ戦訓単位に集約する。新規戦訓７秒、既知戦訓３秒、1.8秒経過後は次へ操作可能。tests/LessonRecipientsUi で61件→２カード、60人への取得、１／20／60人の描画とページ進行を検証。
