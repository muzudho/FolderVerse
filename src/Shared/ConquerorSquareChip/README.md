# ConquerorSquareChip

征服者の女の子の角丸正方形アイコン。顔・国色の枠・本人のエントリー番号を共通描画し、必要なら順位を左上に表示する。所属関係図と戦闘研究で利用する。

配置・取得者の集約・ツリーの線・ホバーヒント・進行時間は各ビューに残す。丸い回転チップは FaceChip に置く。

## 戦闘研究の取得者表示（2026-11-22）

所属関係図と戦闘研究の角丸の顔＋エントリーナンバーカードを Game1.ConquerorSquareChip.cs に共通化。所属関係図では従来の順位も表示する。戦闘研究では同じ戦訓を取得した全員を１ページに並べ、名前はホバー時に表示。１～20人は100px、21～60人は70pxで最大10列６行。取得処理は全員に適用し、表示だけ戦訓単位に集約する。新規戦訓７秒、既知戦訓３秒、1.8秒経過後は次へ操作可能。tests/LessonRecipientsUi で61件→２カード、60人への取得、１／20／60人の描画とページ進行を検証。
