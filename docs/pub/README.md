# Folder Verseについて

[トップページ](../../README.md) / [ドキュメント案内](../README.md)

生配信で遊びやすく、視聴者も展開を追いやすい、20分ほどのストラテジーゲームを目指して制作しています。女の子の征服者と玩具の兵隊ロボットが、立体の世界で領地を広げます。

世界・人物・初期配置はSEEDで抽選します。同じ条件を再現して遊ぶこともできます。ロボットの製造や輸送を計画し、自動戦闘を観戦するゲームです。

## 現在の状況

[v0.4.0 Pre-release（無料試遊版）](https://github.com/muzudho/FolderVerse/releases/tag/v0.4.0)をGitHub Releasesで公開しています。Windows x64向けで、Windows 11を想定しています。ZIPを展開して実行でき、Visual Studioの準備は不要です。

MonoGame製の開発中のゲームです。20分での完走は制作の目標です。既知の問題や検証範囲はリリースページを参照してください。このリポジトリーの資料には、配布版にまだ含まれない開発中の機能も記載しています。

制作の経過は[開発日誌](../dev/log/2026/11.md)、遊ぶ方法は[ユーザー向け案内](../user/README.md)を参照してください。
