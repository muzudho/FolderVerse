# Folder Verseについて

[トップページ](../../README.md) / [ドキュメント案内](../README.md)

生配信で遊びやすく、視聴者も展開を追いやすい、20分ほどのストラテジーゲームを目指して制作しています。女の子の征服者と玩具の兵隊ロボットが、立体の世界で領地を広げます。

世界・人物・初期配置はSEEDで抽選します。同じ条件を再現して遊ぶこともできます。ロボットの製造や輸送を計画し、自動戦闘を観戦するゲームです。

## 現在の状況

2026年10月10日時点では、Windows 11を想定したMonoGame製の開発版です。20分での完走は制作の目標で、完成した製品としての案内ではありません。GitHub Releasesの配布版はまだありません。

制作の経過は[開発日誌](../dev/log/2026/10.md)、遊ぶ方法は[ユーザー向け案内](../user/README.md)を参照してください。
