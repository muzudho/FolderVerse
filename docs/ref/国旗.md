# 国旗

[ドキュメント案内](../README.md)

2026年11月8日実装。国旗は「形・リピートパターン・基本色・２色目・ワンポイント」の５要素から作る。ロボットや既存の国の識別模様にも同じ色・模様を使い、旗の形だけを追加情報として持つ。

形は横３：縦２、横２：縦１、正方形、右向き三角形。三角形を除く抽選の目安は50/40/10％。８国以上では75％の抽選で１国だけ三角形にし、毎回必ず１国とはしない。人物SEEDから決まり、人物を再抽選すれば旗も再抽選する。

７国以下は単色中心。８国以上では単色を７国に抑え、残りは２色の網掛け40％、単色＋ワンポイント30％、２色＋ワンポイント30％を目安に抽選する。人数を厳密な割合へ丸めず、個々に抽選する。２色目は基本色と異なる色を使い、色順を逆にした同じペアを自動抽選で再使用しない。形の違いだけで似た旗を使い回さない。手動設定は利用者の選択を尊重する。

システムメニューの「人間とコンピューター / 国旗の設定」で５要素を変更できる。網掛けとワンポイントは２色目を共有。紋章は輪郭を付け、旗が横長や正方形でも縦横比を保つ。国旗の描画パッチは最大256デザインをキャッシュする。

土地征服では取得済みの地域の中央に国旗を立て、未取得には立てない。地形の色は取得前後で変えない。通常の地星儀と展開図では地点に国旗を表示し、同一地域内の国の混在を表せる。無機能地点の家・船にも小さな国旗を添える。国旗は描画専用で新しいクリック遮蔽領域を作らない。台座は自国・操作できる手下を明色、敵を暗色、未所属を中立色にする。既存の任意選択の国区画色分けレイヤーは残す。

戦場の目標物も同じ５要素で描く。画面文言と新しい戦闘イベントは「国旗」に統一する。既存の「旗を倒した」という保存済みイベントも、留守中に国旗を倒された戦訓の判定対象に残す。勝敗条件や国旗の防衛・奪取に必要なターン数は変更しない。

国旗の形も保存する。旧セーブは形を横３：縦２に補い、既存の国の色・模様・人物を抽選し直さない。

検証は tests/CountryFlags と tests/CountrySettings。60国×100SEEDの構成・形・重複回避、保存と旧形式、形のクリック入力、地形色維持、戦訓の新イベント互換、設定・地星儀・土地征服・戦場の描画を確認する。一時画像・ビルドは artifacts/tmp/delete-after-2026-11-11/cpu-convergence/ に置く。

## ワンポイントの更新

実在国旗との連想を減らす利用者の指示で、太陽・月・星を外し、猫・イルカ・四分音符をそれぞれ同じID 1・2・3へ置き換えた。旧セーブのこれら３図案も決まった新図案へ変わる。他の既存IDは移動しない。宝石のダイヤモンドをID14へ追加し、トランプのダイヤ（ID6）と区別する。なし以外のワンポイントは合計14種類。設定画面は８列２段で全15項目を表示する。

ハートは96点の曲線輪郭を使い、丸い２つの山と中央のくぼみを保つ。宝石は平らな上端・左右の肩・下の頂点を持つ逆五角形の外形にカット線を入れ、トランプの菱形から区別する。国旗・ロボット・設定プレビューで共通の描画を使う。

実在国旗の２色リピート模様の連想候補も資料へ追加した。赤白の横縞はオーストリア、青白の横縞はギリシャと比較できるが、本数・十字部分などが異なる。赤白チェッカーはクロアチアの国章部分、白青の格子はフィンランドの十字との連想候補。旗全体の一致と部分模様の連想を混同しない。リピート模様の禁止・削除は利用者の検討待ちで、今回変更していない。これらを変えただけで全ての実在旗に似なくなるとは保証しない。

新図案の検証は tests/CountryEmblems：抽選・旧ID解釈・保存、６図案のマスクの違い、ハートの丸みとくぼみ、ダイヤモンドの最終ボタンまで選択可能なことを確認。CountryFlags・CountrySettingsの回帰も成功。画像は artifacts/flag-audit/2026-11-08/new-emblems.png と new-emblems-settings.png。２色比較は flag-pattern-review.png（左が実際のゲーム出力、右が模式図）。旧星・月・太陽の比較画像２枚は旧仕様の記録として残す。tools/FlagAudit は現在 --patterns 指定でリピート模様だけを再生成する。

## 虹と斜め縞

利用者の追加指示で虹をID15へ追加。２色目の単色インクで３本の離れたアーチを描く。なし＋15図案が８列２段に収まり、設定・抽選・保存に対応する。虹のIDを追加したので既存の図案IDは変更しない。

横縞（パターンID1）はネクタイ風の斜めリピートへ変更し、名前も斜め縞とする。国旗とロボットを含む共通の国模様へ適用する。旧保存の横縞も同じIDで斜め縞になる。国旗では36×24の各画素で連続位相を評価し、10×10の模様を単純拡大した大きな階段状の線を避ける。市松は維持する。

実在国旗との類似調査は、利用者の「具体的に問題が出たらその時に変える」という方針でいったん終了。斜めなら絶対に似ないという保証はせず、今回これ以上の禁止配色や模様の削除は設けない。

CountryEmblemsで虹の保存・自動抽選、３本のアーチが離れて描かれること、縞が行方向・列方向の両方で変化すること、最後の虹ボタンを選べることを確認する。見本は artifacts/flag-audit/2026-11-08/rainbow-stripes.png。以前の flag-pattern-review.png は横縞だった時点の比較資料として残す。
