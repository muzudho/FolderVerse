# 人数確認フェーズ

タイトルのSTARTから世界構築へ入る前に、＜大きなお子様＞の人数、続いて＜コンピュータープレイヤー＞の人数を選ぶ。両画面とも既存の司会と吹き出しを使い、数字ボタンまたは左右キーで選択し、確認ボタンまたはEnterで次へ進む。

＜大きなお子様＞は０～60人、初期値は１人。推定プレイ時間は人数×20分の概算で、時間制限ではない。

＜コンピュータープレイヤー＞は０～（60 − ＜大きなお子様＞の人数）人。初期値は19人で、残りの枠数まで切り詰める。戻るボタンで人間の人数を選び直せる。合計０人の場合は開始せず、合計１～60人で世界構築へ進む。

指定した合計人数だけ征服者を抽選・表示し、全員に土地を割り当てる。初期状態では参加者１人が征服者１人を担当する。例えば人間１人＋コンピューター２人なら征服者は３人で、未参加の征服者は表示しない。世界の区画が人数より少ない場合は全員を収容できる大きさにする。＜大きなお子様＞は重複しない征服者を順に選択し、残りをコンピューターが担当する。全担当の入力後にターンを確定する既存の仕組みを使う。人間０人の場合は征服者選択を省略し、土地選択と内政以降を自動進行する。

60人に対応するため、人数ボタンは10列の配置とし、21人以上の人物抽選では地星儀の上下に肖像を並べる。征服者選択と征服状況のレイアウト、ロボットと戦闘の所有者番号も60人に対応する。

人数設定はオートセーブに保存し、コンピューターのみのゲームを再開すると自動進行に戻る。従来のセーブとチュートリアルは従来の参加設定を維持する。デモは従来どおり人間１人の設定で進行する。担当・ターン変更時の通知音も維持する。

検証：PlayerCountで０＋60、60＋０、１＋59、59＋１、30＋30、１人のみなどの人数、土地割当、レイアウト、手動担当、セーブ復元、ターン進行、不正値の拒否を確認する。PlayerCountUiで人数画面の操作・描画とデモを確認する。長時間プレイは未確認。

土地征服後の運否天賦で降ってくる演出用ロボットも、実際の参加人数の範囲内で所有者を選ぶ。PlayerCountUiでは１・３・19・20・21・60人について土地征服と運否天賦の地星儀を実描画し、少人数で色配列の範囲外アクセスが起きないことを確認する。
