# 人数確認フェーズ

タイトルのSTARTから世界構築へ入る前に、＜大きなお子様＞の人数を１～20人で選ぶ。初期値は１人。司会進行する女のモブが吹き出しで案内する。

「さあ、みなさん＜画面＞の前に集まってください。準備はよろしいですか？」から始め、人数を選ぶよう呼びかける。音声読み上げではなく画面の台詞。

推定プレイ時間は人数×20分。１人は＜２０分＞、10人は＜３時間２０分＞、20人は＜６時間４０分＞。時間制限ではなく概算。作品の外を指す言葉や所要時間は全角三角括弧＜ ＞で囲む。

人数確定後は従来の世界・人物・配置抽選へ進み、各担当が重複しない征服者を順に選択する。一人が複数の担当を受け持つ遊び方も可能。全担当の内政行動が揃ってから伝播・戦闘を一度進める。人数よりセルが少ない世界は人数を収容できる大きさにする。

現在の征服者枠は従来どおり最大20人。今回、征服者の総数を選ぶ新しい画面は追加していない。人数と征服者の上限をGameLimitsで独立させ、将来は両方60人まで拡張する方針を記録。60人モードは現在有効ではなく、上限の変更だけで完成するものでもない。

担当またはターンが変わって内政画面へ入ると３音の通知を鳴らす。同じ担当でメニューを開閉しても再通知しない。デモは１人を自動選択し、デモ・AUTOの通知は抑制する。

検証：PlayerCount、PlayerCountUi、RobotCampaign、MixedRobotsが成功。人数別の土地割当、担当順、全員入力後のターン確定、実フォントの表示、人数画面の描画、通知音の生成・再生、デモ１人固定を確認。最終ビルドは警告・エラー０。長時間の対面プレイは未実施。
