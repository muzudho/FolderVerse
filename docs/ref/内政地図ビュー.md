# 内政の地図・君臨・節点ビュー
内政は全幅の地図から始める。右上は方向ロボット、左下は大きな丸い征服者の顔。
顔をクリックすると君臨ビューを左に開き、地図を右側へ縮小・移動する。再度顔をクリック、または閉じるボタンで地図へ戻る。
節点は征服者の滞在有無によらず節点ビューを開く。管理者表示と節点内政を共通にする。別節点への切り替えも地図から行う。
ビューの開閉に合わせて地図領域が滑らかに変わる。地星儀では選択節点を中心の基準にする。
## 全体作戦ビュー（2026-10-14）
顔の下のチェック付き全体作戦トグルで開閉する。顔は表示専用、全体作戦の×は廃止。節点を選ぶとチェックが外れ節点ビューへ切り替わる。左下にトグルと大型ターン終了を配置。移動・開戦・ポケットは全体作戦を開いたときだけ表示・操作できる。
