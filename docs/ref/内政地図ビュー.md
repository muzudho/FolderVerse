# 内政の地図・君臨・節点ビュー
内政は全幅の地図から始める。右上は方向ロボット、左下は大きな丸い征服者の顔。
顔をクリックすると君臨ビューを左に開き、地図を右側へ縮小・移動する。再度顔をクリック、または閉じるボタンで地図へ戻る。
節点は征服者の滞在有無によらず節点ビューを開く。管理者表示と節点内政を共通にする。別節点への切り替えも地図から行う。
ビューの開閉に合わせて地図領域が滑らかに変わる。地星儀では選択節点を中心の基準にする。

## 方向操作と表示切替（2026-10-17）

地星儀は円外の赤X・緑Yの棒と、奥行きを表す青Zの点に＋／－を置く。静止中は30°回転、自動回転中は30°分の一時的な加減速。円下の「0, 0, 0」で頭を上・腹を手前へ戻す。ゼロは軸と同じ赤・緑・青。展開図は円外の矢印に沿って＋／－で30°回転し、12時方向の青い0で回転だけを戻す。

上部の「緯番・経番」と「赤道」は独立した表示設定。緑ランプの点灯／消灯がOn／Off、グレーアウトは使用不可。緯番・経番は地星儀用で、展開図では設定を保持したまま使用不可。赤道は両方で切替可能。

## ロボット・他国・インスペクター（2026-10-17追記）

「赤道」の隣の「ロボット」は格納庫ロボットの地図表示を切り替える。「電池」の隣の「他国」をOffにすると、自国・手下以外のロボット・電池・国セル色分けを隠す。節点と交通路は選択のため表示を続ける。地形メニューは「地形」「国セル色分け」の2種類とし、他国の色分け範囲は「他国」で選ぶ。

Xボタンは上が－、下が＋。回転方向自体は従来と同じ。世界構築などの自動回転中は3秒で30°分の進み／遅れを加え、進行角を表示。連続押下は順番に実行する。

全体作戦の操作は「ポケット」「移動予約」「調練」を横並びに配置。インスペクターは地図を縮小しない。地図左端と表示領域の間に15pxの余裕がなくなる位置から、地図を右へスライドさせる。開戦予約でも自動的な縮小・面切替をしない。

## 具体的なロボット輸送指示（2026-10-17）

輸送元の節点を選び、「指示を追加」から0〜16個の指示を作る。方式切替のボタンは置かない。既存の部位別配分に代わる手動設定で、指示０個はその場に留まる。番号は#1〜#16、削除しても他の指示を繰り上げず、空いた番号を再利用する。

`#1 [採用率%] [納品物／廃棄用]として [正規品頭／正規品胴／正規品脚／安物頭／安物胴／安物脚]のいずれか１つを [節点名]へ [個数]個送ったら終了。`

- 品質と部位を組み合わせた６候補から複数選択でき、１回の指示採用で送るのは選択候補のうち１パーツ。正規品頭と安物脚を同時に選べる。複数選択してもセットにはならず、品質もパーツ単位で照合する。終了数量と地図のパーツ量はどちらも１パーツを１個として数える。
- 在庫から送れる部分組み合わせも対象。ただし節点の自動組立・分解禁止は維持する。品質は送る各パーツの安物フラグで判定し、損傷は絞り込み条件にしない。既に廃棄用のものを納品物へ戻さない。
- 節点名を押すと地図で隣接節点を選ぶモーダル。右ドラッグ・ホイールは使え、Escで取消す。新規指示の送り先選択を取り消すと、その新規指示も取り消す。
- 個数は1〜9999をテンキーまたはキーボードで設定。実際に受け入れられた移送だけを達成数に加算し、満杯による差戻しは数えない。完了した指示は停止し、一覧から削除または再開できる。
- 採用率は1°刻み。固定の「#0 休憩」が＃1〜＃16の残りの割合を持ち、休憩込みで合計360°＝100%。指示０個なら休憩100%。休憩は表示専用で編集・削除できず、16個の指示枠に含めない。率の減少や指示削除は休憩へ戻り、率の増加は休憩を先に使い、不足分は他の指示の比率を保って再配分する。休憩が採用されたロボットはその場に留まる。
- 輸送候補ごとに、在庫・品質・残数・経路・受入可否などを満たす指示から重み付きで採用する。休憩も選択肢に含める。実行不能・完了・採用率０の指示は採用せず、実行可能な指示がなければ留まる。
- 円グラフは指示番号と色で表示。極細の扇でも対応が分かるよう全指示の番号・率を凡例にも表示する。

### 地図の輸送実績

地図の％表示は廃止。全体ターンごとに実際の移送パーツ数（頭・胴・脚を各１個）を送り元・送り先・用途別に記録し、直近５全体ターンの合計を５で割る。開始直後に不足する履歴は０。産業ターンだけ進んでも更新しない。品質・損傷は集計を分けない。

| 平均パーツ数／全体ターン | 印 |
| --- | --- |
| 0 | 灰色の四角 |
| 0超〜9以下 | 小矢印 |
| 9超〜18以下 | 中矢印 |
| 18超〜27以下 | 大矢印 |
| 27超 | 特大矢印 |

納品物は黒、廃棄用は赤で２本並べる。０個の四角は選択中の輸送元の周囲に表示し、実績のある経路は他の輸送元も表示する。印を押すと送り元の輸送計画へ移り、採用率の円グラフは開かない。ホバーで用途と平均値を確認できる。

「他国」Offでは他国の節点マーカー・港・選択強調・クリック判定も非表示。ただし開戦予約中は攻撃先候補の他国節点を表示・選択可能とし、閉じると非表示へ戻る。交通路は残し、自国・手下・無所属の節点は表示する。

## 輸送計画の編集終了とプレイヤー別表示設定

「ロボット輸送計画」で送り先を選択中は、地図上の隣接節点を押して確定する。「取消」またはEscで送り先選択を取り消せる。新規追加途中なら未確定の指示を削除し、既存指示の送り先変更なら元の送り先を保つ。インスペクター右端の×は、送り先選択・部位・数量・採用率の編集途中でも閉じられる。

表示設定は操作する征服者ごとに対局中記憶する。対象は緯番・経番、赤道、ロボット、電池、他国、地形/国セル色分け、セル/節点の選択表示、および地星儀/展開図の切替・向き・拡大率・移動・展開図の面配置。ターン交代や手下の操作切替で復元し、初めて操作する征服者は現在地を中心とする初期表示になる。輸送や移動予約中だけ必要な節点表示は元の表示設定と区別する。新規ゲームでは初期化する。全体ターンのオートセーブにも含め、再開時は保存された内政開始時点の表示設定を復元する。

送り先選択中も指示一覧の各ボタンを操作できる。新規指示で別の欄を編集し始める場合は、表示中の隣接節点を送り先として指示を保持する。送り先名を押せば改めて地図から変更できる。


## 予約の掲示板（2026-10-30）

上段の道案内板アイコンを「セカンダリー・アクション・ボタン」として配置。押すと地図を地形・交通路・予約の掲示板だけにする。使用中は約2.4秒周期でボタンをゆっくり明滅させ、隣の×またはEscで解除し、開始前の表示設定を復元する。別の表示設定・内政操作へ切り替えた場合も解除する。

地点の格納庫にいるロボットの台数を、道案内板の形で縦に積む。左に役割アイコン、右に数字を置き、0台の板は描かない。

| 役割 | 板・文字 | アイコン |
| --- | --- | --- |
| 出撃予約 | 赤・白 | 交差した剣 |
| 迎撃予約 | 黄緑・黒 | 盾と小さな短剣 |
| 守備専用予約 | 緑・白 | 盾 |
| 工場作業員予約 | 黄・白 | スパナ |
| 輸送予約 | 水色・黒 | 陸はトラック、海は高速フェリー |
| 廃棄予約 | 灰・赤 | カゴ |

予約の件数やパーツ数ではなく、対象ロボットを各役割で1台ずつ数える。出撃は戦闘への出撃とし、平和移動は含めない。輸送は送り元の確定済み直送便予約を対象に、頭・胴・脚を各1/3台として集計し、`2 + 1/3`のような帯分数で示す。一体型パーツも含有する部位数で数え、同じ個体の同じ部位を重複計上しない。長期計画の将来分は輸送対象が未確定のため含めない。ポケットへの出し入れは即時完了するため予約数はない。対象は自国・他国を含む地図上の全地域で、通常の「他国」表示OFFでも掲示板には他国の予約を示す。板をクリックすると地点の詳細を開く。地星儀は手前に見える地点だけに表示し、展開図・地星儀ともズームして確認できる。

掲示板の下端には備考として、小さな灰色の札で `WAIT`（手番待ち・行動未確定）、`TURN`（現在操作中の陣営）、`DONE`（行動入力済み）を表示する。地点の所有国を操作する担当者を基準にし、手下も同じ担当者の状態を示す。CPUは全員の入力後に出撃を決めるため入力中はWAIT。未所有・行動不能の国には札を付けない。予約台数の色や大きさは変えず、マウスを重ねると日本語の状態を表示する。


## 守備専用予約による戦場の設備（2026-10-30）

地点戦の開始時、守備側とその味方の守備専用ロボットを最大12体まで数え、1体につき設備を1個追加する。既存の砦と旗は残す。壁・堀は移動を妨げるが、地形全体の連結と通行口を検査して配置する。陸上には壁・堀・門、海上には甲板上の樽・門を置き、海上に堀は作らない。狭い甲板では味方が通れる門を守備側区画に置くことで、最大12個を収める。

- 壁：小銃を遮る。種類によっては隣接した特定方向からのみ射撃が通る。
- 堀：移動できないが、小銃は全方向から通る。
- 樽：移動と射撃を遮る海上の障害物。
- 門：所有軍とその味方は自由に通過。敵は破壊するまで通過不可。射撃は敵味方とも遮る。敵の短剣・小銃の有効な攻撃を1回受けるとゆがみ、2回で破壊される。味方の攻撃では壊れない。上下左右4方向と正常／ゆがみを描き分け、被弾時は見た目だけヒットバックする。

設備の個数は戦闘開始時に固定し、守備ロボットの転倒や増援では増減しない。門自身の破壊状態は継戦・戦場の統合・セーブ後も維持する。再生フレームは当時の門の状態を保持するため、破壊後に巻き戻しても正常に表示できる。

敵AIは移動の歩数と、門の残り耐久に必要な攻撃回数を比較する。同じ所要ターンなら武器を節約して迂回する。門への攻撃にも短剣・小銃を消費し、門を攻撃している間も戦意を維持する。同時攻撃中は門へのダメージをまとめて解決するため、そのフェーズに壊れた門の奥へ同じフェーズの弾が抜けることはない。

## 戦訓#7：衝突で守備に時間を稼がれた（2026-10-31）

取得後、地点の守備側は1マス空いていればその区画へ進入して時間を稼ぐ。攻撃側は1マス空いていればその場で相手を向いて短剣を振り、2マス空いていれば射線と仲間を確認して小銃を撃つ。武器の残量、通行・射撃を妨げる設備、撤退状態を尊重する。間合いの「1マス空き」は座標の距離2、「2マス空き」は距離3を指す。

## 戦訓#8：短剣も無いのに目の前で向かい合ったまま時間が過ぎた（2026-10-31）

短剣が尽きたロボットが敵ロボットと隣接して向かい合い、双方が動かず、そのターンにどちらの攻撃も個体へ命中しなかったときに目撃する。帰還・研究で取得する流れは他の戦訓と共通。

取得後、地点戦の攻撃側は短剣がなければ味方のすぐ後ろへ移り、小銃で支援する。隣接した同じ向きの味方だけは越して撃てるが、2マス目以降の味方や門を越えては撃たない。支援位置がなければ安全な後方・側方へ下がって間合いを空ける。短剣も小銃も尽きた個体は単独で撤退し、仲間や待機中の増援に前線を譲る。軍全体の撤退は指示しない。守備側の時間稼ぎにはこの行動変更を適用しない。


## 戦訓#9：逃げた敵を追う仲間を置き短剣で斬った（2026-10-31）

移動前は正面に敵がいたが、その敵が横へ移動し、元の敵のマスへ味方が進入した結果、その場で振った短剣が味方に命中したときに目撃する。以前から味方が正面にいた場合などは従来の戦訓#3の範囲であり、この戦訓の固有条件には含めない。

取得後は、行動開始時の配置から、味方がそのターンの移動で正面へ入れるかを判定する。正面にいる味方と、正面から1歩の位置にいる味方を対象にし、そこが壁・堀・敵の門などで進入不能なら除外する。他人の選択済み行動や移動結果は読まないため、実際には味方が移動しなかった場合でも置き短剣を控えることはある。銃撃や前進しながらの短剣攻撃はこの戦訓では抑制しない。味方には同盟関係の他国も含む。

戦訓一覧は3枚ずつのページ表示とし、前へ／次へで全カードを読む。9枚を1行へ縮めて文字が読めなくならないようにする。


## 説得の格納庫表示と戦訓#10（2026-10-31）

内政開始時の「寝返ってください」の演出は、前回開いた地点のページに関係なくロボット格納庫を開き、対象ロボットのスロットを表示する。通常の地点操作のために記憶したページは変更しない。

戦訓#10「角地で囲まれて横から斬られた」は、直角の2方向が地形・設備・盤外によって歩けず、残る2方向を敵に塞がれた個体へ横から短剣が命中したときに目撃する。対向する2方向が塞がれた直線通路は角地扱いにしない。

取得後、進入前は地形上の歩行距離2マス以内に敵が2体以上いる角地を避ける。既に角地にいる場合は歩いて3マス以内（1・2・3マス）に敵が2体以上いる時点で、空いている安全な隣接マスへ早めに出る。敵の駒や味方の駒は一時的に動くため、距離を測る際は地形と門の通行権だけを使う。壁越しに直線で近くても、歩いて2マスで届かなければ数えない。完全に囲まれて出口に駒がいる場合は、駒や壁を無視して脱出せず、元の攻撃などの行動を維持する。撤退行動には角地回避を強制しない。

## 予約の旗と作業靴の演出（2026-10-31）

守備専用に加え、出撃選択・出撃予約、迎撃専用予約、工場作業員予約、廃棄予約、ロボットパーツ直送便、長期輸送計画へ旗を振って作業靴を履く演出を追加した。予約処理はその場で成立し、描画だけを個体ごとの時計で約1.15秒再生する。開始から約0.28秒は旗を振り、その後約0.45秒で靴が現れる。複数個体の演出は同時に進み、その間も別の選択・予約・取消を受け付ける。失敗した操作では開始せず、解除した役割の靴と演出は消える。

出撃欄の26×31のロボットでも旗の高さを最低18px、靴の厚さを最低3pxとし、旗を小さなプレビューの内側に収める。出撃選択の段階でも反応を示すが、出撃命令の確定は従来どおり開戦予約ボタンで行う。大きな選択画面と小さな出撃欄の両方で描画する。

靴や旗は表示上の追加であり、パーツの所属色、所有権、守備旗の権限、仕事の成立条件は変更しない。守備専用は従来の指示国、その他の個体は役割・出撃命令・直送便注文の所属国を使う。脚を持たない直送便パーツには旗だけを描き、存在しない脚や靴を補わない。

## 安物の所属と内政の説得確率（2026-10-31）

利用者の定義により、安物は品質であり、所属国とは分ける。健康な安物も自国所属として数える。内政の通常の説得成功率は、説得する国に所属する健康なパーツが0/3なら5%、1/3なら35%、2/3なら70%、3/3なら95%。損傷パーツは数に入れない。明示的に変更したシミュレーション用の確率設定は引き続き優先する。

## 仕事の継続資格・組み換え・回収（2026-10-31）

仕事予約は完全体で健康な自国色パーツを1つ以上含み、調練の条件を満たす間だけ継続する。損傷・組み換え・調練変更などで資格を失った時点で仕事予約と靴を解除する。内政準備時、保存データの読込時、戦闘からの帰還時にも検査する。出撃命令は該当個体だけ外し、他の兵隊や征服者の移動は残す。戦場の壁・堀・門は開始時の個数を維持する。

自国色3/3に他国の靴だけが残っていた旧状態は、旧国の健康なパーツが無いため自動解除される。全損傷でも、自国色のパーツを1つ以上含み、他国の有効な仕事予約が無ければポケットへ回収できる。ポケット移動では自国の仕事予約・配送予約を解除する。実行中の分解や廃棄などは引き続き待つ。

同一地点の組み換えでは自国の仕事予約を上書きできる。他国の有効な仕事予約は先に説得で解除する。完全体からパーツを取り外せば仕事を解除し、スワップなら交換後も継続資格を満たす場合に限り仕事を残す。

配送予約は対象パーツの所属色・種類・品質・損傷・一体化状態などが変わった場合、関係する注文だけ解除する。同じ状態のパーツ同士のスワップは何も変更しない。ロボットのId、所属、履歴、配送予約を維持する。パーツ個別のIdは無い。失敗した組み換えでは配送予約を消さない。

仕事の靴は完全体の出撃・守備・迎撃・工場作業を表す。パーツ配送と廃棄実行待ちは仕事の靴を付けない。この定義は上記の初期演出説明より優先する。長期輸送計画の見本演出は実在ロボットへの仕事予約ではない。

WorkContinuityで資格喪失、全損傷回収、調練変更、出撃個体の除外、等価交換とId維持、配送注文の選択的解除、仕事継続、不正操作の原子性を検証する。

## 直送便の連続切替とトランジション（2026-10-31）

大地図のトラック／フェリーから直送便を開くと、約0.35秒で地図の表示領域・拡大率・中心位置を補間し、左右インスペクターをフレームインする。地星儀と展開図の向きは維持する。上段の表示設定とシステムメニューは上へ、プライマリー操作は下へ退避する。×／Escでは逆向きに遷移し、元の大地図のカメラと直送便モードへ戻る。

## 計算演出と開戦予約の表示（2026-10-31）

世界征服状況フェーズの計算演出は、地域数・倍率・Entry番号・得点の数式本体を1行にまとめ、その下に独立した暫定順位の行を表示する。entry noはEntry数値の上、sector／sectorsとpointsは各数値の下へ置く。単位を数式の横幅から外し、数字の枠を高さ56から76へ、数式の記号と単位の文字も拡大した。地域、Entry、得点、順位の公開順と数値の計算は変えない。電池のない国のマイナス100点と、手下の地域数の補足も残す。

開戦インスペクターの小さなロボットには、上段に現在の予約、下段に今回の出撃選択／不可を表示する。現在の予約は守備・迎撃・工場・配送・廃棄・出撃・別出撃を区別し、掲示板と同じ色を使う。大きな出撃選択ダイアログでも元の予約と出撃選択を併記する。出撃選択中は元の役割を消さず、開戦予約の確定で上書きする従来の操作を維持する。

## 守備専用予約と調練の説明（2026-10-31）

格納庫で守備専用予約を選び、調練の「自国のパーツのみのロボット」という制限だけで予約できない個体をクリックすると、予約を指示する国の征服者の顔・名前と吹き出しを表示する。「私の国では 3/3 が自国のパーツでできているロボットしか戦闘に出しません」と説明し、損傷したパーツを自国パーツに数えない点も補足する。ロボットの現在の所有国や地点の国ではなく、守備を指示する国の調練と顔を使用する。

説明の判定は、調練の追加制限だけを無視すれば同じ予約が成立する場合に限る。完全体でない、自国の健康なパーツがない、他国の仕事予約や配送・処理中など、別の理由でも成立しない場合は調練のせいにしない。既存の守備予約の取消にも調練の説明を出さない。予約条件そのものは変えない。

吹き出しは操作を待たせず、クリックで閉じられる。パネル内のクリックは下の地図へ通さない。次の格納庫操作、ページ切替、調練変更、操作国変更などで説明が該当しなくなれば表示しない。

DefenseShoesUiで、指示国と地点・ロボットの所属国が異なるケース、基本条件・予約競合との区別、実入力による閉鎖、調練変更後すぐの予約成功、1080p／540pの顔と吹き出し描画を確認する。画像は既存artifacts/corner-lessonのdefense-shoes-11.pngと12.png。既存の人物画像を使用し、新しい人物画像は作成していない。
