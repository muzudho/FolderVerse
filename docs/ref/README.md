# ゲームの仕組みを知りたい人へ

[トップページ](../../README.md) / [ドキュメント案内](../README.md)

[ゲームの仕組み](ゲームの仕組み.md)には、これまでトップREADMEで説明していたロボット・戦闘・人物抽選・地図・節点の仕様をまとめています。操作手順は[操作ガイド](../user/操作ガイド.md)へ。

このゲームは開発中です。暫定値や過去の画像加工については、各節の説明を参照してください。

## 配布版で遊んで調べる

リサーチャーも、[v0.1.0 Pre-release](https://github.com/muzudho/FolderVerse/releases/tag/v0.1.0)をダウンロードして調べられます。[ダウンロードと起動方法](../user/README.md)を参照してください。Visual Studioやソースコードからの実行は必要ありません。

このフォルダーは開発中の仕様も扱うため、配布版と一致しない記述があります。調査結果には、使用したリリースのバージョン、再現手順、SEED、解像度を残してください。開発中のコードを調査した場合は、そのコミットも記録してください。開発用テストの実行方法は[開発者向け案内](../dev/README.md)へ。
