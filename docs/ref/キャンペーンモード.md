# キャンペーンモード

2026-10-31実装。スタートメニューは「遊び方」「キャンペーンモード」「続きから」「最初から」の順。保存が無い場合も「続きから」は薄く表示し、選択できない。キャンペーンを開くと既存の案内役のモブが説明し、シナリオを選ぶ。選択を取り消しただけでは世界や保存データを変更しない。

## キャンペーン#1 地賽でタイマン

- 人間1人とコンピューター1人。1×1×1、全6地域。
- 両国に3地域ずつ与え、各国の領土が隣接関係で連続する組合せからランダムに選ぶ。
- 地形、地点性能、製造設備、初期ロボットなどは「初めから」と同じ通常の初期化処理を使う。地域数を等しくする設定であり、資源・初期戦力まで対称にはしない。
- 征服者はNo.01～No.60の同じ大きさの一覧から選ぶ。地域数順には並べない。
- 「あなた」「コンピューター」を個別に選択し、それぞれのランダムボタンも使える。同キャラ、同じ外見の選択を許す。
- 「この２人で始める」で世界生成と領土配分を完了し、世界征服状況フェーズへ進む。人数確認、世界構築、土地選択は省略する。
- 通常の内政境界でオートセーブし、タイトルの「続きから」で再開できる。セーブ形式は共通。

実装入口はGame1.CampaignMenu.csとWorldSetup.CampaignDuel.cs。既存の人物画像と案内役画像を使用し、新しい画像素材は生成していない。

## 確認

CampaignDuelで24通りの乱数設定、両国の領土の連結・3対3、同キャラ、人間／CPUの操作担当、通常初期化、保存復元を確認。実際のGame1で1080pと540pの描画、60人目の選択、ランダム、戻る、開始、オートセーブと「続きから」を確認した。出力は既存のartifacts/corner-lessonを再利用し、campaign-0.png～campaign-5.pngに保存。

TitleStartMenu、ConquestOverview、InvasionPlanning（モデルとUI）、DemoUi、FontCoverageも検証。TitleStartMenuの旧プラスボタン／電池ボタン操作と、既に実装済みのチュートリアルを未実装扱いしていたテストを現行操作へ更新した。InvasionPlanningの未初期化Game1テストには、先行直送便変更で追加されたクリック矩形リストの初期化を補った。
