# ゲーム用語

## 地点（Point）

ロボットや征服者が滞在し、交通路でつながる盤面上の場所を「地点」と呼ぶ。英語表記は単数形 Point、複数形 Points とする。

陸上・海上・空中に共通して使う。将来、同じ場所で高度を区別する場合は「地点」と「高度」を組み合わせて示す。

画面・ツールチップ・説明書では従来の「節点」「ノード」「Node」を「地点」「Point」に統一する。面積を表す「区画（Sector）」、得点を表す points とは区別する。

コード上の Node 等の識別子やセーブ形式は変更しない。過去の開発記録や個人用の検討記録にある旧称は、その時点の記録として残す。

## 区画（Sector）

地星儀の表面を区切り、土地の選択・獲得・征服数の単位になる領域を「区画」と呼ぶ。英語表記は単数形 Sector、複数形 Sectors とする。

画面、ボタン、ツールチップ、説明書の「セル」「Cell」は「区画」「Sector」に統一する。右上の交通路メニューは「区画を選択」「地点を選択」、地形メニューは「国区画色分け」とする。

コード内部の Cell / Cells 等の識別子と保存形式は維持する。「キャンセル」は取り消し操作の名称として維持する。過去の開発記録と個人用の記録は書き換えない。
