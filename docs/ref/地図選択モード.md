# 地図選択モード
ノードを初期モードとし、交通路と節点を表示する。節点にカーソルを合わせると節点を強調し、クリックで節点内政を開く。空白のセルから節点内政を開かない。
セルモードは交通路と節点を隠し、セルを強調・選択する。展開図では選択セルを保持、地星儀では既存のセルを中心に展開図へ移る動作を利用する。
選択ボタンは四方への線と中央円のノードアイコン、１マスを塗ったグリッドのセルアイコンに下向き印を組み合わせる。一覧には対象名を表示する。
セルの所属は全ノードの最上位ボスが一致するときそのボスの国。未所属ノードを含む、異なる最上位ボスが混在する、ノードがない場合は未所属。陸海の接続有無でノードを除外しない。
将来の国・国境セル・連合国セル選択と内政は追加予定。国境の分類はセルの所属とは別に扱う。
