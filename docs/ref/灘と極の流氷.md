# 灘と極の流氷

海には、通常の網目状の航路に加えて、灘の大渦巻きと極の流氷がある。どちらも通行できない水域を作り、航路の選択を重要にする。

## 灘

大渦巻きの内部には地点を作らず、航路も通さない。灘があっても、各地域には少なくとも１地点を残す。

大渦巻きのすぐ近くまで水域が続く海上地点は、初期格納庫が１個で、初期のロボット製造レーンを持たない。地点名の説明には「灘付近」と表示する。陸地や港まで一律に不利にはしない。隣接地点からの機能移転で後から工場や格納庫を増強できる。

灘だからといって、ロボットの廃棄が容易になるわけではない。大渦巻きへの投棄による処分はできず、廃棄には通常の設備と手順が必要となる。廃棄の時間や費用が有利になる特例もない。

## 極の流氷

極に当たる２面の海上では、流氷が海面を狭め、分岐を減らす。同じ方向へ長く進む航路を優先し、端で折り返す経路と限られた出口を残す。他の４面は網目状の航路と灘を特徴とする。

氷の中には地点を作らず、航路も通さない。全地点への到達性を保つために必要な接続と港は残す。流氷の見た目は、不定形の多角形を敷き詰めた形にする。航路の通行可否は全体ターン中に変化しない。

新しい地形と初期設備のルールは、新しく構築した世界に適用する。保存済みの世界の航路、格納庫容量、工場を後から変更しない。
