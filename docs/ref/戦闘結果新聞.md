# 戦闘結果新聞

戦場カメラマンが集めた全情報から、新聞社が注目記事を選ぶ。１社の１号は１枚で読み終わる。新聞の即時性は画面演出であり、世界観では１～３日遅れの配達となる。

## 現在の実装

写真付き記事は最大３件、文字の戦況短信は最大６件。全戦場数、終結数、継戦数、未掲載数を明記する。選定は元の戦闘配列を変更しない。写真は勝者の顔と国名、記事には各陣営の転倒・撤退数を載せる。

基本点は番狂わせ100、クイーン参加40、上位国参加25、多数の駒を持つ国の敗北30、継戦15。３国以上は追加国ごと10（上限30）、総駒数は３駒ごと１（上限20）。順位は戦闘生成時に保存する。上位・下位は順位表の四分の一（端数切り上げ）。

既掲載記事と異なる国が参加する戦場に12点を補正し、同点は元の戦場順とする。従軍紙はプレイヤー参加35、うわさ紙は下位国勝利25、記録紙は転倒数（上限30）、学級新聞はクイーン25を追加する。

AUTOは１社を６秒、DEMOは３社を各６秒読む。戦場数によってページ数や読了時間は増えない。手動では下段の新聞カルーセルで社を選べる。

## 今後の改善案

トップ記事１件を大きくし、注目記事２件と視覚的に区別する。所在地が定義されたら地方紙の周辺優先を導入する。自国・手下の結果の短信保証、国別損失集計、全件を見返せる戦闘記録を追加する。現在の画面は全件の詳細一覧を備えていないため、未掲載戦場の詳細は紙面から確認できない。

入力元は個人用資料の「戦闘_戦場カメラマン女_世界観設定」「戦闘_戦場カメラマン女_仕様」。実装は NewspaperSelection と Game1.BattleSummary。
