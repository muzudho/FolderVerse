# 産業フェーズと安い兵隊ロボットのパーツ

## 進行と時計

全員の内政行動が揃うと、伝播・戦闘・戦闘結果の表示を経て、全員共通の産業ルーレットを１回回す。戦闘が発生しないターンも産業へ進む。回転は4.5秒で減速停止。結果の産業ターンを順に実行し、「次の内政へ」で戻る。DEMO・AUTOでは結果表示後に自動で進む。

全体ターンは従来の人口・戦闘・輸送の時計。産業ターンは製造進捗、製造レーンの休業、廃炉の時計。産業で40が出ても戦闘・輸送・人口更新を40回繰り返さない。組み立ては各産業ターンの完成品を対象に実行する。格納庫の空き枠予約を守り、満杯なら完成待ちになる。継戦中の節点は産業処理を保留する。監督官の休暇は引き続き全体ターン単位。

## 安いパーツ

所属国・安いパーツ・損傷は独立した属性。安いパーツは製造国を保持するが、通常の自国パーツ数・装備量への加点はなく無所属相当。安いパーツ単独では出撃できない。正常な正規自国パーツが１つ以上あれば従来の混成出撃に使える。さらに正規自国パーツが損傷していても、健康な安いパーツが１つ以上あれば最低限の能力で動ける。安いパーツも全部損傷した場合、この補助は働かない。正規パーツもない個体は動けない。

この補助出撃では短剣・盾・小銃を最低１にする。通常の健全な正規自国３パーツの装備より弱い。既存の調練設定は維持し、混成を使うには混成組立・混成出撃を許す方針を選ぶ。正規のみの方針を安いパーツで迂回しない。

格納庫・ポケット・地図・戦闘・製造見本で縞を表示。健康な安いパーツは自国色と明るい素体色の縞、損傷時はくすんだ金属色の縞。分解・合体・パーツ移動・輸送・帰還・JSON保存で安さと損傷をそれぞれ保持する。

各製造レーンの正規３プランに対応した安い３プランを追加。製造所要時間は正規の半分を切り捨て、最低１産業ターン。既存の抽選プランは最低２産業ターンなので必ず正規より早い。「製造しない」、指定台数ごとの休業、予約枠を引き続き使用できる。監督官の自動計画変更は従来どおり有効なので、手動で計画を保持したい場合は監督官へ任せない。
