# 産業フェーズと安い兵隊ロボットのパーツ

## 進行と時計

全員の内政行動が揃うと、伝播・戦闘・戦闘結果の表示を経て、全員共通の産業ルーレットを１回回す。戦闘が発生しないターンも産業へ進む。最初の1.4秒は数字を読むために静止し、その後4.5秒で回転・減速停止。結果の産業ターンを順に実行し、「次の内政へ」で戻る。DEMO・AUTOでは結果表示後に自動で進む。

全体ターンは従来の人口・戦闘・輸送の時計。産業ターンは製造進捗、製造レーンの休業、廃炉の時計。産業で40が出ても戦闘・輸送・人口更新を40回繰り返さない。組み立ては各産業ターンの完成品を対象に実行する。格納庫の空き枠予約を守り、満杯なら完成待ちになる。継戦中の節点は産業処理を保留する。監督官の休暇は引き続き全体ターン単位。

## ルーレット

数字のセット・各区画の割合・配置順を全体ターンごとに生成する。世界のSEEDと全体ターンから再現でき、同じ盤面の回転中に内容を差し替えない。

- ０は合計４％。大当たりは１％。それ以外は合計95％。
- 大当たりの数字は30～60。その回の最大値を大当たりとし、40固定ではない。
- 通常値は１・２、および３～６／７～10／11～16から選んだ値。割合も変える。
- 毎回、確率合計100％、期待値ちょうど４産業ターンを満たす。10全体ターンの期待値は40で、実際の結果を保証するものではない。
- ０と１を複数区画へ分ける。描画面積と抽選確率は同じ生成データを使用。０や大当たりも他と同じ文字サイズで、扇からはみ出してよい。数字は全ての扇を描いた後に重ねる。

## 安いパーツ

所属国・安いパーツ・損傷は独立した属性（2026-10-31変更）。安いパーツも、損傷していなければ製造国への所属を持ち、自国パーツ数・装備量に正規品と同じように数える。自国の安物３パーツだけで完成したロボットも出撃できる。損傷したパーツは所属への加点を失うが、元の製造国の情報は保持する。

既存の調練設定は維持する。自国３パーツを要求する方針でも、健康な自国の安物３パーツなら条件を満たす。混成の出撃を許す方針では、完成体に健康な自国パーツが最低１つあればよく、安物と正規品を区別しない。損傷した自国正規品だけを身元として、他国の安物を借りて出撃できる従来の補助判定は削除した。

格納庫・ポケット・地図・戦闘・製造見本で縞を表示。健康な安いパーツは自国色と明るい素体色の縞、損傷時はくすんだ金属色の縞。分解・合体・パーツ移動・輸送・帰還・JSON保存で安さと損傷をそれぞれ保持する。

各製造レーンの正規３プランに対応した安い３プランを追加。製造所要時間は正規の半分を切り捨て、最低１産業ターン。既存の抽選プランは最低２産業ターンなので必ず正規より早い。「製造しない」、指定台数ごとの休業、予約枠を引き続き使用できる。監督官の自動計画変更は従来どおり有効なので、手動で計画を保持したい場合は監督官へ任せない。

## 数字の案内（2026-10-17更新）

隣り合う同じ数字の扇は、円の最後と最初を含めて統合する。各結果の合計確率は変えない。最初は全ての数字を隠し、1.5秒待って最初の数字を表示する。12時から時計回りに0.4秒ごとに１つずつ表示し、最後の数字を表示してからさらに1.5秒待って回転を開始する。以前の一律1.4秒の待機を置き換える。

## 検討案：工場作業員のパーツと追加レーンの製造候補（2026-10-31）

利用者の指示により、今回は仕様の整理のみ。以下の製造候補への影響は未実装。実装済みなのは、調練の配備項目の改名・初期値変更と、独立した工場作業員の割合設定である。

### 利用者からの案

対象は工場作業員によって追加したレーン。作業員の頭・胴・脚の属性が、それぞれ同じ部位を含む製造候補に影響する。

- 他国色の部位がある場合、その部位を含む候補の約50％で、製造するその部位も同じ他国色にする。
- 安物の部位がある場合、その部位について通常選べる正規候補を約50％減らす。
- 色と品質は独立した要素として扱う。外国色かつ安物の頭なら、頭の色と頭の正規候補数の両方へ影響し、胴・脚へ一括波及させない。

「正規が50％減る」は候補数に対する相対的な半減と解釈する案。例えば通常その部位の正規候補が４件なら約２件にする。製造後に50％で勝手に安物へ変わるルールにはしない。

### 実装する際の推奨事項（採用は未確定）

- 常設レーンは従来のままにし、追加レーンだけへ適用する。
- 候補は任命時に確定し、画面の開閉や毎回の製造では再抽選しない（以下の追記で利用者が指定）。
- 正規候補が少ない部位は、半減後の数を切り上げ、もともと正規候補がある部位には最低１件残す案。
- 色も品質も部位ごとに表示し、選択した見た目どおりのパーツを完成品へ渡す。複数部位や一体型でも、対象でない部位の属性は変えない。
- 作業員のパーツ変更で候補を更新する場合、既に進行中の製造品を黙って変えない。
- 品質の変更や候補数を決めた後、その最終候補の部位ごとに外国色の約半数を割り当て、色と品質を組み合わせても割合の意味がずれないようにする。
- 監督の自動製造計画も、完成予定品の実際の所属色・品質を使って評価する。

現在は各レーンに通常３案、対応する安物３案、一体型の正規２案・安物２案、製造しない１案がある。製造プランの安さはプラン全体の真偽値で、完成品の所属色も地点所有国を使う。そのため、この案の実装にはプランの部位別の色・品質、候補表示、実際の完成品を揃える拡張が必要になる。単に抽選率を１つ追加する変更ではない。

候補が少ないときの端数処理、減らす正規候補を安物へ置き換えるか選択不可にするか、一体型の製造時間、作業員交代や組み換え時に候補をいつ更新するかは未確定。現段階で承認済み仕様として扱わない。

### 追記：任命時のプラン確定とSeed（2026-10-31、利用者指定）

製造候補は工場作業員を任命した時点で確定させる。地点と任命時のロボットパーツの状態の等価性に基づいて再現可能にし、同じ条件での解除・再任命を候補の引き直しに使えなくする。今回は仕様整理のみという指示を継続し、製造レーンの生成コードには未反映。

- Seedの入力は、世界Seedと地点Id、製造する国を判定するための工場の所属国、任命時の頭・胴・脚の状態を使う案。
- 部位の状態は、存在する部位、各部位の所属色、安物／正規、損傷、一体化の状態を一定の順序で表現する。派生する損傷・結合関係も同じなら、等価な状態として扱う。
- ロボットId、任命回数、日時、靴や予約フラグ、説得履歴、画面の開閉回数は入力に含めない。同じ地点で状態が等価なら、別Idのロボットでも同じ候補になる。
- 一度条件を変えても、元の地点・所属国・等価なパーツ状態へ戻して任命すれば元の候補になる。
- 実装時は、実行ごとに変動しない方法でSeedを計算し、保存・再起動後も同じ結果を再現する。

在任中に予約を継続できる組み換えを行った場合も、任命時の状態を記録したスナップショットでプランを固定し、再任命時に新しい状態から確定し直すのが一貫した扱いとして考えられる。この更新タイミングと、製造途中の仕事の扱いは実装前の確認事項とする。
