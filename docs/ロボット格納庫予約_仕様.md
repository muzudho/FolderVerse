# 節点の格納庫予約と工場作業員

更新：2026-10-24。利用者の追加指示を反映した実装仕様。

## 予約の操作

［ロボット組立・分解］画面の下部に［廃棄予約］［守備専用予約］［工場作業員予約］を置く。ボタンを押してから格納庫の個体をクリックすると予約する。同じ個体をもう一度クリックすると、その種類の予約を解除する。ツールは選択を続けられ、同じボタンをもう一度押すと通常のパーツ操作へ戻る。セルごとの廃棄チェックボタンは置かない。

輸送予約は設けない。輸送計画に該当していても、内政中は組立・分解・パーツ交換ができる。ターン終了時は予約済みの組立・分解と自動組立を行い、その後の在庫から既存の輸送計画に沿って輸送対象を選ぶ。輸送計画を組立のたびに解除する必要はない。出撃予約は既存の出撃計画で設定／解除する。

廃棄・出撃・守備専用・工場作業員の予約が付いた個体は、手動のパーツ移動、交換、組立、分解、自動組立、輸送先での自動結合の対象から外す。別の役割へ変えるときは元の予約を解除する。継戦中と廃棄炉で処理中は変更しない。

## 守備専用

- 頭・胴・脚が揃い、その個体の所属国の出撃方針に適合することを予約条件とする。
- 攻撃出撃、他節点への増援、輸送、廃棄、ポケットへの移動を禁止する。
- 自分が格納されている節点が攻撃された場合は、出撃条件を満たす守備専用個体を守備側として配置する。帰還後も予約を保持する。

## 工場作業員とレーン

- 頭・胴・脚が揃い、所属国の出撃条件を満たす個体を指定する。
- 空きレーン１つにつき作業員１体。その個体が格納庫にいる間、担当の生産レーンを１つ追加する。
- 常設レーンと追加レーンの合計上限は陸上３、海上１。
- 常設は［常設レーン］、追加分は［工場作業員］と担当ロボット・IDで識別する。
- 各追加レーンは独自の製造計画・進捗・休業を持つ。作業員の予約を解除すると担当レーンを閉じ、未完成の製造進捗を破棄する。他の作業員のレーンと製造済みの在庫は保つ。
- 作業員は配置中、出撃・守備・輸送・廃棄・組立・分解・ポケット移動から外す。出撃条件を失った場合は、継戦外での内政準備・産業更新時に作業員予約を解除する。
- 予約・担当レーン・進捗はオートセーブする。旧セーブは新しい予約なしとして読み、海上の既存複数レーンは先頭１レーンに制限する。

## 海上の表示

海上節点の２・３段目は追加可能な空き枠として表示せず、波模様の海面と［海上 / レーン上限１］を表示する。常設０レーンの海上節点でも、作業員を１体配置して１レーンを稼働できる。

## AUTOとDemoの内政

AUTOは約２秒ごとに格納庫、輸送計画、組立、工場を巡回してから次の全体ターンへ進む。出撃可能な個体を組み立てられる節点を優先して表示する。画面クリックまたはEscで全フェーズ共通にAUTOを解除する。解除入力は伝播や演出、モーダル画面の入力より先に扱い、同じクリックで別の操作を実行しない。

Demoの組立紹介では、完成した個体を分解して元へ戻す操作をしない。予約されていないパーツから出撃可能な個体を作れる組み合わせを探し、実際に組み立てて戦力を増やす。材料がなければ操作を省略する。紹介のためだけの輸送指示も追加しない。
