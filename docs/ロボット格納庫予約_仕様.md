# 節点の格納庫予約と工場作業員

更新：2026-10-25。利用者の追加指示を反映した実装仕様。

## 予約の操作

［ロボット格納庫］タブの下部に［組立・分解］［廃棄予約］［守備専用予約］［工場作業員予約］［迎撃専用予約］を置く。［迎撃専用予約］は下段に配置する。ボタンを押してから格納庫の個体をクリックすると予約する。同じ個体をもう一度クリックすると、その種類の予約を解除する。ツールは選択を続けられ、同じボタンをもう一度押すか［組立・分解］を選ぶと通常のパーツ操作へ戻る。予約モードではパーツ単位の枠・ホバー反応を止め、個体が入ったセル全体をホバー強調する。予約可能なら明るい枠、条件不足や処理中なら赤い枠で示す。セルごとの廃棄チェックボタンは置かない。

長期計画による輸送予約は設けない。輸送計画に該当していても、内政中は組立・分解・パーツ交換ができる。ターン終了時は予約済みの組立・分解と自動組立を行い、その後の在庫から既存の輸送計画に沿って輸送対象を選ぶ。輸送計画を組立のたびに解除する必要はない。出撃予約は既存の出撃計画で設定／解除する。

廃棄・出撃・守備専用・工場作業員の予約が付いた個体は、手動のパーツ移動、交換、組立、分解、自動組立、輸送先での自動結合の対象から外す。別の予約を選ぶと、新しい予約の条件を確認して元の役割予約を上書きする。同じ予約を選ぶと解除する。出撃条件不足・空きレーン不足などで切替不能なら、元の予約・出撃計画・担当レーンと進捗をそのまま残す。廃棄処理中・出撃中・継戦中・組立分解の処理予約中は上書きしない。

出撃予約から別の役割へ上書きした場合は、その個体だけを古い出撃計画から外す。残りの参加個体、出撃先、クイーンの参加は保つ。ロボットが０体になったクイーン不参加の計画は削除する。逆に格納庫から出撃を予約するときも、条件を満たす廃棄待ち・守備専用・工場作業員を選べる。出撃予約の確定時に元の役割を上書きし、作業員だった場合は担当レーンを閉じる。選択画面の取消や未選択の個体は変更しない。

## 守備専用

- 頭・胴・脚が揃い、その個体の所属国の出撃方針に適合することを予約条件とする。
- 攻撃出撃、他節点への増援、輸送、廃棄、ポケットへの移動を禁止する。
- 自分が格納されている節点が攻撃された場合は、出撃条件を満たす守備専用個体を守備側として配置する。帰還後も予約を保持する。

## 工場作業員とレーン

- 頭・胴・脚が揃い、所属国の出撃条件を満たす個体を指定する。
- 空きレーン１つにつき作業員１体。その個体が格納庫にいる間、担当の生産レーンを１つ追加する。
- 常設レーンと追加レーンの合計上限は陸上３、海上１。
- 常設は［常設レーン］、追加分は［工場作業員］と担当ロボット・IDで識別する。
- 各追加レーンは独自の製造計画・進捗・休業を持つ。作業員の予約を解除、または別の役割へ上書きすると担当レーンを閉じ、未完成の製造進捗を破棄する。他の作業員のレーンと製造済みの在庫は保つ。
- 作業員は配置中、出撃・守備・輸送・廃棄・組立・分解・ポケット移動から外す。出撃条件を失った場合は、継戦外での内政準備・産業更新時に作業員予約を解除する。
- 予約・担当レーン・進捗はオートセーブする。旧セーブは新しい予約なしとして読み、海上の既存複数レーンは先頭１レーンに制限する。

## 海上の表示

海上節点の２・３段目は追加可能な空き枠として表示せず、波模様の海面と［海上 / レーン上限１］を表示する。常設０レーンの海上節点でも、作業員を１体配置して１レーンを稼働できる。

## AUTOとDemoの内政

AUTOは約２秒ごとに格納庫、輸送計画、組立、工場を巡回してから次の全体ターンへ進む。出撃可能な個体を組み立てられる節点を優先して表示する。画面クリックまたはEscで全フェーズ共通にAUTOを解除する。解除入力は伝播や演出、モーダル画面の入力より先に扱い、同じクリックで別の操作を実行しない。

Demoの組立紹介では、完成した個体を分解して元へ戻す操作をしない。予約されていないパーツから出撃可能な個体を作れる組み合わせを探し、実際に組み立てて戦力を増やす。材料がなければ操作を省略する。紹介のためだけの輸送指示も追加しない。

## 迎撃専用予約（2026-10-25）

- 守備専用とは別の、他の役割予約と排他的な予約。出撃条件を満たす完成ロボットへ指定する。通常の進軍・自動輸送・組立操作から外す。
- 同じ全体ターンの敵の攻撃を、攻撃元の異なる辺の数で集計する。１辺なら迎撃可能な予約個体全員を辺戦へ出す。２辺以上、または迎撃可能個体０なら地点戦へ参加する。
- 迎撃中の別辺からの攻撃は、出撃済み個体を含めない別の地点戦にする。迎撃中も地点自体は辺戦のためにはロックせず、辺だけをロックする。
- 迎撃の辺戦には旗の条件を適用しない。勝敗・撤退にかかわらず、この辺戦だけでは地点を占領せず、両側のロボットは帰還する。再進軍は次の全体ターン以降。
- クイーンは征服者本人の駒。参加中の本人だけを表示し、帰還は征服者の現在地点を更新する。格納庫へロボットとして追加しない。
- 新しい戦場は13×13。地点戦は中央の守備軍と外周４軍の最大５軍。旗はG7、守備側はその周囲の菱形13マス、各攻撃側は外周７＋内側６マス。各軍はロボット最大12体＋参加中のクイーン１人を初期配置する。
- 戦場表示は従来の1000×1000ピクセルを維持し、マス・駒・演出を10/13へ縮小する。旧保存の継戦は10×10を維持する。
- 戦闘中の地図は、辺戦を辺の途中、地点戦を地点にアニメーション表示する。新聞は５軍を掲載する。
