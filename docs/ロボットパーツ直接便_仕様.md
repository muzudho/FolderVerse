# ロボット輸送長期計画とロボットパーツ直接便

更新：2026-10-24。初回実装は、自国と配下の隣接する２節点間を対象とする。

## 二つの輸送方式

- ［ロボット輸送長期計画］：従来の割合・回数による輸送計画。計画に該当するだけでは個体やパーツをロックしない。
- ［ロボットパーツ直接便］：実物の頭・胴・脚を指定する、一度きりの輸送。ターン終了時に直接便を処理し、その後の組立・在庫に長期計画を適用する。

## 画面と操作

内政下部の［ロボットパーツ直接便］を押すと、地星儀または展開図の節点間の辺にトラックを表示する。両端が自国・配下の節点である辺を対象とし、継戦中の節点・辺のトラックは操作不可とする。右ドラッグ・拡縮・地図表示切替は既存の操作を使う。

トラックをクリックすると、左右に両端のロボット格納庫を表示する。片側につき12セル、頭・胴・脚を個別に操作する。

- 同じ側へのドラッグ：その場で組立・分解・部位交換を行う。
- 反対側へのドラッグ：選んだパーツを直接便として予約する。実物は出発側に残す。
- 既存の個体のセルへドロップ：同じ所属国で、選択した部位が空いている個体へ取り付ける予約。
- 空セルへドロップ：新しい到着予定セルへの予約。異なる部位を同じ到着予定セルへ予約できる。
- 予約された出発側のパーツ、または半透明の到着予定パーツをクリック：該当する予約を取り消す。
- 到着予定パーツは、実際に届くまでは出発側として扱えない。
- 左上のボタンまたはEsc：トラックの地図へ戻る。さらにEscまたは直接便ボタンで通常の内政地図へ戻る。画面を閉じても予約は残る。

予約中の出発パーツは薄くし、受取側には半透明の到着予定を描く。トラック上の数字と左右画面下部に、その辺の予約件数・部位・待機状態を表示する。

## ロックと整合性

出発側の指定パーツと、受取先に指定した個体の空き部位をロックする。同じ個体の別の部位は、IDを保てる範囲で手動で動かせる。到着先の個体を消してしまう最後のパーツ移動は認めない。

一つでも直接便の対象部位がある個体は、個体全体を使う自動組立・分解指示・攻撃出撃・増援・ポケット移動・長期計画から保護する。直接便の対象外パーツを手動で別個体へ移した場合、その別個体は通常どおり扱える。

守備専用・工場作業員・廃棄待ち・出撃予約・組立分解指示中の個体には、直接便を重ねない。逆に直接便の部位予約がある個体へ、役割予約や出撃予約を上書きすることもできない。直接便は部位の移動を伴うため、役割の上書きとは別扱いとする。

同じ部位が既にある相手への輸送交換は初回実装では行わない。まず取消・組替えなどで受取先の部位を空ける。

## ターン終了時

予約済みの手動組立指示を処理した後、直接便を同時に評価する。出発側から取り外した後の在庫と受取側の結合結果を試算し、帰還予約を含む格納庫容量を超える便は元の場所で待機させる。入る便だけをまとめて確定し、受取容量が空いた次のターンに再試行する。

継戦中・経路閉鎖・所有関係の変化で通れない便は待機する。このターンに敵の攻撃が入る出発地・到着地への便も保留し、守備側は出発前の完全な個体で守る。

指定したパーツや受取先の個体がなくなった場合、対象予約を取り消す。実物のパーツを消すことはしない。一部の部位だけ先に届いた到着予定セルは、作られた個体IDへ残りの予約を結び直す。

直接便が確定した後、自動組立と長期計画を処理する。直接便で到着した個体はそのターンの長期計画では再輸送しない。次のターンから通常の長期計画の対象に戻す。移動履歴には直接便も含める。

予約・対象ID・部位・待機状態は保存対象。旧セーブを読む場合は直接便の予約なしとして扱う。通常のオートセーブの保存タイミングは変更しない。
