Windows x64向けの無料試遊版です。Assets の **FolderVerse-v0.15.0-win-x64.zip** をすべて展開し、**FolderVerse.exe** を起動してください。.NETランタイムを同梱しています。

- 画面上部中央に、玩具風の共通ネームプレートを導入。位置を固定し、画面ごとの説明・新聞題字・ボタン・地図を重ならないよう整理しました。ポップアップヒントはプレートより前に表示します。
- 内政の主な操作をイラスト付きボタンに変更。ガイド呼び出し、順位別の記念メダル、内政開始時の回転演出を追加しました。
- 地星儀・展開図の選択を通常・無効・ハイライト配色とHUDの輪へ統一。スポットライトを廃止し、夜景との干渉、輪の見やすさ、宇宙と大気のはみ出しを改善しました。
- 廃品回収は、受取地点→欲しいもの→回収ロボットの出発地点→到達条件→品選択→最終確認へ整理。別地点への搬入、最大６体、途中取消、最初の回収班状況、地星儀と展開図の切替に対応しました。
- 世界征服状況を朝の番組として刷新。局アナ・現地の背景・得点ボードと順位表・国旗演出を追加し、紹介中の吹き出しは下部へ配置。新聞の場面転換やカーテンの切替タイミングも改善しました。
- 平和移動・開戦・輸送長期計画のインスペクターを短くし、地図を拡大。戦場の盤も正方形を保って少し小さくし、プレート下へ収めました。
- ターン終了時に予約済み計略を全件再検証。条件が変わった計略だけ自動取消し、一度の通知から「このままターン終了する」「戻って続ける」を選べます。
- 意図的に格納庫を一定数空け続ける設定を撤去。セーブ形式をバージョン管理し、未対応形式は読込不能の案内を出します。地形プレビューでの配列範囲外例外なども修正しました。
- 表示ブレーカー、戦闘研究・戦訓、ガイドの指南、敗退後の観戦、デモ・チュートリアルの点検を進めました。

開発中の試遊版です。CPUの収束は条件別に継続調査中で、全条件での完走や全画面・全既存セーブの互換性は保証していません。今回の検証は対象機能のテストと実描画の確認であり、全既存テストの一括成功ではありません。
