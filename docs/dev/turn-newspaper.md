# 朝刊の新聞フェーズ

2026-11-18実装。世界征服状況の演出後、外交の返事を処理する前に朝刊を開く。外交の予定がないときは、新聞を置くと元の内政画面へ戻る。捕虜処遇画面を表示中だった場合も復帰する。チュートリアル専用進行には挿入しない。

各エントリー国の既存の新聞ロゴ・番号字体を使い、１社の新聞を複数の「面」で構成し、１面につき１トピックを載せる。講評も独立した面。自国紙を先頭にし、前後ボタンで他国紙をめくる。各紙を開くときの最初の面はランダムで、面番号は記事順に固定。紙面下の番号・種類・見出し付きプレビューで任意の面へ直接移動する。人間も８秒の無操作で閉じる。クリック・キー・ホイールで残り時間を戻す。Enter/Escまたは「新聞を置いて…」で進む。自動操縦・デモ・コンピューター観戦は８秒で進む。

記事は記録と仮説を区別する。

- 昨日の戦闘結果：完了した戦場を既存の各国視点見出しで報道する。
- 昨日の出来事：世界征服状況と同じ地域増減、戦闘前後の地点所有変化、自国だけの交通路でつながる機能地点のまとまり、入荷先問題の直近記録。
- 今日の外交予定：閲覧者本人の国に関係する期限到来済みの取引件数だけ。他国紙に非公開の取引内容は載せない。読むだけで返事しない。
- 将来の予想：現在の機能地点・前線数に基づく「もし補給できれば」という条件付きの見通し。勝率や確定した未来ではない。

以前の１社１見出しへの絞り込みを廃止し、各記事を別の面へ分ける。同時に表示する本文は１面だけとし、１つの見出しを大きく読む。他国の予想記事は前線のある国から交代掲載する。

朝の演出はコード描画の玩具ポスト４種、木製テーブル、湯気の立つ玩具のコーヒーカップ、厚みと折り目のある紙。新聞社の系統でポストを使い分ける（実在国の厳密な再現ではない）。配達時に短い二段のノック音をSE音量に従って再生し、紙が投入口へ進み、取り出されてテーブル上へ展開する。演出はクリックで省略できる。

## 分析の限界と次の拡張

連絡網は同じ所有国の交通路のみ。過去と現在の機能地点のまとまり数を報告するが、同盟経由・戦闘封鎖・格納庫混雑・実輸送量を含む配送能力の断定ではない。地域増減も戦闘だけの成果とは断定しない。入荷先問題は直近状態が古い可能性を明記する。

数ターン後の新聞と過去記事へのリンク、個別の進撃による物流・製造・勝利への因果推定、地理的な小地図の前後比較は未導入。現在は当日の根拠付き記事と条件付きの見通しを出す。ゲームルール・CPU判断は変更しない。元セーブ・実ゲーム・公開物は変更せず、コミット・公開も行っていない。
