Windows x64向けの無料試遊版です。Assets の **FolderVerse-v0.13.0-win-x64.zip** をすべて展開し、**FolderVerse.exe** を起動してください。.NETランタイムを同梱しています。

- 計略カードから出撃・救援・集中攻撃をまとめて予約できます。CPUも計略を利用します。
- 城壁・詰所の戦闘、遅延救援、待ち伏せ・クロスファイア、戦訓と地点ごとの戦場配置を追加・改善しました。
- 製造中に原材料を消費し、中断した仕掛品を回収・輸送・組替・製造再開できます。繰り返しの既定は無効です。
- 新規通常ゲームに解体レーン・スクラップ・最終処分場を追加しました。１全体ターン置いたスクラップを自動処分します。旧セーブ・チュートリアルは旧処分ルールを維持します。
- 宇宙と朝昼夜の地図、所属関係図・国旗・顔チップ、初期配置の円グラフ、新聞の講評など、見やすさと操作を改善しました。

開発中の試遊版です。配布物で最終処分場108項目・仕掛品367項目・逐次消費24項目と９素材描画を確認していますが、長時間の収束、CPUの新施設活用、全画面・全セーブの互換性を保証するものではありません。既存の検証には変更前から再現する失敗もあり、全テスト成功とはしていません。FRRと戦略カードの類型化は調査段階です。
