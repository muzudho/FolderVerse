# 表示ブレーカー

従来の「簡易表示」を改称。チェックあり＝表示・有効に統一し、経番・緯番、赤道、配備ロボット、電池、煙、隣接オブジェクト、国旗のなびき、地形の高低差を切り替える。チェック状態と表示の意味を逆転させない。

アプリケーションは固定時間ステップの目標18 FPS（約55.6ms）とし、垂直同期による別の上限を重ねない。18 FPSを実現できる性能を保証する設定ではない。

## 自動OFF

- 初期状態で有効。メニュー先頭から自動OFF自体を停止可能。
- 約１秒窓の平均負荷を観測。判定にはフレーム間隔とCPU描画時間の大きい方を使う。
- 55.6msの110%を超える窓が３秒分続くと、現在有効で実測CPU時間の大きい項目を１つだけOFFにする。長い単発停止を複数窓と数えない。
- その後３秒は追加OFFせず、結果を観測する。
- 自動ONはしない。OFFにした項目は画面・カメラ復元が有効へ戻そうとしてもOFFを維持する。
- 手動ONは10秒保護し、超過の連続観測をやり直す。保護終了後も重ければ再び対象になる。
- 自動OFFは通常の内政地図表示中のみ。非アクティブ、ガイド、放送、AUTO一時停止、地図切替や方向回転中は実施しない。
- 画面上に理由を残し、操作ログに項目・計測CPU時間・予算を記録する。

## 計測の範囲

表の単位はCPU ms/frame。各項目に関わる描画・形状生成区間を合算した毎フレームの平均であり、GPU時間や、その項目をOFFにしたときに必ず削減される時間ではない。共通の投影、資源回避、メッシュ転送などは各項目へ無理に按分しない。国旗は旗全体の描画費用を表示し、OFFになるのはなびきだけ。地形の高低差は毎フレーム費用を安全に分離して測定していないため「個別計測なし」と表示し、自動OFF候補にしない。手動では従来どおり切替可能。

OFF中は最後の有効時の計測値を残す。実測のない項目や現在描いていない項目を、推測した費用で自動OFFにしない。全候補をOFFにしても残る負荷は、別の描画最適化が必要。将来の段階的な品質低下は未実装で、現在はON/OFF方式。

## 検証

tests/DisplayBreaker はスパイク、継続超過、費用順、段階実行、10秒保護、手動モード、非対象シーン、未測定項目などを既知時間で検証。tests/DisplayBreakerUi は表示とチェックの一致、実コントローラーでの自動OFF、カメラ復元からの保護、18 FPS設定、通常／自動OFFのメニュー描画を確認。UI画像の4.00ms等は検証用に注入した値で、利用者PCでの性能改善結果ではない。
