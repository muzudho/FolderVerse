# ボタンの状態表現

2026-11-21利用者指定。選択・操作対象・案内を異なる表現にする。

- 選択中：国の基本色（Accent）で面を塗る。
- マウスを重ねた操作対象：面を変えず、基本色の玩具風の枠を付ける。段付きの角、上側の明るい縁、下側の影で成型部品の雰囲気を出す。
- 次に押してほしい案内：外枠をゆっくり明滅させる。選択中の塗りとは独立する。
- 無効：暗く表示し、操作枠と案内明滅を出さない。選択済みの固定ランドマークは基本色の面で現在状態を伝える。

共通描画は UiPainter.StateButton / ToyActionFrame。最初の適用先は地点庁舎の計画地点ボタンと、ガイドの「次へ／終了」。既存の全ボタンを一括変更したものではない。通常Buttonの既存表示は維持し、状態を明示できる画面から移行する。
