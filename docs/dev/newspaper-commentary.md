# 新聞の講評（Commentary）

2026-11-20利用者承認。局所的な成功と国全体への貢献を分けて読むため、朝刊の既存記事に講評を添える。１国１記事の構成・優先順位、新聞配達演出、ページ送り、８秒の無操作タイマー、外交への順序は変えない。

講評を独立した１面にし、本文の３行を「確認」「講評」「仮説」と明記する。他の記事面には併記しない。獲得・喪失件数と増減バーは、その出来事を扱う面に表示する。読み手の操作・予約・能力値・CPU判断を変更しない。

NewspaperCommentary.Buildが次の順で該当する１件を返す。記録が不足する場合は何も出さない。

1. 自国が参戦した完了戦場で味方側が勝利し、前回自国所有の別地点が自国所有でなくなった。局地勝利と支配維持は別成果と講評する。所有変化の原因を戦闘と断定しない。
2. 前回から所有するグレード２以上の城壁地点が今回の戦場記録に登場せず、別地点を失った。守りの配分を点検する余地と書く。敵が過去に来なかった、抑止に無効だった、投資が無駄だったとは断定しない。
3. 読者国について、敵への開戦対象がない地点に役割札なしの戦闘可能機が３体以上あり、開戦対象のある地点には同条件の機体が０。役割予約中の守備兵・製造員等を不足扱いの数へ混ぜない。３体は記事抽出の暫定閾値で、強弱・適正兵力のルールではない。輸送可能性を証明した記事ではなく、経路・空き枠・趣向を確認する条件付き提案。
4. 読者国の製造レーンに直近のIntakeFailureが残る。過去記録と現在の障害を混同せず、経路・所有国・空き枠を再確認する提案。

他国の私的在庫・工場停止は講評から開示しない。戦績・所有変化・公開された城壁による講評は各国視点で表示できる。Buildはモデルを変更しない。表示用TurnNewsArticleの講評面を一時生成し、既存ワールドのセーブ形式に新しい履歴を追加しない。

「不要な時期に強かった」「別の計略を選べば勝てた」「取引成功が敗因になった」といった機会費用の確定評価は未実装。開発時刻・当時の公開情報・代替案の合法性・趣向・後続成果が必要であり、現在の記録だけから捏造しない。世界征服との因果も、別の比較解析で検証する。
