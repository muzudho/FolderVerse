# CPUによる他国ロボットの戦力化

2026-11-25 実装。

CPUは自国地点の格納庫で、他国所属の完全体に自国旗の部位を１つ組み込む組替予約を作る。所属を直接書き換える特例ではなく、通常の部位交換・確定処理を使う。元の部位は供出元へ戻るので、完全体同士なら両方とも完全体を維持する。

## 判断

- 同じ地点にいる自国所属のロボットから、汚損していない自国旗の頭・胴・脚を１つ選ぶ。
- 一体型の途中を切り離す交換はしない。
- 交換先がその国の出撃方針を満たすことを確認する。１部位で出撃可能になる方針なら、それを利用する。自国部位３つを要求する方針は維持する。
- 交換元が出撃可能だった場合、その出撃資格を失う交換は選ばない。交換後の自国出撃可能兵数が増える組み合わせを選び、次に出撃可能兵の装備合計を比較する。
- １地点につき１回の内政計画で１組を予約する。別地点への部位取り寄せや、複数回交換を要する再編は今回の対象外。

## 保護と実行順

人間操作国（自動操縦を除く）、手動管理地点、監督休暇中、チュートリアル、戦闘中、計略・施設移転・進撃・組替・仕掛品再開などの既存計画がある地点を保護する。管理人・作業員・守備等の固定役、配送や取引に使うロボットも交換しない。

内政終了時、計略計画の後、通常のCPU物流計画の前に実施する。そのため圧迫時の帰国を選ぶ前に戦力化を試せる。交換は予約だけで、内政中の現物を変更せず、既存の取消・保存復元・配送時確定に従う。

実装は `ComputerRobotReassembly`、予約入口は `RobotPartPlanning.ReserveComputerReassembly`。帰国・再発注などの別の実験候補は含めない。
