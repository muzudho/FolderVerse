# 地図上の陣営国旗

大旗は実所有者の所属木の根のボス。所有者がボスと異なるときだけ、右下1/4（幅1/2×高さ1/2）へ所有者自身の国旗を合成する。途中の上司の旗は含めない。三角形の大旗は左下へ移し、外側の輪郭で小旗をクリップする。根を毎描画で参照するので所属変更に追従する。

地星儀の面に沿う折れた旗と展開図マーカーは同じGeographicPatchesを共有。元のCountryFlagArt.Draw/Patchesは維持し、ロボットの国籍・制服、設定見本、戦場旗の表示には陣営合成を広げない。ルールと所有国データは変更しない。

検証: 隔離ビルド警告・エラー0、25,974画素検証（大旗4形×小旗4形、輪郭外非描画、小旗以外のボス画素不変、3階層の中間省略、根の変更）。全16組合せの大サイズと36pxマーカーを実UiPainterで描画・目視。地星儀の実カメラでの追加目視は未実施。
