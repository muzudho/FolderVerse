# 2026年11月の開発日誌

[ドキュメント案内](../../../README.md) / [10月の開発日誌](10.md)

## 2026-11-01：配信プレイを受けて内政の見やすさを改善、画像制作は一時停止

配信や実際のプレイで寄せられた報告をもとに、開戦予約・パーツ表示・キャンペーン・操作メモを整えた。最後にCドライブの容量を調べ、画像制作に伴う会話履歴の肥大化が分かったため、征服者の画像更新を一時停止して本日の開発を終えた。

### パーツの状態を見分けやすくする

予約パーツには日本語の荷札を付け、Disabled時にも状態が分かるようにした。直送便で届く側は「予約」、送り出す側は「直送」と表示する。利用者から両方の荷札が見やすいとの確認を得た。

損傷パーツは全体をグレーへ寄せると所属色が分かりづらいため、斜め半分に元の色を残す表現へ変更。さらに、境界が整いすぎて模様に見えるという報告を受け、境界に不規則さとぼかしを加えた。製造レーンを増やせない場合の工場作業員予約の無効化や、F11で全画面から戻った際にウィンドウの枠を付ける改善も進めた。

### 開戦予約とエンディング

開戦予約では地図上の別の開戦可能地点を直接選び直せるようにし、目標と出撃可能地点をスポットライト表示する。対象外は35%暗くし、開戦可能地点の表示を残した。InvasionPlanningの検証は成功し、利用者から改善を確認したとの返答を得た。

手下を含む陣営での世界征服後、エンディングBGMがすぐ切れる報告を調査。ウィンドウが非アクティブになった際の停止が関係していたため、エンディングの音楽を継続するよう修正し、EndingFactoryUiで確認した。

### キャンペーンモード＃２「三国誌」

人間１人・コンピューター２人、２×２×２の地箱で始めるキャンペーンを追加。各国は隣接する２面、８ sectorsを持ち、３国で全６面を覆う。

キャラクター選択画面はキャンペーン＃１と共通化した。参加者一覧とキャラクター一覧の境界をドラッグで動かせるようにし、普段の少人数にも最大60人にも対応する。CampaignDuelで両モード24シード、60人とキャラクター60番の選択、540pでの境界移動と開始を確認。利用者から使いやすいとの確認を得た。

### チェックマークを作業メモとして広げる

地点の手動チェックを所属フォルダー・インスペクターにも表示。利用者の追加要望に合わせ、ツリー左側に専用の空き列を取り、階層に関係なく✅が縦一列に並ぶようにした。チェックのない地点を探しやすくするための変更で、展開ボタンの当たり判定も表示位置に合わせた。

直送便にもハンドルの×の隣へ✅ボタンを追加し、地図上のトラック／フェリーにも印を表示する。接続の両端を逆にしても同じ印として扱い、人間ごとのメモとターン終了時の解除に対応。DirectDeliveryUiの22フレーム検証は成功した。

左側チェック列への最後の変更後、通常のゲームプロジェクトのビルドは警告０・エラー０で成功した。今回の日誌作成では追加のゲーム起動やテストは行っていない。

### Cドライブの容量調査と整理

利用者の許可を受け、リポジトリのtmp内にある再生成可能な検証用bin/objを14フォルダー削除した。対象がtmp内に収まることと、追跡ファイル・セーブ・リンク先を巻き込まないことを確認。約5.55 GiBを解放し、その時点のCドライブの空きは約7.34 GiBとなった。原画、ソース、tmp/MobUi/outputは残した。

さらに、Codexの2026/10/09のセッション保存先を調べた。約10.75 GBのほぼ全部を１つの会話履歴が占め、全31,070行の集計では約6.49 GBが画像のデータURL、約4.16 GBがツール完了記録内のPNGのBase64文字列だった。前者には2,258件、重複を除いて1,760種類の画像データがあった。後者にも1,262件のPNGがあり、音声のBase64埋め込みは検出しなかった。全画像の人物特定はしていない。

会話履歴は原画ファイルとは別に画像を保持していた。画像IDと保存場所を分け、同じ画像を共有する設計案について利用者と相談したが、Codex本体側の対応が必要であり、既存履歴の画像を独自に置換・削除する作業はしていない。

### 画像制作の停止と次回

No.40〜60画像更新の定期実行（no-40-60）は、利用者の明示指示でPAUSEDに変更した。容量問題の解決と再開指示があるまで制作を再開しない。原画と制作記録は保持する。

停止時点でNo.53は通常１〜４が候補選択、通常５は瞳修正中。最後の眼部試作v011は白丸配置が改善した一方、半開きの目の開口が広がったため未採用。通常６・新聞８枚は未着手、No.53のゲーム採用は0/20。詳細は[人物別進捗](../../../../art-source/portraits/character-update-40-60-progress.md)に残した。

次回は利用者の指示から再開する。画像制作の停止は維持する。本日誌作成ではコミット・プッシュ・公開を行わず、ここで本日の作業を終了する。
