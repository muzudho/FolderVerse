# クロスファイア戦術と誤射の戦訓

2026-11-20利用者承認。無線連絡を前提とし、隊長と射手の距離上限や相互視認を要求しない。隊長はその場から指示し、焦点を観測する。攻撃・守備、陸・海の両方で使用できる。

## 成立条件と行動

- 行動可能で退却中ではない隊長１体と、同国の兵２体。兵はそれぞれ小銃の残弾があること。隊長が使用方針を持つこと。
- 隊長から焦点まで障害物がなく見通せる。任意角度の直線を通るマスを検査し、角に接する遮蔽物も視界を遮る。ユニットは視界の障害物に数えない。
- ２射手は焦点の水平・垂直方向に分かれ、通常の小銃で射撃できる。隣接射撃不可、既存の壁の方向制限・射線遮断を保つ。初期射線途中のユニットや焦点の味方を避けて組む。
- 焦点候補は敵の現在位置と、そのターンに既存AIが選んだ１歩先。予測移動は確定した未来ではなく、衝突等で外れることがある。遠い将来の到着まで待ち続ける動作は追加しない。
- 射手と隊長をその場に留めて照準し、移動解決後の同じ攻撃フェーズに射撃。隊長は既存の軍刀を振り上げる演出で合図する。
- 能力値・命中率・威力・弾薬への追加ボーナスなし。通常の同時射撃・盾・被弾処理を利用する。射線の状況や既存戦訓で片方が見送る場合もある。

国ごとの事前の使用方針はBattleTactics.UsesCrossfireへ集約。暫定配分はBaseId（0始まり）mod 6が1/2/4の30キャラクター。取扱説明書に使用する/しないを表示。既存の趣向や戦訓の自動獲得には置き換えない。人間の国も同じキャラクター方針を用いる。

BattleTurnResolverの通常自動行動でパターンを見つけた時に発動する。明示的なordersを渡す診断・手動行動では勝手に上書きしない。１射手は同時に複数の隊長へ割り当てない。

## 戦訓18：クロスファイアで味方を撃った

未取得では移動前の状況で照準を決める。合図後、同時移動で射線へ味方が入ると既存の射撃処理で誤射し得る。既存の戦訓3等で射撃が見送られる場合はその効果を維持し、誤射を強制しない。

実際にクロスファイアの小銃攻撃が味方を標的として命中した時だけ、戦訓18（131072）を目撃する。目撃対象は既存のWitnessと同じ戦場の活動中の兵・隊長。生き残り、物理ロボットのある目撃者が帰還して研究するまで所持にはならない。回避・空振り・敵への命中・通常射撃だけで18は獲得しない。通常の誤射戦訓3の目撃も既存どおり残る。

取得後のクロスファイア射手は、移動と衝突巻き戻しの確定後、実際の攻撃対象が味方になるか再確認する。その射手だけ発砲を見送るため、弾薬は減らない。安全なもう一方は射撃できる。通常の射撃AIに常時対策を付けない。

## 表示・保存

発動記録から画面下に戦術カードを表示し、隊長の合図を再生する。連続ターンの同隊長による発動ではカード再登場を抑える。既存の待ち伏せも、行動確定後のフレームと発動イベントのターン番号を合わせた。

国別使用フラグと戦訓ビットは保存する。古い保存にクロスファイアのフラグがなければ全OFF、既存戦場に追加しない。戦場の再生履歴は従来同様ターン境界セーブで省略。戦術カードと戦訓カードは別扱いで、戦訓18は研究画面・一覧で閲覧できる。

検証はtests/Crossfire。条件不成立・誤射・目撃と帰還研究・学習後の片側見送り・弾薬・保存を確認する。既存戦闘はtests/BattleRules、待ち伏せはtests/SiteDefenseで回帰する。世界征服への影響はこの局所検証とは別に固定DLLで測定する。
