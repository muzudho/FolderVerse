# 計略カード（初期３枚）

内政の共通入口として「城壁越しの出撃」「城壁への救援」「多地点からの集中攻撃」を追加。カードは既存ルールの用途変更・役割予約・開戦予約をまとめる。能力値や戦闘ルールは変更しない。

## 操作

- 左端のマニュアル操作で従来のプライマリーアクションを表示。使える計略がなく予約もないときは「計略がありません」と従来操作を表示する。
- 横スクロールのカード棚。通常は上部を表示し、マウスを合わせると横３：縦４に展開。選択中は操作欄と重ならないよう展開を止める。
- 目標地点→具体的な配置の２段階で選ぶ。各一覧６行とページ送りで10件を超える候補も表示。選択すると地図に地点・経路を表示し、左側にカードの淡い背景を置く。
- 「この計略を予約」で一括予約する。用途・ロボットの役割・開戦注文はまだ変更しない。
- 同じ計略を複数予約できる。予約一覧で選んだ１件だけ取消できる。取消は他の予約・手動操作に影響しない。
- 陣営のターン終了時に全予約を再検証し、全件有効なときだけ適用。無効なら部分適用せず理由を表示する。予約は保存・復元可能。

## 初期パターン

城壁越しの出撃は、敵に隣接する味方地点を城壁に、その背後を詰所にする。城壁に守備１体、詰所に選択可能２体以上が必要。詰所から１体を残して出撃予約する。既に守備予約された機体はそのまま利用し、確定時に解除しない。

城壁への救援は同じ前後配置で、後方の選択可能機体を迎撃予約にする（１体から可、複数なら１体を残す）。救援先への個別派遣を保証するカードではなく、実際の戦闘と共通の詰所迎撃分配が派遣先・到着時刻を決める。

集中攻撃は同陣営の２～３地点から同じ敵へ開戦予約する。現在の到達範囲で候補を求め、各出発地２体以上、兵数順で最大３地点、各１体温存。全ての部分集合を列挙するものではない。勝利を保証せず、プレビューで使用機体を確認できる。

中継地点・戦闘中地点・既存の地上開戦注文や施設移転と競合する地点は候補から除外。機体の出撃資格・戦訓による適格性・手動予約を維持する。クイーンを自動同行させない。
