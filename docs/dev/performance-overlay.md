# パフォーマンス表示

タイトルのスタートメニュー → システムメニュー、または内政中のシステムメニュー → パフォーマンス表示で有効にする。AUTO一時停止のメニューからも使用できる。最上部右寄りの半透明黒帯を全シーンの描画後に重ね、×で閉じる。表示状態は起動中だけ保持し、セーブやゲームの設定値は変更しない。

約１秒ごとの集計：FPS（実際のDraw呼び出し間隔）、平均フレーム間隔ms、最長フレーム間隔ms、更新CPU時間の平均ms、描画CPU時間の平均ms、うち地星儀のCPU時間の平均ms。更新が複数回ある場合は更新呼び出しごとの平均、描画は描画呼び出しごとの平均。停止・読み込みも最長値に含む。起動直後の最初の集計までは０。

描画時間は画面本体のCPU処理と描画指示の発行にかかった時間。GPU実行時間・GPU使用率・CPU使用率・画面提示完了は計測していない。ドライバー側の待ちがCPU呼び出しへ現れることはある。帯自身の描画は描画CPU平均に含めない。

地星儀はWorldPreview.Draw、大気、配備ロボット、CubeNet.DrawGlobeLayersを合算し、呼び出しが入れ子のときは二重計測しない。地星儀を描かない画面では次の集計窓で０になる。地星の生成、背景画像読み込み、その他UIは全体の更新／描画時間に含まれても地星儀内訳には含まれない。

60FPSの間隔は約16.7ms。FPSだけでなく最長値を見て、一時的な引っ掛かりを確認する。簡易表示の項目を切り替え、同じ位置・倍率で比較すると負荷の切り分けに役立つ。最初の画像読み込み直後と安定後は分けて観測する。
