# 仕掛品（WIP）

2026-11-21 実装。仕掛品は完成予定と同じ頭・胴・脚の占有範囲を持つ。通常パーツと同じ格納・輸送・組替経路を利用し、部位ごとに整数の加工済み工数/必要工数と消費済み原料量を保存する。表示は約分した有理数。未完成部位は暗めの表示と加工中の帯で区別する。仕掛品の間は戦闘・製造員・採取員・倉庫管理人に使えない。

## 中断と回収

製造プランの変更や製造しない選択、作業員の解除・採取員への交代で、加工済み品を元地点の廃品として残す。消費原料は返さない。部位への配分は各部位の工期比率に応じ、端数を決定的に割り当て、消費済み総量を保存する。単なる一時停止や出荷待機は中断品を増やさない。

既存のロボット回収・廃棄計画から回収を依頼できる。自分で放棄した仕掛品も回収依頼の対象。現地でポケットへ拾う既存経路も利用可能。仕掛具合・素材・国籍・結合・原料履歴は回収と保存で保持する。

## 分解・組替と加工の合成

通常ドラッグは既存の部位交換。部位と一緒に仕掛具合・原料消費履歴も移動する。一体型は従来どおり分離できない。

Shiftを押しながら仕掛品の同じ部位へドロップすると、加工をまとめる予約になる。同じ素材・国籍・必要工数と結合条件が必要。受け側を完成まで満たし、余剰工数と原料履歴は元側に残す。加工だけが完了しても必要原料を払い切っていなければ完成品にはならない。組替だけで原料や工数を増やさず、未完成の骨格も消さない。

組替/加工合成は内政予約。取り消し可能で、ターン終了時に確定する。

## 続きから製造

工場の各製造レーン左上の［再開］から仕掛品カタログを開く。格納庫にある仕掛品のうち、同じ部位・素材・結合の製造候補があるものを選ぶ。元からその候補のない工場では再開不可。ブリキは現在の製造候補に含まれず、再開可能にする変更はしていない。

選択は再開予約で、確定前に実物の格納庫在庫を動かさない。同じボタンの［取消］または直前予約の取消で解除できる。確定時に仕掛品をレーンへ渡し、加工済み工数/原料を引き継ぐ。参照元の作業員・所有国などが変われば予約を解除し、仕掛品を勝手に消さない。再開予約を置いた地点はCPUの製造管理・主要物流・施設移転から保護する。

部位ごとに残る加工を進め、その工程に必要な原料だけを追加消費する。完成した部位は再消費しない。仕掛品１個を完成させる処理なので、再開は１個で終了する。製造前から完成していた他部位も保持する。入荷枠待ちの間は追加消費しない。
