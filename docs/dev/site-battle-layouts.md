# 地点ごとの戦場配置

2026-11-20利用者承認。地星儀の地域の元の10×10ドットと地点の位置を使い、標準と比較できる戦場の違いを作る。元の地形ドット、交通路、資源配分、地点所有は変更しない。

## 判定

BattleSiteProfile.FromWorldで戦闘開始時の対象地点から選ぶ。地点全体のPointsの面積と外接矩形、Center周辺±2ドット（地域内のみ）の海・高山数、既存の谷判定を使う。地域境界の外側はこの判定には含めない。

| 配置 | 判定と特徴 |
|---|---|
| 標準 | 特徴がない場合。従来の海陸戦場と壁の基本間隔を保つ |
| 開けた平地 | 地点面積60ドット以上、他の特殊地形に該当せず、固定ハッシュで約1/3。地形の岩を取り除き、壁の希望半径を3→4マスへ広げる |
| 狭い通路 | 海岸・高山・谷に該当せず、地点面積12以下か外接矩形の短辺2以下。左右に岩を置き、壁の希望半径を3→2へ寄せる |
| 山の通り道 | 地点が高山、または周囲の高山が4ドット以上。既存の高山配置に通り道を残す岩を追加 |
| 谷の水路 | 既存のWorldTerrain.IsValleyが地点中心で成立。切れ目のある水路と岩を配置 |
| 海岸 | 陸地点で港、または周囲の海が4ドット以上。海ドットの偏る側へ水面を置き、旗は反対の陸側へ1マス寄せる |
| 浅瀬 | 海地点で周囲の陸が4ドット以上。近くの陸の側に岩を置く。それ以外の海は標準 |

判定優先順：海は浅瀬/標準。陸は海岸→山→谷→狭い通路→開けた平地→標準。港が面積1だから常に「狭い通路」になるような判定を避ける。海岸方向は周囲の海、浅瀬方向は陸への偏りから決め、偏りが同数なら固定方向を使う。細長い形の向きは地点の外接矩形から決める。戦場用の乱数列を消費して地形を選ばない。

閾値と配置は初回の調整値で、各種が同じ頻度になる保証はない。実世界3SEED（0/42/104729）では標準・開けた平地・山・海岸・浅瀬を確認。狭い通路と谷はその３世界の中心では出ず、制御fixtureで配置・保存・連結を確認している。

## 安全性と戦闘上の効果

新規の地点戦13×13で適用する。辺戦・多戦場に分けた野戦は従来のまま。隊の進入方向を別の方向へ強制せず、今回の実装では進入口の削減や援軍の遅延を追加しない。

配備候補・実配備位置・旗・進入口・進路・退却路・既存城壁を保護する。岩や水面を追加するたび、旗から全歩行可能マスへ到達できることを確認し、分断する候補は捨てる。追加は最大12マス。多軍戦では保護対象が多く、見た目の変化が減る場合がある。

岩は移動と射線を遮る。陸上の水路・海岸水面は移動を遮るが、小銃の弾は通る。海上の浅瀬の岩は従来の水面を岩に変え、射線を遮る。水に対する架橋や泳ぐ能力を追加しない。旗位置の変更・通り道・射線・壁の間隔によって攻守の相性が変わる。グレードによる壁の数4/8/12は変えない。希望半径は配備・進路の保護を優先するため厳密な円にはならない。

地形名・地点面積・近くの海/山のドット数・簡単な説明を戦場に表示する。地形の岩/水面は戦場と伝播表示の共通描画を使い、惑星色設定を保つ。

## 継戦・保存

SiteProfile、追加水面・岩の座標、適用フラグを保存する。通常の継戦は同じ戦場を保持する。戦場統合時は前の旗の座標・地形プロフィールを継承し、進路や配備を保護して配置を再構築する。再生成時には古い地形マスクを消す。適用済みの戦場へ重複して岩を追加しない。

古いセーブにプロフィールがなければnull・追加地形なしとして復元し、進行中の戦場へ新地形を勝手に追加しない。新しく起きる地点戦から対象になる。

検証：tests/SiteLayoutsは海陸4地形、適用可能プロフィール、2/4/13軍、通常木4/城壁4/12の180条件を検査する。3SEEDの地形選択、実キャンペーン入口、保存、継戦と再構築も確認。--uiで標準と特殊配置を共通描画で比較する。世界征服の勝率・収束への影響は別の固定DLL解析で測る。
