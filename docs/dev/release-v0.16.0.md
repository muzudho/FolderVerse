Windows x64向けの無料試遊版です。Assets の **FolderVerse-v0.16.0-win-x64.zip** をすべて展開し、**FolderVerse.exe** を起動してください。.NETランタイムを同梱しています。

- 内政の右上を整理しました。地星儀と展開図は絵で切り替え、表示ブレーカーと表示フィルターはレバーと双眼鏡で開きます。地点３区分と辺６区分の表示を切り替えられ、フィルターが有効なときは双眼鏡が点滅します。
- ３連スタンプ入りの紙をポップアップヒントとお品書き風のスタートメニューに採用しました。画面上側のヒントは下側に表示します。地星儀と展開図の［方向のロボット］は共通の **AxisBot** にまとめました。
- 倉庫管理人の頭・胴・脚の素材で、地点の格納庫数が変わります。格納庫数が減らない場合は、［組立］で管理人の部位を交換できます。コンピューター陣営も素材による増加枠を見て管理人を任命し、手持ちの余剰パーツやロボットで管理人を強化します。工場が必要とする原材料も輸送します。
- クイーンが交差点で足止めされるケースを改善し、領土０のクイーンに対する戦場での説得を追加しました。成功したときは国旗と配色が変わります。
- エキシビジョン中、ゲーム外でのクリックでシステムメニューが開く問題を修正しました。デモ、チュートリアル、ヘッドレス実行の点検も進めました。

倉庫管理人の変更が世界征服の収束にどの程度影響するかは、観戦と比較を継続します。
