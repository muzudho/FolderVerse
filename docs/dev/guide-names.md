# ガイドの名前生成

2026-11-21利用者承認。Guideは職業ではなく、各国でユーザーを案内する専属ポジション。案内係・ウェイトレスなどの職業、髪型・素体、国旗の色とは独立して名前を付ける。

## 元ネタ

身近な道具、手仕事、布・紙・陶器、文房具から、人名らしく聞こえる造語を作る。実在言語の正確な翻訳や実在人物を意味しない。征服者名の徳・美・希望・自然など、都市名の地理・集落語とは候補表を共有しない。音の一部が似ることまで禁止するものではない。

## 生成ルールと利用方法

`GuideNames.Generate(count, seed)`が「呼び名・姓」の文字列配列を返す。呼び名24種類×姓24種類の576組から、独立したSeedRandomで部分シャッフルして最大60名を重複なしで抽出する。再抽選ループを使わず終了を保証する。重複禁止はフルネーム単位なので、呼び名が同じで姓が違う人は存在する。

- 配列の添字を国のインデックスに対応させる。エントリー番号１なら添字０。
- 同じSEEDと人数なら同じ結果。人数だけ増やしても既存の先頭部分は変えない。
- 国名や征服者名を名前に付け足さない。素体や職業でも名前を変えない。
- ガイド専用SEEDに定数を混ぜた独立乱数を使い、ゲーム進行や地形の乱数を消費しない。
- 表示時は別の役割欄に「ガイド」、名前欄にフルネームを描く。短縮名は現段階では作らない。
- `WorldNames.Conquerors`を参考に候補表＋SEED方式を採用したが、人物画像のBaseIdには結び付けない。

内政ガイドへ組込済み。WorldSetup.Guidesに国ごとの名前配列・素体・既読状態を保存し、ロードのたびに引き直さない。詳細は[内政開始時のガイド](guide-runtime.md)。候補表を更新した将来版で既存ガイド名が変わらないよう、保存された名前を優先する。

## 検証

`tests/GuideNames`で７SEED（負数・int境界を含む）の60名重複なし、決定性、人数を増やした際の先頭保持、形式、別SEED、０名、範囲外入力を確認する。通常UIに新しい操作や表示は追加しない。
