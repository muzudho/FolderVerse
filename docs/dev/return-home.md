# ロボットの帰国先

2026-11-25 更新。人間とCPUで共通の帰国処理を使う。

## 帰国先

- 部位の国旗が最も多い国を優先する。同数の場合は、経路の辺数で近い国の軍用地点を選ぶ。未所属部位は国として数えない。
- 帰国先の征服者が電池を抜かれていれば、電池を抜いた相手を履歴から再帰的にたどる。現在の所属ツリーとは別に保存する。
- 対象国に軍用地点がない場合は、参加中のクイーンのポケットを目指す。クイーンが移動したら追いかける。
- 国旗から候補を得られない場合は、参加中の国の近い地点、地点のない国のクイーンを候補とする。ただし、脱落国の履歴不明を無関係な国への帰国で補わない。
- 古いセーブで電池を抜いた相手が不明な場合や、履歴が循環する場合は待機する。
- 帰国完了時にロボットの所属を受取国へ変更する。頭・胴・脚の国旗は変更しない。

## 予約と容量

全員の内政予約確定後、通常の配送・部品計画などの処理を先に行い、既存の配送開始処理の末尾で帰国を処理する。専用の画面や操作フェーズは追加しない。

- 出発前の帰国予約は低優先度。作業員・守備・出撃・輸送・組替・回収などの通常操作を妨げず、他の予約が優先される。
- 到着枠を確保できなければ、元の格納庫に残って出発を待つ。帰国先と同じ地点に既にいる場合は追加枠を要求しない。
- 出発時に既存の格納庫容量予約で到着枠を確保する。出発後は通常予約による上書き対象にならない。
- 帰国先変更時は新しい枠を確保してから古い枠を解放する。変更先が満杯なら既存の枠を保持して待機する。
- ポケットの貸出予約も空き容量に含める。地点への未完了の通常入荷予約は保守的に枠を見込み、帰国を優先させない。
- 他国を通過できる。戦闘中の地点・辺は通らず、通れるようになれば再計算する。既存の配送速度と、民間開放地点を通過する経路の扱いを維持する。
