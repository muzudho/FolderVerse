# ロボットの帰国先

2026-11-25 更新。

帰国先の国に有機能地点があれば、従来どおりその国の地点の格納庫へ帰る。自国の地点が１つもなく、電池の入ったクイーンが地図上に残っている場合は、そのクイーンのポケットへ帰る。

- 混成ロボットの帰国先候補は、帰れる国のうち部位国旗の数が最も多い国とする。未所属部位は国として扱わない。
- 帰国中もクイーンの現在位置を調べ直す。クイーンが移動したら追いかける。
- ポケットが満杯なら、ロボットを消したり容量を増やしたりせず、帰国中のまま到着を待つ。貸出予約などを引いた既存の空き容量判定を使う。
- 自国の地点ができたら、地点への帰国に戻る。クイーンが脱落し、ほかにも帰れる国がなければ帰国先なしとして待機する。
- 他国の通過、戦闘中の経路の待機、配送ごとの移動速度は変更しない。人間の予約とCPUの帰国予約で同じ帰国先判定を使う。

実装は `FolderVerse/RobotWorld.ReturnHome.cs`。新しいセーブ項目は追加せず、既存の帰国中ロボットの国・現在地点から行き先を再計算する。

NASの `archives/return-home-pocket-2026-11-25/` に隔離検証を保存。同地点到着、遠方到着、満杯待機と保存復元後に移動したクイーンへの追従、通常地点優先、脱落国の５シナリオ・15項目を確認した。元保存は変更せず、全体ターンは進めていない。世界征服への影響は別途解析する。
