# 戦闘結果新聞の実装

[表示仕様・編集方針](../ref/戦闘結果新聞.md)

NewspaperSelection.Score が評価し、Select が国の重複を抑えた安定順の戦場インデックスを返す。RobotCampaign.NewState で順位を記録し、戦闘後の領土変化による順位の逆転を防ぐ。Game1.BattleSummary は最大３件の写真記事と６件の短信を１枚に描く。

検証は tests/NewspaperSelection。番狂わせ優先、件数上限、全件掲載、安定順、入力非破壊を確認する。AUTOの紙面読了は従来の tests/AutoPlay も参照。

注意：駒数評価は結果時点の所属で集計する。説得による所属変更や継戦の増援を厳密に扱うには、将来、各区間の開始兵力も保存する必要がある。
