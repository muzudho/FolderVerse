# ロボットの装備数モード

新規ゲームの登場人物確認画面で装備数モードを選べる。初期値は旧仕様。世界と戦闘に記録し、追加フィールドのないセーブは旧仕様として読み込む。統計の `equipmentMode` は `Legacy` または `Materials`。

素材９種モードでは、存在する無傷の部位の装備値を３分の１単位の整数で加算し、装備ごとに最後に切り捨てる。部位や出身国による寄与の差は設けない。出撃資格や既存の所有・汚損処理は従来のルールを使う。現行の配分を採用し、ソフトビニールとシリコンの盾は当初の数値を使用する。今後の数値調整は試遊結果を踏まえる。

製造ラインは既存のレシピ枠に８素材を割り当て、地点とラインで並びをずらす。レシピ内の部品は同素材。メープルの暫定工期は１部品につき内部２刻み（表示では２／３産業ターン）加算する。ブリキは製造候補から外し、土地確定時に初期配置された単品のうち、別々の地点に頭・胴・脚を最大１点ずつ割り当てる。候補がない部位は出現しない。

[165通りの装備配分と重複一覧](robot-equipment-combinations.html)

同じ初期配置シードで比較する場合は `CpuConvergence --create-world <seed> <players> <save>` を２回使い、一方に `--materials` を追加する。この比較には装備計算に加えて素材製造と初期ブリキ配置の差も含まれる。
