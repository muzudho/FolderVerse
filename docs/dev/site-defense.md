# 地点守備・戦術・戦訓（2026-11-20）

戦場は物量と学習の違いが見えることを重視する。緻密な最適化を目的とせず、戦訓は無限ループや成果のない反復を減らす。新しい事前行動方針は戦術カード、実戦経験から得る改善は戦訓カード、地図で予約をまとめるものは計略カードと区別する。

## 城壁と通常地点

新しい地点戦では、城壁計画地点の開発済みTotalCapacityによるグレード1/2/3に対して壁4/8/12個を置く。守備専用ロボットの数では増減しない。壁に隣接する内側から外側への射撃を許し、逆方向は遮る。所属国による透過ではない。通常地点は木4個、海上は浮いた木製遮蔽物4個。木はどちら側からでも隣接射撃を許す。遠くからは遮る。城壁の海上版は浮体付きの壁。

旗・配備済みユニット・進入路・退却路を避け、通行可能領域の連結を維持する。海上の狭い多軍戦では甲板に隣接する水面へ浮体を置ける。浮体の元水面属性は保存し、設備継承時に復元する。既に進行中の戦場は設備を継承し、増援時に再建しない。旧保存の設備はそのまま維持する。

## 戦訓17：旗が危ない中、守備専用が旗から離れた

未学習の守備専用が、敵のいる旗から離れる移動を実行したとき、同国の兵・隊長が目撃する。生き残った目撃者が持ち帰り、研究して取得する。取得後の守備専用だけが旗付近・壁の内側・味方の援護を使い、追撃を抑えて持ちこたえる。能力値は増やさない。未取得の従来行動、一般兵への非適用、戦訓13/14の独立性を維持する。

## 待ち伏せ：戦術カード

事前入手に相当する使用方針を戦場開始時に国別に設定する。暫定配分はキャラクターBaseId（0始まり）のmod 6が0/1/2の30人が使用、3/4/5の30人は不使用。同キャラの外見差では変えない。取扱説明書に使用有無を表示する。キャラクター性の最終決定ではなく、後で配分を変更できる入口をBattleTactics.UsesAmbushに集約する。

条件を満たすと選択・確認なしで即時有効。学習・研究・消費は不要。対象は退却していない守備側の守備専用兵で、旗から4マス以内、木か壁に隣接し、旗が立っていること。敵が旗から2マス以内なら発動させず、既存行動へ戻す。

- 敵の正面・背面ではなく横に位置し、短剣なら隣接、小銃なら2〜4マスで実射線が通ればその場で攻撃する。
- 木・壁の向こう4マス以内の敵を待つ場合は、戦闘ターンmod 7が0〜2だけ待機する。3〜6は既存行動へ戻す。新しい無期限待機を追加しない。
- 遮蔽物まで移動して罠を準備する機能は今回含めない。既に使える配置を検出する。
- 弾薬・威力・命中・同時攻撃解決のルールは変更しない。

実AIが戦術行動を選んだときBattleEventへ記録する。手動指定行動では自動発動の記録を付けない。再生では連続する同ユニットの発動をまとめ、開始した戦闘ターンだけ画面下から0.22秒でカードをせり上げる。戦闘再生や操作を止めず、再生を戻せば同じ記録から表示する。保存には使用方針を含む。イベントは既存の再生用履歴と同じくターン境界セーブでは省略する。古い保存に使用方針がない場合は全OFFとし、既存戦場に戦術を勝手に付けない。
