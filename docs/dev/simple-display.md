# 簡易表示と計画地点の外観

内政地図の上部に簡易表示ドロップダウンを追加。チェックは非表示/停止を意味する。経番・緯番、赤道、配備ロボット、電池、煙、隣接オブジェクト、国旗をなびかせない、地形の高低差を無くすの８項目。他国は別ボタンを維持。既存４個の個別ボタンは集約し、ドロップダウン内のクリックとEscは地図へ透過させない。

隣接オブジェクトは既存NodeLandmarksの装飾。採取資源や施設・国旗そのものは隠さない。煙は製造重点型の煙突から４個の半透明粒を周期的に上昇・漂流・フェード。稼働状態の指標ではなく景観演出。国旗は地星儀の折れ面と展開図の縦ストリップをゆっくり変形、ボス/所有者の合成に同じ変形を適用。停止時は静止描画へ。

高低差はWorldTerrainの表示専用Reliefを0へ切替し地星儀メッシュ再生成。地形判定/埋蔵/交通路/セーブ上の地形は変更しない。設定は実行中の表示状態で、今回新しい永続設定ファイルは追加しない。直送便地図にも新表示フラグを共有。

屋根は製造重点型を３段の鋸屋根、採取重点型は切妻、中継は青灰色の平屋根へ。海陸とグレードの既存共有モデルを利用する。能力・費用・製造速度は変更しない。

検証: 隔離ビルド警告エラー0、簡/易/煙をUiFontへ追加してFontCoverage通過。８項目の往復入力、他国設定の独立、Relief=0/復元を実UIハーネスで確認。３屋根と２時点の煙・旗、８項目の一覧を描画・目視。低スペック実機の速度改善や全グレード全カメラ角度は未測定。NAS archives/diagnostics/simple-display-2026-11-21、tmp/delete-after-2026-11-21/simple-display。
