# 廃品回収：ロボット予約とポケット貸出

2026-11-22 実装。プライマリーアクションの［廃品回収］から使う。地点のタブは［ロボット廃棄計画］として廃棄専用にする。

## 操作の流れ

1. 地点またはポケットにいる、予約のない自国の完全体を選ぶ。素材・汚損による回収性能の差はない。仕掛品・解体中・他の仕事を予約したロボットは選べない。
2. 欲しいものを指定するか、なんでもよいかを選ぶ。到達できない品も候補に含めるか、良品だけか汚損可かも選ぶ。
3. 右ペーンのカタログで品を複数選択する。［地図上で表示］で位置を確認できる。
4. 帰還先とポケット貸出予定を確認し［回収に行かせる］。内政中は出発予約の取消が可能。全員の内政が終わると出発する。
5. ［回収班の状況］で現在地、目的地、積荷、残り予定、貸出枠を確認する。班をクリックすると回収・断念の履歴を読める。

左640×1080は既存の人物・地点背景・共通吹き出し、右1280×1080は選択・確認・状況表示。入力は画面内で消費し、背後の地図やボタンへ透過しない。

## 条件と品の単位

- 同じ欄の複数選択はOR、別の欄はAND。指定モードで空の欄があれば次へ進めず、全部選ぶ・全部消すが使える。
- 頭／胴／脚単品、頭胴・胴脚一体型、完全体、製造の仕掛品、解体の仕掛品、スクラップを区別する。
- 一体型は単品を代用しない。混成品では条件を満たす分解可能な部位だけを取る。完全体も選んでおり全体が条件を満たす場合は、完全体を１品として優先表示する。単品を探したい場合は完全体を外す。
- ［汚損可］は良品も含む。［なんでもいい］でも品質条件は有効。素材条件は指定モードで９素材から選ぶ。
- スクラップは素材選択の対象外で、量と滞留履歴を維持する。仕掛品は製造進捗・解体進捗・一体型のまとまりを維持する。

## 共有する12枠と帰還

- 征服者ごとのポケット12枠を全班で共有。本人１枠＋選んだ品の個数だけ、満枠単位で貸し出す。最大６班、１班だけなら最大11品（他の在庫がない場合）。既存の帰還留保とも容量を共有する。
- 地点から出たあとの元の格納庫は再利用可能。ポケットの予備枠には［貸出中／廃品回収班予備］を表示して移動先にできないようにする。
- 同じ品を複数班が狙ってもよい。それぞれ本人と品の枠が必要。現物は最初の班だけが取れる。後の班は断念理由を記録し、対応する未使用の荷物枠だけを解放する。
- 地点発は、本人と積荷を一緒に収められる出発地点へ帰る。満杯・到達不能ならポケットへ切り替える。ポケット発はポケットへ帰る。
- ポケットは移動した征服者を追う。手下でも同じ。脱落時は征服者が残る国（現在地の所有国、未所属なら出発地の所有国）の近い収容可能な地点へ向かう。本人の所属を強制変更せず、他国ロボットとして届くことがある。
- 帰還不能なら本人・荷物・予備枠を保持して待つ。経路が復活すれば帰る。
- 出発後の指示は［すぐ帰れ］だけ。内政中は帰還予約として取り消せる。確定すると未回収の予定を終了し、不要な貸出枠を解放する。一度帰還を始めた班は回収へ戻らない。

## 経路と自動行動

近さは辺数。障害がないと仮定した道路グラフの最短距離で次の品を選び、実際には戦場の地点・辺などを避けた経路を使う。最も近い品が到達不能でも先に試し、迂回できなければ断念して次を試す。１全体ターンに最大１辺進む。現在は他国すべてに国交がある扱いで通過可能。地星上へ荷物だけを置いて帰還完了とはしない。

CPUも実物の完全体を予約する。当面は国ごとに１班、ポケットの予備が足りる範囲で近い品を最大２個狙う。性能や征服への寄与の最適化は別の解析課題。

## 保存と旧セーブ

班、本人、積荷、対象、帰還予約、貸出トークン、履歴を保存する。旧セーブで新しいフィールドがなければ既定値を補う。画面を開く時またはCPUの内政計画時に旧方式を移行し、旧無料回収隊の積荷は現在地のカゴへ残してから無料回収隊を退役させる。旧APIは旧保存形式の互換・回帰のため残す。
