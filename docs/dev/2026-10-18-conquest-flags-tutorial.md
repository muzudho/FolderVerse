# 2026-10-18 順位・旗・チュートリアル勲章

- 順位は本人＋手下の完全支配セル数×100＋Entry No.、同セル数なら後の登録を優先。人数100以上の係数拡大は維持。関係図・新聞・エンディングも同じ共通順位。
- 世界征服状況の主紹介は下位から上位。上位の祖先の短い再紹介は維持。セルの塗りと手下の加算、顔とEntryの1.5秒待機後は筆算風の静止式、0.5秒後から順位4秒。変換の減算演出は廃止。
- 順位表示中にCharacterSelectionLayoutを再利用して顔面積を完全支配セル数に対応させる。ゼロセルは最小枠。開始前の担当者選択は操作に必要なので存続。
- 節戦の旗を倒した時点は残り10。以後10戦闘ターン、旗が戻らなければ守備側降伏。防衛は初戦開始から50、倒れたらリセット、取り返したターンは0で以後50を数える。辺戦・分割野戦には適用しない。従来の旗からの強制退去・旗上の攻撃側の戦意ペナルティーを廃止。
- 戦力消滅等の通常決着は残す。旗の時間決着でも生存した敗軍を破壊せず帰還させる。最後の旗奪取国が既に不在なら、その国へ領地を与えない。旗の進捗は戦闘状態・再生フレームへ保存し、旧オートセーブは新しい上限10/50と進捗0で復元。
- TutorialAchievementsはOS利用者のLocalApplicationData/FolderVerse/achievements.jsonへ解除日時を原子的に保存。autosave.json.gzと独立し、終了や新規開始で消さない。消去はtutorial-で始まる実績だけを対象とし、他の実績は残す。
- ステップ１の実績は予約でなく実際の攻撃側参加。勲章アイコンと達成表示、ステップ選択の獲得済み表示と消去ボタン。未解除かつ敵への有効な出撃予約がない時だけEndPlannedTurnを案内で止める。通常ゲーム・解除済み・予約済みには影響しない。
- 案内文：待った～！　ステップ１では、戦争の始め方を覚えてみましょう！　まず［開戦予約］ボタンを押して出撃を予約してから、［ターン終了］ボタンを押してください！

## 検証
