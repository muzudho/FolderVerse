# 2026-10-18 順位・旗・チュートリアル勲章

- 順位は本人＋手下の完全支配セル数×100＋Entry No.、同セル数なら後の登録を優先。人数100以上の係数拡大は維持。関係図・新聞・エンディングも同じ共通順位。
- 世界征服状況は７×５カレンダーの左上２×２が地図、その直下２×２が式、残り左下２×１が手下ツリー。地図は途中で移動・拡縮しない。式はセル・Entry・points・暫定順位の固定枠を最初から伏せ、本人・手下の集計が終わった後、セル数→１秒→Entry→１秒→points→１秒→順位→0.7秒→カレンダーの顔、の順に開示。顔は４秒待機し、次の紹介でもカレンダーに残る。主紹介は下位から上位、祖先の短い再紹介は維持。
- CharacterSelectionLayout.CreateOverviewは左２列を固定予約して、右５列×５行へ全人物の枠を先に確定。ゼロセルは最小枠。まだ紹介していない人物は顔を描かず、順位開示後に本人分だけ追加。開始前の担当者選択の操作は存続。
- 節戦の旗を倒した時点は残り10。以後10戦闘ターン、旗が戻らなければ守備側降伏。防衛は初戦開始から50、倒れたらリセット、取り返したターンは0で以後50を数える。辺戦・分割野戦には適用しない。従来の旗からの強制退去・旗上の攻撃側の戦意ペナルティーを廃止。
- 戦力消滅等の通常決着は残す。旗の時間決着でも生存した敗軍を破壊せず帰還させる。最後の旗奪取国が既に不在なら、その国へ領地を与えない。旗の進捗は戦闘状態・再生フレームへ保存し、旧オートセーブは新しい上限10/50と進捗0で復元。
- TutorialAchievementsはOS利用者のLocalApplicationData/FolderVerse/achievements.jsonへ解除日時を原子的に保存。autosave.json.gzと独立し、終了や新規開始で消さない。消去はtutorial-で始まる実績だけを対象とし、他の実績は残す。
- ステップ１の実績は予約でなく実際の攻撃側参加。勲章アイコンと達成表示、ステップ選択の獲得済み表示と消去ボタン。未解除かつ敵への有効な出撃予約がない時だけEndPlannedTurnを案内で止める。通常ゲーム・解除済み・予約済みには影響しない。
- 案内文：待った～！　ステップ１では、戦争の始め方を覚えてみましょう！　まず［開戦予約］ボタンを押して出撃を予約してから、［ターン終了］ボタンを押してください！

## 検証

BattleFlagSupplies：旗上滞在・通過、10ターン奪取、50ターン防衛、期限での取り返し・再計数、辺戦除外、フレームの進捗、セーブと旧形式、勲章の永続化・重複授与・限定消去。InvasionPlanning：実際の攻撃参加と予約・守備の区別、案内の制限条件。ConquestOverview：加算式・下位順・面積一覧・カーテン・退場フェード・プレイヤー状態不変。RelationsUi：同セル数のEntry優先、共通エンディング順位。AutoSave：再開と従来の保存項目。

BattleRulesの旗に関する旧期待値を新ルールへ更新した。増援と戦意の旧テストは軍ごとの戦意、盤外へ移る撤退処理に合わせた。ただし広範囲スイープはField辺戦、２軍×12体＋クイーン、seed4で1000ターン未決着となるため全体PASSではない。変更前HEADのResolverを別名で実行して同じ1000ターン後の未決着・全個体状態一致を確認。辺戦の永久反復は既存ルール上の可能性であり、今回節戦の旗タイマーで解消したとは扱わない。

No.39画像は [採用・旧版比較](../../art-source/portraits/characters/character-39/runtime-design-v001/index.html)。通常６枚×２セットと新聞８枚、計20配布先。生成原画・工程別プロンプト・旧画像・メタデータのバックアップを保存。内蔵image_gen使用。体格は承認v017参照で、3Dモデルから直接レンダリングしたものではない。

## 実績解除の見せるタイミング（追加）

プレイヤー１をHumanPlayersの先頭として、参加した戦場を最優先にする。現在の担当PlayerSlotの順序や、最初のフレームにまだ駒が出ていないことでは優先を落とさない。ステップ１の初回実績の対象となる攻撃戦場が複数ある場合は、その対象を最初に選ぶ。伝播中は授与を保留し、該当戦場の変身・盤面公開演出が終了した直後に保存して、図書館のモブの吹き出し「［開戦］を実績解除しました！」を3.5秒表示する。クリックやEnterを求めず自動で消える。吹き出し中は戦闘再生を保留し、操作の押し抜けを防ぐ。取得済み実績は再通知しない。

検証はRobotBattlePlaybackの待機兵を含むプレイヤー順、InvasionPlanningの変身前未授与・変身終了時の永続化・3.5秒で自動消去・入力遮断・再通知なし。UI検証はinvasion-ui-12/13でカットインと自動退場を描画する。

## 内政開始の案内とメッセージの読み返し

ステップ１の未達成時、内政フェーズの通常カットインが終わってから１度だけモブを表示し、「さあ、戦争の始め方を覚えましょう！　［開戦予約］ボタンを押してください！」と案内する。［チュートリアルを見返す］は開始案内・予約案内・実績解除の３メッセージを一覧から表示するモーダル。読むだけでは実績を解除しない。閉じる・Escで戻れる。世界征服状況の演出中はその終了を待つ。

InvasionPlanningで開始案内の待機・一度だけの表示、一覧の選択と閉じる操作を検証し、UIの14〜17で描画確認。ConquestOverviewではゼロセル・６人・20人のレイアウト境界・非重複、固定地図、５段階の開示と顔の保持、カーテンとフェードを検証。
