## 解析で比較する項目

初回実装では60人の主趣向を12種類の評価に対応づけた。第一候補が埋まっていれば、同じ評価で空きから次点を選ぶ。続けて取る地域は隣接を優先し、飛び地好きは獲得権が４以上なら最後の１枠で港か原材料のある飛び地を探す。表にある個別の代替条件と台詞は演出案。ゲーム内の台詞は趣向別の共通文と、キャラクター別の発話有無・タイミングを使う。

- 集計単位は趣向。候補が多い・少ない状況、第一候補を取れた・取られた状況も集計する。候補数は実数を記録し、配分を比較するときは選択順と残候補数を揃える。
- 同じ地星 SEED と初期条件で、趣向の割り当てを選択順やキャラクター間で入れ替える。土地選択の効果を調べる比較では、内政・戦闘の方針を固定する。
- 第一候補の確保率、代替方針への切替率、序盤の採取・製造の稼働、中盤の戦線拡大、終盤の前線補充、征服率と到達ターンを追う。比較の際は試行数と、上限ターンで未達の件数も併記する。
