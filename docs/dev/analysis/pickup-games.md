- 丸：軍用地点。色は所属木の根のボス。
- ×：民間開放地点。
- 上の白線：城壁。下の水色線：中継地点。
- 大きな丸：港または最終処分場。

`tools/PickupGame/Export-PickupGame.ps1` を使う。既存の診断用 `Program.cs` に観測処理だけを差し込み、元ハーネスとゲーム本体は編集しない。世界を再生成するのではなく、同じ初期セーブを使う。
