Windows x64向けの無料試遊版です。Assets の **FolderVerse-v0.14.0-win-x64.zip** をすべて展開し、**FolderVerse.exe** を起動してください。.NETランタイムを同梱しています。

- 内政開始時のガイドを追加。国ごとの名前と姿で、目標や操作の入口を案内します。
- ガイドと産業ルーレットを共通の人物レイアウトに統一。地点の背景、ルーレット部屋、楕円の吹き出し、ネームプレートと玩具風の仕切りを用意しました。
- 運否天賦の円グラフは２つのハンドルで操作できます。分布チャートは地点の最大容量に合わせて表示します。
- 地形と地点数に応じた初期の空き格納庫配分、国旗の揃い方による倉庫管理人の効果と配置予測を改善しました。
- 新聞を１トピック１面に整理。プレビューで面を選べ、最初に開く面はランダムです。
- 計略トレイと手動操作の切り替え、インスペクターの閉じる操作、絵本から宇宙が広がる表示、用途ボタンの選択・操作対象の区別を改善しました。

開発中の試遊版です。CPUの世界征服への収束は継続調査中です。400全体ターンでの解析打ち切りを非収束の証明とは扱いません。全画面・全セーブの互換性や全既存テスト成功を保証するものではありません。
