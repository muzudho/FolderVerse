## 2026-10-17 初回センタリング・方向ウィンドウ

世界構築完了後の初回内政で地星儀を表示し、現在地を GlobeAnchor にして中央へ寄せる。以後の内政では既存のカメラ復元を維持する。

Game1.OrientationControls.cs に画面正面基準の X（赤）・Y（緑）の十字と Z（青）の円周、各方向の＋／－を追加。1クリック30°、0.4秒の補間。展開図はロボットを隠し、円周の時計回り＋／反時計回り－のみ。旧左右回転ボタンは削除。

展開図の任意角度は CubeNet.ScreenRotation.cs の ScreenAngle と SpriteBatch 変換で描画し、節点位置・マス・小区画・面接続・ロボットバッジの入力も対応させる。保存状態に角度を追加。

切替途中の裏面は灰色。展開の最後は最終の展開図位置・角度・倍率へ補間し終えてから表示方式を切り替える。輸送・移動中の表示調整は切替前に済ませ、完了時の再フィットによる飛びを防ぐ。

通常ビルド／FeatureCheckビルドとも警告・エラー0。OrientationControls（現在地投影、6方向の30°回転と中間姿勢、12回の展開図回転、回転後の入力、角度復元、往復展開描画、裏面灰色画素）と NodeInspectorUi 成功。画像で方向操作の配置と展開途中を確認。

## 2026-10-17 方向操作の配置改訂

地星儀の軸線はロボット円の内部を横断させず、円外の上（緑Y）・右上（青Z）・右（赤X）へ短い棒として配置。各棒の同じ端に＋／－を対で置く。展開図の円周矢印は維持。姿勢リセットは円下の28×28の「正」へ移動し、ホバーで「頭を上へ、腹を手前へ」を表示。

世界構築・人物抽選・担当選択でも、描画と同じ領域に入力を対応。自動回転中は通常回転を継続し、選択軸の追加回転速度を4秒間のsmoothstep差分で変えて、合計30°の進み／遅れを作る。Y軸減速の最低速度は正で逆回転せず、終了後は0.3rad/sへ戻る。実行中の追加押下は消費する。静止画面と内政の30°・0.4秒回転は維持。

OrientationControlsで両符号の速度・積算角・通常速度への復帰・小型リセットを追加検証。内政・世界抽選・人物抽選の画像確認済み。

## 2026-10-17 奥行き軸・ゼロ・表示レイヤー

Zの斜め棒は撤去し、少し離した＋／－の間に直径約8pxの青点を配置。地星儀リセットは円下の「0, 0, 0」（ゼロは赤・緑・青）。展開図は円外に左右の回転矢印と＋／－、12時方向に青い0。0は回転だけを戻し、面接続・パン・倍率を保持。

上部の旧「地図記号」は「緯番・経番」と「赤道」に分割。前者は既存ShowMapSymbolsで座標ラベルを制御し、後者は新設ShowEquatorで地星儀・展開図・伝播図の赤道線だけを制御。ボタン背景のOn／Off兼用を廃止し、緑ランプ点灯／消灯で状態を表示。展開図の緯番・経番や切替・回転アニメーション中はグレーアウトし、設定を変えずクリックを消費する。

OrientationControlsで独立切替、使用不可時の入力、ランプの実画素、座標オフ時の赤道描画、外周ボタン、ゼロの回転・カメラ保持を追加検証。NodeInspectorUiも成功。地星儀／展開図の画像確認済み。

## 2026-10-17 ロボット・他国トグルと縮小しないパネル

Xの回転符号は維持して＋を下、－を上へ入替。自動回転の30°差は4秒かけていたため直後の変化が小さく、追加クリックも捨てていた。3秒の加減速へ短縮し、進行角を表示、連続クリックをキューへ入れる。通常Y回転の減速は逆転せず、各パルスの積算差は30°。

「赤道」の右に「ロボット」、「電池」の右に「他国」を追加。ShowRobotsは節点周囲の格納庫ロボットとクリック領域を両ビューで制御。ShowOtherCountriesは他国ロボット・電池・国セル色分けを制御し、自国と手下は保持。節点と交通路は開戦対象の選択用に残す。地形メニューの「自国・手下セル色分け」は削除し、国セル色分けと他国トグルの組合せへ統合。全体作戦は「ポケット」「移動予約」「調練」の順に横並び。

MapViewBoundsを表示・入力のクリップ領域、NetPanelを1840×820固定の投影カメラへ分離。パネルを開き始める時の地図左端を保存し、表示領域左端＋15pxがその位置へ届くまでは据え置き、その後だけカメラを右へ移す。閉じる時は逆順。位置の基準は開閉開始時に固定するため、開いた後のドラッグは相殺されない。開戦予約はOpenMovementWithFit(false)を使い、元のビュー・姿勢・倍率・面接続を保持。

OrientationControls（X位置・連続30°・独立トグル・ロボットの非表示とヒット領域・他国色とバッジ）／NodeInspectorUi（両ビューの不変倍率・15px・開戦予約のカメラ保持・パネル描画）／RobotTransport成功。全体作戦の横並び・表示切替の画像確認済み。
