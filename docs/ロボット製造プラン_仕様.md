# ロボット製造プランと土地選択表示

各節点は初期設定の種付き乱数で固定の製造プラン３つを持つ。製造するパーツと工期（ターン数）を掲示し、製造しない選択肢を加えた４択とする。複合パーツは基本工期が長くなる。工期そのものの自由な増減は廃止する。選択し直すと製造進捗と休業カウントを開始し直し、同じプランを押しても進捗をリセットしない。

休業計画は１～９回製造毎に１～９ターン休業。製造完了後の次ターンから指定ターン数を休み、休業中は製造進捗を進めない。製造数は格納庫に０～１２個の空きを残す設定で制限する。上限を超えて既にある個体は削除せず、新たな製造を待機させる。１２個空ける設定では新たに製造しない。戦闘中の節点と操作できない国の工場は従来通り変更できない。

組立・分解では自国と配下の個体を通常の背景で表示し、他国の個体の格納庫背景を暗くする。操作できない個体のパーツはホバー強調しない。土地征服フェーズには、現在土地を選択中の征服者の画像を表示する（人間・AI・デモ共通）。

2026-10-12 UI更新: 工期プランはパーツ絵柄付きの４枚のカードで選ぶ。カード内下部に『nターン毎に製造』を表示。休業の製造回数・休業ターン数と空き枠数はドロップダウンで設定する。展開図は右マウスドラッグでスクロールし、地星儀は右ドラッグで回転する。新規スクリーンショットはJSTの年月で Screenshots/yyyy-MM に保存する。既存画像は移動しない。

## 生産ライン（2026-10-12）

節点ごとに運否天賦で０～３本の生産ラインを決める。各ラインは製品プラン・工期・繰り返し回数・休業ターンを独立して持つ。図のロボットをクリックして製造プランを選び、繰り返しと休業は図中のドロップダウンで変更する。ベルトのお皿の横幅はロボット枠と同じ。格納庫の空き枠指定は全ライン共通で、同時製造でも１２枠の容量と予約空き枠を超えない。ライン０本では製造できない。

## 格納庫予約・作業員・海上の制限（2026-10-24）

[格納庫予約と工場作業員の仕様](ロボット格納庫予約_仕様.md)を追加。工場作業員１体につき空きレーンを１つ稼働できる。常設分と追加分を合わせ、陸上は３レーン、海上は１レーンまでとする。海上の２・３段目は海面表示。追加レーンには担当ロボットを表示する。予約個体は組立・分解の対象から外す。

## 製造レーンの現在位置（2026-11-02）

工場上部に全体の産業ターン累計を表示し、各レーンに周期内の進行数・次の完成までの産業ターン数・休憩中の残りターン数を表示する。生産部分は１台分の工期を表し、同じ区間をリピート数だけ繰り返す。完成位置は生産部分の右端の白い小目盛、現在位置はTickの中心に合わせた棒状の蛍光灯キャレットで示す。柱は濃い縁取りを付け、製品画像より手前に描画する。蛍光管は生産中が緑、休憩中が黄、空き枠待ちが赤、一時停止が灰色。蛍光管はゆっくり明暗する。横に広がる床の光は付けず、細い差し込み部分をTickの中心に合わせる。生産中の位置は周期進行数を工期で割った剰余とし、工期４・リピート９で進行数10なら２の位置となる。途中の個体の完成後は先頭へ戻り、最後の個体の完成後だけ休憩部分へ進む。空き枠待ちは剰余０に戻さず完成位置で止める。生産部分の終端ラベルは１台分の工期、休憩部分の終端ラベルはリピートと休憩を含めた周期全体の累計を示す。例えば工期６・リピート３・休憩１なら「０・６・19」と表示する。生産部分と休憩部分はそれぞれの表示幅に縮尺を合わせるため、両者の１ターンの画面上の長さは同一とは限らない。休憩中の蛍光管は黄色。休憩終了で周期の先頭へ戻る。

リピート数・休憩数の変更は現在の１台の工期進捗を保ち、休憩残りと休憩までの製造回数をリセットする。同じ値の再選択ではリセットしない。出荷待ちでは完成位置で蛍光灯が止まり、毎産業ターンに格納を再試行する。停止・戦闘などで処理対象外のレーンは全体累計が進んでも進行しない。ルーレット結果は１産業ターンずつ処理されるが、画面には処理後の位置を表示し、途中経過のアニメーションは行わない。

柱にマウスを重ねると「あとN生産ターンでロボットを製造できるよ」のヒントを表示する。休憩中は休憩分を含む残りを示し、空き枠待ち・一時停止はそれぞれの状態を説明する。プラン選択・ドロップダウン表示中はこのヒントを出さない。

## 順繰り格納・出荷待ち（2026-11-02）

先読みはしない。１産業ターンごとにレーン番号順で出荷する。格納済みの予約されていないパーツ１個体または２個体と製品を合わせて完全体にできる場合、空き枠に単独格納するより先に直接合体して格納する。候補は既存個体ID順とし、自国パーツ数の組立方針を満たすものを選ぶ。未完成で止まる途中合体はしない。候補がなければ空き枠へ単独格納する。自動組立を禁止している工場では直接合体しない。格納庫の帰還予約枠と工場の空ける枠数は合体後も守る。

後続レーンは先行レーンが同じ刻みに格納した個体を利用できる。既に処理したレーンを同じ刻み中に再試行はしない。出荷できないレーンは完成位置に留まり、蛍光灯を赤くする。出荷できなかった完成の刻みから待ち時間を数える。休憩中・一時停止・戦闘で処理対象外の間は増やさない。実際に出荷できるまで次の製造・休憩へ進まない。ヒントは「３生産ターンも待っていますよ！」のように表示する。成功・製造プラン変更では待ち数を０に戻す。休憩設定の変更では待ち数を維持する。待ち数はセーブし、待ち数のない旧セーブは０から数え始める。

## 1/3産業ターン単位（2026-11-03）

内部では1/3産業ターンを整数１単位として製造・休憩・出荷待ち・廃棄・累計を進める。ルーレットは分数の出目を含み、各盤面の確率合計100％、期待値は内部12単位＝表示４産業ターン。表示は「1/3」「2/3」「8+2/3」のように統一し、端数０は整数で表示する。工場で指定するリピート数・休憩数・空き枠数は整数のまま。休１は３単位分の休憩となる。

新規の通常正規プランは部位１つにつき内部４単位を基準とし、製品全体に工場固有の−２～＋２単位の補正を付けて固定する。正規完全体の基準は内部12＝表示４。安物プランは正規工期の半分を内部整数で切り捨て、最低１単位。作業員の影響で正規部位が安物になる場合は、その部位につき２単位短縮する（最低１単位）。一体型の短縮は１産業ターン（内部３単位）で、最低１単位を守る。

蛍光灯は1/3刻みで進む。床は１産業ターンごとの濃い色の太いTickと1/3ごとの白い細いTickを表示し、生産部分は１台分を繰り返す。長い区間の中略表示も維持する。出荷待ちは初回失敗から1/3、2/3、１……と増え、赤い蛍光灯のヒントにも同じ分数を表示する。

オートセーブ形式はバージョン２。旧バージョン１の工期・進捗・休憩残り・廃棄進捗・累計・待ち時間・ルーレット出目を読み込み時に３倍し、表示上の時間を保つ。リピート数や休憩設定値は３倍しない。既存の製造候補は工期を保ち、新しい工期生成規則で再抽選しない。

製造プランのカード下部と製造レーンの目盛りは、共通の帯分数描画部品を使う。品質名との区切りスラッシュと分数のスラッシュが重ならないよう、工期を縦組みの帯分数で描画する。整数部の右に分子・横線・分母を置き、品質名との区切りは空白とする。整数工期は整数のまま、１未満の工期は整数０を付けない。分子・分母は本文の90％の大きさとし、横線を少し上へ置く。数字の実際の描画範囲に基づいて上下の隙間を確保する。レーン下部の括弧は帯分数と重ならない位置へ下げる。状態文やヒントなど、他の時間表示は従来の分数書式を維持する。
