# フェーズ看板

2026-11-23。玩具の飾り像が付いたクリーム色の看板で、進行中のフェーズを示す。操作ボタンではない。

## 共通配置と表記

1920×1080基準で右ペーンの上端、x=696〜1116、y=0〜80を使用する。全画面の星抽選や戦闘画面も同じ位置・大きさを使う。地図操作の行（y=82以降）とシステムメニューに重ねない。画面サイズへの追従は既存のキャンバス変換を使う。

大きいメイン名と小さい差し替えサブ札を組み合わせ、「フェーズ」の接尾辞は看板には付けない。例：世界構築／星抽選、世界構築／征服者抽選、内政／作戦と準備、産業／製造レーン稼働、新聞／朝刊。旧固定テキストのフェーズ見出しを削除した。開始時の一時的なカットインや説明文中の用語は残す。

枠と像はPNG、文字はゲームのフォントで重ねる。文言変更時に原画を描き直す必要はない。主文字は最大0.68、サブは最大0.38で、枠幅に合わせて縮小。文字は濃い茶色、枠はクリーム色。内政画面では国の色の背板を薄い縁として加える。

タイトルとエンディングには適用しない。廃品回収・取引など内政内の専用操作画面や設定ダイアログは既存のナビゲーション領域を維持し、そこを別フェーズとして表示しない。

## 描画と切り替え

ガイド・産業・世界征服状況の吹き出しを看板の下へ移動した。新聞の日付・紙面表示と製造レーンの産業ターン表示は右側へ寄せた。産業から世界征服状況へのカーテンは、閉じる間は産業の看板を保持する。新聞へ移る際も、カーテンの下で新聞の看板まで切り替える。

透過PNGはロード時にRGBへアルファを乗算し、SpriteBatchのAlphaBlendに合わせる。透明部分のRGBが色にじみとして出ないようにする。像のアトラスは３列×３行、左上から世界構築・内政・産業／新聞・世界征服状況・戦闘／研究・伝播・外交。終了時にテクスチャを破棄する。

実装：FolderVerse/Game1.PhasePlaque.cs。実行素材：Content/Images/Ui/phase-plaque-frame-v001.png と phase-plaque-icons-v001.png。既存のImages/Ui/*.pngコピー規則で配布する。

## 原画と検証

内蔵imagegenで承認済みの立方体版イメージボードを参照し、文字なし共通枠と９種類の像を生成した。制作原画・透過調整前の版はNAS art-source/ui/phase-plaques-study-v001/runtime-v001/。採用した透過PNGと同名の実行素材をプロジェクトへ配置。生成プロンプトの記録は同フォルダーのproduction-notes.txt。
