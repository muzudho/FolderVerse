# フェーズ看板

2026-11-23。玩具の飾り像が付いたクリーム色の看板で、進行中のフェーズを示す。操作ボタンではない。

## 共通配置と表記

1920×1080基準で右ペーンの上端、x=680〜1240、y=16〜128を使用する。全画面の星抽選や戦闘画面も同じ位置・大きさを使う。表示ブレーカーは看板の右側、地図操作の行は右側のy=112以降に置き、システムメニューに重ねない。画面サイズへの追従は既存のキャンバス変換を使う。

大きいメイン名と小さい差し替えサブ札を組み合わせ、「フェーズ」の接尾辞は看板には付けない。例：世界構築／星抽選、世界構築／征服者抽選、内政／作戦と準備、産業／製造レーン稼働、新聞／朝刊。旧固定テキストのフェーズ見出しを削除した。開始時の一時的なカットインや説明文中の用語は残す。

枠と像はPNG、文字はゲームのフォントで重ねる。文言変更時に原画を描き直す必要はない。主文字は最大0.80、サブは最大0.46で、枠幅に合わせて縮小。文字は濃い茶色、枠はクリーム色。内政画面では国の色の背板を薄い縁として加える。

## 描画と切り替え

ガイド・産業・世界征服状況の吹き出しを看板の下へ移動した。新聞の日付・紙面表示と製造レーンの産業ターン表示は右側へ寄せた。産業から世界征服状況へのカーテンは、閉じる間は産業の看板を保持する。新聞へ移る際も、カーテンの下で新聞の看板まで切り替える。

透過PNGはロード時にRGBへアルファを乗算し、SpriteBatchのAlphaBlendに合わせる。透明部分のRGBが色にじみとして出ないようにする。像のアトラスは３列×３行、左上から世界構築・内政・産業／新聞・世界征服状況・戦闘／研究・伝播・外交。終了時にテクスチャを破棄する。

実装：FolderVerse/Game1.PhasePlaque.cs。実行素材：Content/Images/Ui/phase-plaque-frame-v003-cloud.png、phase-plaque-subtitle-v001.png、phase-plaque-icons-v001.png。既存のImages/Ui/*.pngコピー規則で配布する。

## 余白・中央揃えと表示拡大（2026-11-23）

利用者指定に従い看板全体の中心を画面中央x=960へ統一し、上端に12pxの余白を確保。枠を560×98、像を88×88へ拡大し、主名・サブ名は同じ中心線に揃える。全角の日本語を縦横同じ倍率で描画し、横幅合わせの非等方な伸縮は行わない。地図の操作行はy=112、高さ36へ寄せ、インスペクターの開始y=150より前に収めた。吹き出し、新聞の日付、戦訓図鑑の所有者名などを看板から離した。背景ロゴの開始位置はy=144。

併せて星抽選のApplyDaylightの配列範囲外例外を修正。地形は６頂点の面、樹木・資源模型は任意の三角形群であるため、生成時に地形部分の頂点数を記録し、タイル対応を地形だけに作る。模型は独自の色を維持し昼夜の色変化だけを受ける。ShowLandConquestでメッシュを差し替えた際も昼夜キャッシュを一致させる。

３頂点を含む模型の回帰ケースで、修正前DLLのApplyDaylight46行目のIndexOutOfRangeExceptionを再現。修正後は同ケースと３シードの星・土地プレビューを確認。PhasePlaquesの画面描画、看板と文字の中心・余白・像の正方形を検証。出力はNAS tmp/delete-after-2026-11-24/phase-plaques/ui-roomier/。
