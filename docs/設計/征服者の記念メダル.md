# 征服者の記念メダル

2026-11-23の利用者指定。展望台などの土産用の、名前を刻印できる薄い記念メダルを採用する。

## 表裏と材質

- 表面：現在の征服者の肖像を金属の刻印調に描き、外周へ名前を掘り込み表示。
- 裏面：FolderVerseの地星儀・ロボット・建物の意匠。
- １位は金、２位は銀、３位は銅、４位以下は白い反射のメッキ調。順位は既存の暫定世界征服順位を使う。
- 金属の地色と国旗の色は分ける。表裏とも外周の差し色に国旗の配色を使う。
- 名前は画像に固定せず、既存フォントの字形から影と反射を作る。カタカナ、濁点・半濁点、小書き、長音、中黒を扱う。

## 内政開始時の演出

内政の画面が見えるまで裏面で待つ。世界征服状況、新聞、ガイド、フェーズ見出しを終え、内政画面が見えるまで回転の開始を待つ。内政画面で裏面を0.3秒見せ、キランというチャイムと光を合わせて1.1秒で表面へ回転する。横を向いた部分には厚みと側面のギザギザをプログラムで描く。

同じ全体ターン・担当陣営でカメラを開き直しても繰り返さない。陣営や全体ターンが進んだ内政開始時に再度行う。音量は効果音設定に従い、デモ・自動操作の効果音方針も維持する。音声機器がない場合は描画を継続する。

## 素材と実装

実行素材は FolderVerse/Content/Images/Ui/souvenir-{front,back}-neutral-v001.png。built-in image_genで制作した無彩色・透過PNGを、実行時に金属色へ着色する。肖像は既存の人物画像を使い、メダル専用の描画で刻印調にする。通常の人物イラストは変えない。

原画・比較ボード・生成条件はNASの art-source/ui/conqueror-medallion-study-v001/。制作物一覧の art-source/ui/conqueror-medallion.html から参照できる。

共通実装は `src/Shared/ConquerorMedal/` に集約する。枠・円周の名前・顔のレリーフ・国旗色・順位別の金属・小型メダル・回転・効果音・キャッシュを含む。描画入口は対象の征服者と中心位置を受け取り、各画面が配置と表示対象を決める。内政開始の呼出しは `FolderVerse/Game1.DomesticCamera.cs`、内政の配置と表示条件は `FolderVerse/Game1.DomesticView.cs` に残す。

## 検証

SouvenirMedallionUiで、裏→側面→表、光、チャイムのPCMと再生トリガー、順位による４材質、透過、同一ターンの再開防止を検証する。ターン終了ボタンは通常96pxの２倍、192px。

CompactWarInspectorUiで、開戦パネルのメダルとの非重複と地図幅、125体を欠落なくページ分割すること、後半ページの実クリックと描画範囲、国旗の通常色を検証。

ConquestEntryCurtainUiで、産業から閉鎖を始める最初の画面と閉鎖途中に産業の表示を維持すること、完全閉鎖後の切替、入場中のスキップを画素比較する。

出力はNASの tmp/delete-after-2026-11-24/souvenir-medallion/。日本時間2026-11-24まで保持し、翌日から削除候補。
