# 最終処分場・解体・スクラップ

2026-11-21 利用者承認仕様。通常の新規ゲームに適用する。既存セーブとチュートリアルは、配置済み施設や処理中の荷を無断で変更しないため、従来ルールを保持する。

## 地点と施設

- 地点は地形上の場所、計画地点はその用途、施設は地点に備わる要素。
- 港と最終処分場は移転できない恒久施設。互いに同居せず、用途を変更できないランドマーク。
- 製造・採取・解体の作業員とレーンは、工場の施設移転に含む。
- 民間開放地点の格納庫は０。それ以外は１つ以上。ランドマークから全施設移転しても、恒久施設と１格納庫を残す。
- ランドマークの外観は、通常地点と同じく使用可能な総格納庫数（管理人を含む）で３段階。１～９、１０～１９、２０～３０。
- 最終処分場は新規世界に最低１つ。港・大渦付近を避け、穏やかな海にも配置できる。各国に１つずつ配る保証はない。暫定密度は適地ごとに1/40で、０なら適地から１つを選ぶ。
- 全地点の交通網は既存の接続修復処理でつながる。敵対国や戦闘による現在の通行不能まで解消するものではない。

## 解体レーン

［解体作業員予約］で完全体１体を任命し、１レーンを作る。札は［解体員］。素材による解体速度の差はない。専用の０～３上限は設けず、製造・採取のレーン枠とは別に任命する。工場を持たない中継地点では任命できない。

［解体予約］の付いた荷を順に解体する。頭１、胴２、脚２産業ターン、完全体は合計５。最終処分場や用途による速度ボーナスはない。製造の仕掛品も解体対象にできる。

解体中の荷は元の格納庫に保持し、移動・組替をロックする。開始時に格納枠を空けず、返却不能を防ぐ。完了時にスクラップ専用の置き場を確保できなければ、そのまま完了待機する。倉庫管理人の解除は既存の容量保護に従う。

作業員を解除しても、元の場所に［解体の仕掛品］と進捗が残る。製造の仕掛品とは区別し、戦闘・製造再開・通常の組替には使えない。別の解体レーンで続きを処理できる。作業から外れた解体仕掛品は、荷全体のまま直送便・長距離便で輸送でき、他のパーツへ合体できない。工場だけの施設移転でも、稼働中の荷と作業員を一緒に移す。

## スクラップ

何にも製造できない無害な荷。採取カタログには含めない。ロボットパーツの元の占有量の1/3に圧縮する。

| 解体する荷 | スクラップの量（格納庫比） |
| --- | --- |
| １部位 | 1/9 |
| ２部位 | 2/9 |
| 完全体 | 1/3 |

最小単位は1/9格納庫。束は最大1/3格納庫分まで合算でき、超過分を元に残す。Shift＋ドラッグで小分けする。量を整数の九分率で保持し、分解・合算で増減させない。通常の原材料の量（十六分率）とは単位が異なる。

スクラップが入った格納庫へロボットや他の原材料を同居させない。スクラップ同士は同居できる。空きの部位があっても、その格納庫へ完全体を入れられるわけではない。

## 最終処分場

ヒント：`１全体ターンで格納庫に置いてあるスクラップを自動処分してくれるよ`

全員の内政終了後、他の配送処理より先に、同じ地点の格納庫で１全体ターン経過したスクラップを除去する。合算した束でも入荷時期別の内訳を保存し、古い分だけ処分する。ローカルな小分けは滞在履歴を保持する。別地点へ出した分は、到着時から数え直す。

カゴの中身や回収班の荷は自動処分しない。

## カゴへの廃棄と回収

［廃棄（カゴ）］は内政中の予約で、全員の内政終了時に確定。キャンセルできる。１地点・１全体ターンあたり、ロボットパーツとスクラップを合計して１格納庫分まで。束を分けても量で制限する。超過する荷を勝手に小分けしない。

カゴは世界全体の放棄品一覧に位置とともに保存する。収容量上限は設けず、地点の征服・施設移転で中身を移したり消したりしない。スクラップも既存の回収班へ依頼できる。本人が捨てたスクラップも直接ポケットへ拾えず、回収班で戻す。

格納庫のロックを不要にする将来の仕様変更は、今回に含めない。
