# 地星儀・展開図のUIルール

2026-11-22 合意仕様。地星儀と展開図は同じ操作状態と配色を使う。

## 世界とHUD

世界の地形は基本的にイネーブルカラーで、朝・夜の照明を受ける。地形を操作可否によってディセーブルカラーにはしない。選択したオブジェクトの足元の１タイルだけハイライトカラーとする。複数選択はそれぞれの足元を強調する。選択解除・変更で通常に戻す。

HUDは世界に重ねる画面上の案内で、照明の影響を受けない。輪は大気・雲より後に合成し、色や明るさを薄めない。

輪は旗竿の一点ではなく建物の投影範囲を囲み、ズームと建物の大きさに追従する。引いた表示でも半径相当34×26論理px以上、主線幅4～7論理pxを保つ。海路の水色と混同しない金色～クリーム色の輪に、暗い縁取りと淡い外周を付ける。地形や建物を照らす光源として扱わない。地星儀の裏側に隠れた対象には輪を表示しない。

スポットライト、円の外側の減光、周囲の地形の暗色化、円の内側だけ夜の暗さを打ち消す処理は廃止する。

## オブジェクトの３配色

| 状態 | オブジェクトの配色 | HUD |
| --- | --- | --- |
| 操作の対象にできない | ディセーブルカラー | 輪なし。必要に応じて操作不能の理由を表示 |
| 操作の対象にできる | イネーブルカラー | 通常は輪なし |
| 操作可能でカーソルが合っている | イネーブルカラー | 明るい輪。濃淡がゆっくり移動する |
| 選択済み | ハイライトカラー | ホバーしていれば輪も併用 |
| チュートリアルでクリックを促す | イネーブル～ハイライトの緩やかな明滅 | 輪も同期して明滅。完全には消えない |

ディセーブルカラーは、国の色相を残しながら彩度を落とし、少し暗くしたもの。ハイライトカラーは色相を保って彩度と明るさを少し上げたもの。透明度は変えない。白や原色など色域の上限では安全に値を抑える。

建物・国旗・地点番号には同じ状態の配色を適用する。ホバーだけでオブジェクトを大きくしたり、ハイライトカラーへ変えたりはしない。

## 優先順位と状態更新

操作不能が最優先で、輪と注目の明滅を抑制する。選択状態が操作不能になったら、その選択は解除する。操作可能な対象では、選択済みのハイライトを注目の明滅より優先する。ホバーは配色・選択と独立したHUDの状態。

注目中の明滅は表示だけであり、点滅の位相でクリック判定を変えない。実際の入力・チュートリアル達成条件から毎フレーム導出し、クリック・達成・画面離脱で解除する。

## 地形タイル

選択地点の表示位置から、地形の10×10グリッド上の足元タイルを決める。画面上の円や投影位置でタイルを決めないため、地星儀の回転や展開図への切り替えでも同じタイルを強調する。

雪などの通常色は白の上限まで使い切らず、強調の明るさに余裕を残す。地形のハイライトにも昼夜の照明を適用する。夜でも位置を見つけられる案内はHUDの輪が担当する。

## 宇宙背景と描画枠

内政画面の宇宙背景は、インスペクターの開閉にかかわらず画面の左端から右端まで固定する。インスペクターを宇宙背景より手前へ重ねる。

地形・大気・雲は同じ地図表示枠で切り取り、宇宙背景の下の操作エリアやインスペクター側にはみ出させない。

## 開戦画面の補足（2026-11-23）

開戦のインスペクターは左上の850×520論理pxに収め、メダルの上で終わる。地図幅は922論理pxを確保する。ロボットが多い出撃元は48体単位でページ分けし、選択・ツールチップ・CPU／デモの指示を同じカード位置へ合わせる。

開戦画面の国旗は所属を確認する情報なので、対象の建物が操作不能でもイネーブルカラーを保つ。建物の選択可否と国旗の可読性を分ける。

## 他国同士の交通路の暗黒表示（2026-11-25）

表示フィルターの「他国と他国の地点間の辺」は、表示→暗黒表示→非表示の３値。初期設定および「初期設定に戻す」は暗黒表示とする。自国・手下と他国の辺は従来の危険表示を維持する。

暗黒表示では通常の道の形を保ち、陸路をダークグレイッシュイエロー RGB(103,97,61)、海路をダークグレイッシュブルー RGB(57,76,91)で描く。地星儀・展開図と面境界の接続に適用する。暗黒表示中は明るい景観用の破線・乗り物への置換を避け、道を控えめな色に揃える。ゲームの経路・通行条件は変更しない。
