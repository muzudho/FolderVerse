# 仕様　＞　ゲーム構成　＞　世界構築フェーズ


## 星抽選フェーズ

星のサイズ、地形（陸、海、高山）、港、交通路が決まる。  


## 世界征服者世代抽選フェーズ

登場人物と、各国の［権利のセル数］を決める。土地は未確定。  


## 世界征服者選択フェーズ

使用キャラクターを選ぶ。  


## 土地制服フェーズ

［権利のセル数］が多い国から土地を取る。  
同数なら抽選順。  
自分の盤では、ドラッグした矩形内のセルの選択を反転する。  
飛び地も可能。  


## 運否天賦フェーズ

ロボットが空から降る演出とともに、初期ロボット・輸送計画・工場・廃炉を抽選する。
