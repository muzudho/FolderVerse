# 仕様　＞　ゲーム構成　＞　世界構築フェーズ


## 星抽選フェーズ

星のサイズ、地形（陸、海、高山）、港、交通路が決まる。  


## 世界征服者世代抽選フェーズ

登場人物と、各国の［権利のセル数］を決める。土地は未確定。  


## 世界征服者選択フェーズ

使用キャラクターを選ぶ。  


## 土地征服フェーズ

［権利のセル数］が多い国から土地を取る。  
同数なら抽選順。  
自分の盤では、ドラッグした矩形内のセルの選択を反転する。  
飛び地も可能。  


## 運否天賦フェーズ

ロボットが空から降る演出とともに、初期ロボット・輸送計画・工場・廃炉を抽選する。  


## 以降

［内政フェーズ］へ進む。  



## 実装した操作（2026-10-12）

- 左ボタンの矩形ドラッグで表示中のセル中心を選択反転。飛び地も可能。右ドラッグで回転、ホイールで拡縮。
- 権利と同じセル数のときだけ確定できる。取得済みの土地は選べない。
- 権利の多い国から順番。同数はシードによる順番。自分以外は自動取得。
- 地形・交通路・港だけを表示し、生産性・ロボット数は表示しない。
- 配備は土地取得後に抽選。デモでは全員の土地選択を自動進行する。
