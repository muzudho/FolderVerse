# 仕様　＞　プレイスタイル


## 生配信

* ✅　生配信を考えている。
    * これは定義。


## ２０分で楽しめないといけないゲーム

* ✅　配信者の努力により、１プレイは２０分で楽しめないといけない。
    * １つの放送枠で終われるから。
* ✅　［プレイ時間制限］とは相性が悪い。
    * ターン制ストラテジーゲームなので、いくらでも待てるから。
* ✅　強制［エンディング］ボタンを付ける。
    * いつエンディングにするか、配信者が確定できる。
* ✅セーブ機能とか持たない。
    * 毎回、新規ゲーム開始をする。
    * `SEED値` という再現機能があるが、デバッグ用。仕様が変更されたら、無効になる。


## １人用ゲーム

* ✅　１人用ゲームである。
    * ✅　なぜなら、対戦ゲームではない。  
        マージャンでも、４人集まってスピーディーなゲームにしようとしたら、  
        牌を切るだけで精一杯になる。
    * ✅　なぜなら、通信機能は持たない。  
        サーバーを用意するとお金が掛かるから。
