# 仕様　＞　戦闘　＞　ロボット性能


## パーツの所属国と損傷（2026-10-15）

頭・胴体・脚は、元の所属国と損傷の有無を独立して保持する。損傷しても所属国の記録を書き換えない。

- 損傷中のパーツは、所属判定・自国パーツ数・装備性能・調練・自動組立・在庫判断・国別の色表示では未所属として扱う。
- 分解、組立、格納庫内のパーツ移動、部分輸送で所属国と損傷を引き継ぐ。
- 新規および損傷情報のない既存データは全パーツ損傷なしとする。
- 内部の損傷フラグを解除すれば、記録された所属国として再び判定する。修理操作は今後の仕様で定める。

今回の実装はパーツ状態とその判定の土台。戦闘でどのパーツを損傷させるか、倒れたロボットの帰還先の確保、勝利後のスワップ順位と交換処理は、続く仕様決定で実装する。
