# 仕様　＞　戦闘　＞　ロボット性能


## パーツの所属国と損傷（2026-10-15）

頭・胴体・脚は、元の所属国と損傷の有無を独立して保持する。損傷しても所属国の記録を書き換えない。

- 損傷中のパーツは、所属判定・自国パーツ数・装備性能・調練・自動組立・在庫判断・国別の色表示では未所属として扱う。
- 分解、組立、格納庫内のパーツ移動、部分輸送で所属国と損傷を引き継ぐ。
- 新規および損傷情報のない既存データは全パーツ損傷なしとする。
- 内部の損傷フラグを解除すれば、記録された所属国として再び判定する。修理操作は今後の仕様で定める。

## 戦闘後の損傷・帰還・スワップ（2026-10-15）

- 倒れたロボットは戦闘結果の確定時に頭・胴・脚から等確率で一か所を抽選する。短剣と小銃は同じルール。戦闘の乱数に従い再現可能。
- 当たったパーツを損傷状態にする。既に損傷していれば追加損傷なし。パーツもロボットも戦闘で廃棄しない。最後の自国パーツが損傷すれば戦闘に出せなくなるが、格納庫には残る。
- 出撃時に個体ごとの元の節点またはポケット格納庫へ帰還枠を予約する。生産・輸送・分解・ポケット移動は予約枠を埋められない。同じ国の複数節点からの出撃も個体別に帰る。
- 倒れた個体と退却個体、敗者は元の格納庫へ帰る。元の節点が奪われても帰還先を失わない。退却だけでは損傷しない。
- 勝った進駐個体は目的地に空きがあれば入る。満杯なら現地のロボットを元の格納庫へ持ち帰って交換する。持ち帰る側から見た損傷していない自国パーツ数が多い順、同数なら個体IDの小さい順。持ち帰る個体は所属国情報を保持し、運用上の所有者を勝者にする。
- 同じ戦闘で今回進駐する個体、廃炉処理中・組立予約中の個体は交換対象にしない。交換候補がなければ元の格納庫へ戻る。ポケット出撃個体は勝ってもポケットに戻る。
- 損傷したパーツはくすんだ金属色にし、格納庫の図では塗装が剥げた斑点を重ねる。格納庫に損傷表示と、パーツのホバー説明を付ける。

修理の操作・費用と武器別の損傷特性は未実装。現時点で戦闘は廃炉の代替にならない。
