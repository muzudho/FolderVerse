# 仕様　＞　戦闘　＞　戦場カメラマン女


## 優先して新聞に載せる戦闘

全ての戦闘が新聞に載るなら載せる。  
そうではない場合、  
以下の条件に［何点］かを付け、その総得点が高いものから新聞に載せる。  
写真を載せず、文字で情報だけ載せるケースもある。  

* ランキングの下位１／４にいる［征服者の女の子］の国が、  
  ランキングの上位１／４にいる［征服者の女の子］の国を敗退させた戦場。（番狂わせ）
* ランキングの上位１／４にいる［征服者の女の子］の国が１国以上参加している戦場
* ［クイーン］が参加している戦場
* ［継戦］している戦闘。
* ３国以上が参加している戦闘。（国の数が多いほど優先）
* 参加している総［駒］数が多い戦闘。
* 参加駒数が多い方が負けた戦闘。（意外性）
