# 仕様　＞　キャラクターグラフィック　＞　作品統一感

整理日：2026-10-18  
位置付け：作品共通の描画仕様・横展開用指示書。過去の利用者の指示を整理した初版。新しい完成画像による一式の適合確認はまだ行っていない。

## 1. 目的

キャラクターの顔、手、表情、持ち物がゲーム画面で読み取れ、同じ作品の人物として見えることを目的とする。

「この生成画像から目を何倍にする」という修正手順ではなく、完成時にどう描かれているべきかを定義する。手描き、画像生成、3Dモデルからの描画のいずれにも共通して適用する。

写実的な物体形状や照明の正しさより、キャラクターの視認・識別性を優先する。物理的には誇張された頭身、輪郭、ハイライト、反射光も、作品内で一貫して使う。

文章だけで誰が描いても完全に同じ画像になるわけではない。再現性を高めるため、本書の完成条件、承認された参照画像、測定基準、縮小表示での比較を組み合わせる。

## 2. 制作時に必ず組み合わせる三つの資料

| 資料 | 決めること | この資料から転用しないこと |

| 本書：作品統一感 | 線、目の表現、髪の光、色面、陰影、奥行きの演出 | 個々の髪型、衣装、瞳色、性格 |
| むずでょ監修プロポーション | 頭・胴・手足の比率、短い首元、関節配置 | 参照役の王女の顔、髪、衣装 |

## 3. 完成形：線と色面

### 3.1 輪郭線

- 衣服・帽子・手袋は、外形を黒いドローイングペンで描いたような、明瞭でソリッドな線にする。
- 一番外側の線を相対的に太くし、内側の縫い目・装飾・形状線は細くする。全てを同じ太さの黒線にしない。
- 前髪の外形、虹彩の輪郭、睫毛は、細いペンで描いたような線を使う。服の外形と同じ太さにはしない。
- 持っている玩具も最外周を太めの線で区切る。内部は形や材質が分かる陰影で表し、細部を全部太線で囲わない。
- 線幅の絶対ピクセル値はまだ未確定。大きい原画だけでなく、実際のゲーム用サイズで外形が残り、顔の線が潰れないことを確認する。

### 3.2 衣服の塗りと陰影

- 作品の玩具らしさを共有する、厚みのあるソリッドな色面とセルアニメ調の陰影を基本とする。
- 衣服の主要な色はソフトカラーを基調とし、影はダークトーンで明確に区切る。ただし、個別設定の紺・黒・赤などの固有色を勝手に変更しない。
- 衣服の明部・暗部が判別できる構成にする。過去の指示では影を約5割まで増やしているが、これは当時の衣服の見え方の目安であり、顔・背景を含む画面全体を一律50％暗くする指定ではない。
- 陰でない部分には、うっすらした光沢のグラデーションを入れてよい。明暗の境界までぼかして、全体を連続的な写実塗りに戻さない。
- ファー、編み物、金属、髪などの固有材質は残す。玩具らしい統一感を理由に、人体や全素材を同じプラスチックへ置き換えない。

## 4. 完成形：目・肌・睫毛

### 4.1 「目の大きさ」と「瞳の大きさ」を区別する

本書でいう「目の縦幅」は上瞼と下瞼の間の開口高さ、「瞳の横幅」は虹彩の左右幅を指す。瞳孔は虹彩中央の別の構造であり、混同しない。

- 虹彩は横に広がりすぎない、縦方向を感じる楕円形にする。虹彩の横幅を細くし、白目が読み取れるようにする。
- 虹彩の一番外側は、細いドローイングペンで引いたような繊細な輪郭線にする。
- 肌は、白目と区別できるライトトーンにする。白目と肌を同じ白さへ飛ばさない。褐色などの固有の肌色は保持する。
- 全員を同じ大きな目にしない。共通の描画方式の中で、個別設定の目つき・分類を維持する。

過去の共通化指示にある分類：

| 分類 | 基準となる開いた目の縦幅に対する目安 |
|---|---:|
| 細目 | 0.5 |
| ふつう | 1.0 |
| 大きな目 | 1.3 |

この分類は目の開口高さについてのもの。虹彩の横幅を0.5倍／1.3倍にする指示ではない。基準となる「ふつう」の測定用見本は、今後一枚選んで固定する必要がある。現時点でNo.39を含む全員の分類を本書から新規に割り当てない。閉じ目、ウインク、眼帯、渦目なども元の設定を維持する。

### 4.2 瞳のハイライト

- 主ハイライトは、瞳の斜め上側にある大きな白い丸。初期の指示では右上。
- 主ハイライトを虹彩の斜め上側の輪郭に接触させ、輪郭の短い一部を白抜きで途切れさせる。単に虹彩の中央へ白点を置くだけにしない。
- 反対側の斜め下、初期の指示では左下に、小さな丸い補助ハイライトを置く。
- 主と補助の大小差を明確にする。過去の「主ハイライトを2倍」は明瞭さを増す修正履歴であり、新しい絵に毎回2倍を掛け続ける指定ではない。
- **白点は目の開口内でトリミングする。肌・瞼・睫毛へはみ出さない。** 虹彩の線を白抜きすることと、目の外へ飛び出すことを区別する。
- 閉じた目や眼帯の下に、見えない虹彩やハイライトを追加しない。
- 主ハイライト径を虹彩径の何％とするかは未確定。承認した画風見本から採寸して決める。独自の割合を確定仕様として追加しない。

### 4.3 睫毛

- 上睫毛は細いドローイングペンのような線で、上向きにカールする線をおおむね3本見せる。
- 下睫毛は上より短く、極細にする。
- 下側の目尻に、上へ跳ねる細い毛を1本入れる。
- 縮小時に黒い塊へ潰れたり、全員の目つきを同一にしてしまったりしないようにする。

## 5. 完成形：髪のハイライト

**毛の流れに沿った縦筋ではなく、頭部の球面を回る横方向の光の帯を基本とする。**

- 頭を球体として捉え、その丸みに沿ってハイライトを横へ走らせる。
- 帯の上辺と下辺を揃え、おおむね一定の幅を持つ、意図的・機械的な形にする。
- 帯の白い部分は、はっきり白く飛ばす。細い自然な光沢線を大量に足すだけで置き換えない。
- 毛束の境界や髪型に応じて帯を分割してよいが、全体として同じ球面を回る帯に読めるようにする。
- 「横方向」は画像の水平線へ直線を貼る意味ではない。頭の傾き、向き、球面に追従する。
- オールバックでも、頭頂を横切る弧として成立させる。
- 三つ編み・カール・前髪の固有の形を、帯を作るために消したり別の髪型へ変えたりしない。

最初の履歴には縦のハイライトを太くする指示もあるが、その後に横方向の帯へ変更されている。現在の共通指定は後者。

## 6. 完成形：顔と首元を際立たせる影

- 顔は比較的平面的な色面として読み取らせ、前髪はそれより立体感のあるものとして描く。
- 前髪から顔へ、帽子から下の部分へ、重なりを感じるドロップシャドウを落とす。
- 顎から首にも影を落とし、顔の輪郭を際立たせる。
- 首元が暗くなって沈む場合、襟は演出的な光で明るくしてよい。現実の光源だけに拘束されず、顔を読み取りやすくする。
- この影のために首を長くしたり、鎖骨を下げたりしない。短い首元は最新プロポーションを維持する。
- 目を前髪の影で隠すモブ専用の指示を、征服者全員へ適用しない。

## 7. 完成形：後ろ髪の空気感・境界の遠景効果

ここでいう「空気感」は、背景をぼかすだけの処理ではない。**髪と首・肩・腕・服が重なる境界付近に、奥行きと分離を感じさせる色を局所的に入れる描画処理**である。

### 7.1 適用する場所

- 首・肩の後ろを通る髪。
- 腕の後ろへ回る髪。
- 顔から離れた部分で、暗い服と暗い髪が重なって同化する境界。

後ろ髪全体を遠景色へ染めない。効果の面積は小さくし、境界の周辺に限定する。長髪の外形や毛先は残し、髪が消えてショートヘアーに見える状態を避ける。

### 7.2 色と明るさ

- 明るい髪では、奥へ行くほど少し色が抜け、淡い水色などの遠景を感じる色へ寄せる。
- 遠景色はキャラクターの配色に合わせて変えてよい。全員へ同じ水色を貼らない。
- 暗い髪では夜景のような暗い奥行きを使い、接する首・肩・腕側へ反射光を入れる。
- ただし暗い服と暗い髪が同化する場所は、暗い効果を重ねず、明るい境界効果で分離する。
- 顔の色や服の色との関係を見て、明暗の差が残る色を選ぶ。髪の固有色そのものは保持する。

### 7.3 共通規則にしない個別指定

「太い毛束と隙間で奥行きを出す」というNo.7の修正は、共通の奥行き表現を考える参考にはなる。ただし、No.7の一房を肩前へ出す髪型やNo.9の短い後ろ髪は個別設定であり、全員へ転用しない。本書の境界効果と、特定人物の髪型変更を混同しない。

## 8. 構図・小物・ゲームサイズ

- 顔、手の表情、キャラクターを識別する装飾・小物を読み取れる構図にする。
- 背景は人物を説明するが、人物の髪やファーと同化しないように距離・コントラストを整理する。
- 遠い背景と、後ろ髪へ局所的にかける遠景効果は別々に指定する。
- 通常のゲーム用画像は256×192、新聞用は300×400。新聞はゲームでグレースケール化されるので、色相差だけに依存せず明度差で顔・髪・服を分離する。
- 原画の拡大表示だけで判断せず、出力サイズと、実際の丸い顔枠などのトリミングでも確認する。顔や識別用装飾が切れないようにする。
- キャラクターが持つ玩具には、明瞭な外形、ソリッドな色境界、形が分かる陰影を使う。動物の生体表現と玩具表現は個別設定に合わせる。

## 9. 元絵からの倍率を、完成形の基準へ置き換える

| 過去の修正表現 | 横展開するときの扱い |
|---|---|
| 頭・手・足を何倍にする | 最新承認のプロポーションの見た目を転用する。倍率を累積しない |
| 瞳を細くする | 白目が読める縦長の虹彩として定義する。眼球・目の開口・瞳孔と区別する |
| 上側ハイライトを2倍 | 大きな主ハイライトと小さな補助、接する場所、トリミング条件を指定する |
| 髪のハイライトを太く | 頭部の球面に沿う白い横帯という形と方向を指定する |
| 後ろ髪へ遠景効果を追加 | 首・肩・腕・服との境界周辺に限る、面積の小さい奥行き処理として指定する |
| 飾りを拡大する | 最新プロポーションの前方中央から側端・後方へ弱まる規則を使う。旧倍率を再適用しない |

参照画像は「本人の意匠」「体格」「画風」の役割を明記する。一枚で全ての条件を満たしていない場合、用途ごとに複数の参照を渡す。

## 10. 横展開用の制作指示ひな型

以下の共通部分に、対象キャラクターの固有設定と構図を足して使う。未確定の目の分類などは、既存の承認設定を確認してから記入する。

```text
【目的】
ゲーム画面で顔・手の表情と人物の識別性が高く、同じ作品の絵として見えるキャラクター画像を制作する。

【参照の役割】
A：対象人物の承認済みキャラクターデザイン。顔立ち、瞳色、髪型、肌色、衣装、装飾、小物を保持。
B：最新のむずでょ監修プロポーションv017。大きな頭部、短い首元、大きな手足、高い膝位置を転用。Bの王女の顔や衣装は転用しない。
C：作品共通画風の承認見本。未選定なら本仕様の各条件を使い、見本が確定済みだと扱わない。

【共通画風】
厚みのあるソリッドな衣服の色面とセルアニメ調の陰影。外形は黒いドローイングペンのように明瞭に、内側の線は細くする。衣服の影はダークトーン。明部には控えめな光沢グラデーションを許す。
虹彩は白目が読める縦長の楕円。輪郭と睫毛は細いペンの線。目の縦幅の分類は本人の承認設定を維持。
瞳の斜め上に大きな白い丸、反対側の斜め下に小さな白い丸。上の丸は虹彩輪郭に接し、その短い一部を白抜きで切る。ただし全て目の開口内に収め、肌・瞼・睫毛へはみ出さない。閉じ目・眼帯へ虹彩を追加しない。
上睫毛は細く上にカールする線をおおむね3本。下睫毛は短く極細、下の目尻に上へ跳ねる線を1本。
髪のハイライトは毛流れに沿う縦筋ではなく、頭部の球面を回る横方向の白い帯。帯の上下辺と幅を揃え、頭の傾きと髪の立体に追従させる。
前髪・帽子から下へ、顎から首へドロップシャドウを落とす。襟は顔を際立たせる演出的な明るさを与えてよい。首や鎖骨の隙間を増やさない。
首・肩・腕の後ろを通る髪の境界だけに小面積の遠景効果を入れる。明るい髪は淡い冷色寄り、暗い髪は暗い奥行きと接する部位の反射光を基本とし、暗い髪と暗い服の境界は明るく分離する。色は本人の配色に合わせる。後ろ髪全体を染めず、長さや毛先を消さない。背景ぼかしで代用しない。
玩具は最外周を太めに区切り、内部は材質と形が分かる陰影を使う。

【固有設定】
対象人物、目の分類、表情、髪型、衣装、装飾、小物、変えてはいけない特徴を記入する。

【構図と出力】
用途、画角、ポーズ、背景、縦横比を記入する。顔と手を読み取りやすくする。過去の拡大倍率を再乗算しない。指定していない人物の意匠を混ぜない。
原画と生成・制作条件を保存し、通常256×192／新聞300×400、必要な顔枠トリミングと白黒表示で確認する。
```

### 10.1 横展開を始めるときの手順

1. 本書、最新プロポーション、対象人物の個別設定を読み、使う画像ごとに「意匠／体格／画風」の役割を記録する。
2. ひな型へ、用途・ポーズ・表情・縦横比を記入する。過去の修正履歴をそのまま連結せず、現在の完成条件として指示する。
3. まず代表の一枚で確認する。顔と手が見える構図を選び、明るい髪・暗い髪で処理が異なる場合は、その違いも比較する。
4. 第12節の確認項目で原画とゲームサイズを見比べる。未達は「虹彩」「髪の帯」「境界の遠景効果」など部位ごとに記録し、体格と画風を別々に確認する。
5. 確認した制作条件を他の構図へ展開する。完成した各画像も確認し、一枚の成功を全画像の適合として扱わない。

制作記録には、対象人物・用途、参照画像のパスと役割、本書とプロポーションの版、実際に使った指示、出力ファイル、確認結果を残す。生成環境が対応する場合はモデル・設定・シードも保存する。同じ設定でも完全一致は保証されないため、再現性は結果の比較で確かめる。

## 11. 3D制作でも共有する条件

- 素体は頭・胴・手足・関節位置の共通化に使う。形状だけで線やハイライトの画風は再現されない。
- 外形線、セル調の影、髪の横帯、瞳の白点、後ろ髪の境界効果は、材質・照明・描画後の処理にも仕様を渡す。
- 髪の横帯は頭部の向きと球面に追従させる。画面へ固定された横線を貼るだけにしない。
- 後ろ髪の効果は、前後関係や重なる部位を識別して局所適用する。全ての後ろ髪へ同じ色をかける処理にしない。
- 本仕様を定めたことと、現在の簡易3D素体へこれらの描画機能が実装されていることは別。現在の素体には画風を再現する顔・髪・衣装・材質は未実装。

## 12. 出来上がりの確認項目

- [ ] 個別キャラクターの特徴が保たれ、他人の髪・衣装・小物が混ざっていない。
- [ ] 大きな頭部、短い首元、大きな手足、高い膝が最新プロポーションに合う。
- [ ] 服・帽子・手袋・玩具の外形と内側の線に太さの差がある。
- [ ] 衣服の色面と暗い影がセル調に分かれ、光沢だけが控えめなグラデーションになっている。
- [ ] 虹彩が横に広がりすぎず、白目と肌が分かれる。目の分類を勝手に変えていない。
- [ ] 主・補助ハイライトがあり、上側が虹彩輪郭に接し、目の外へはみ出していない。
- [ ] 睫毛の細線が縮小後も潰れず、元の表情が読める。
- [ ] 髪の白いハイライトが、頭の球面に沿う幅の揃った横帯として読める。
- [ ] 顔の下の影と明るい襟で顔が際立ち、首の隙間を増やしていない。
