# 仕様　＞　内政フェーズ　＞　君臨画面

内政フェーズのホーム画面を `君臨画面` と呼ぶことにする。  

左半分上側に［征服者］の絵が入った額縁を置き、  
**誰のターンか** 常に視聴者に分かるように表示する。  

右半分に［地星］を中心とした世界全体を見せたい。  
位置情報もここで表示される。  

## 移動・開戦の予約とターン終了（2026-10-12）

［移動］と［開戦］は命令を予約する操作とし、この操作だけではターンを終了しない。ほかのコマンドより少し大きい［ターン終了］で予約命令を確定する。親分・手下を操作する場合は、全員の行動提出後に共有ターンを一度だけ進める。

［移動］は自国・手下の節点を選ぶ。征服者とポケットの直属ロボットが同行する。他国への侵攻は［開戦］で指定する。

［開戦］では、自国・手下の節点または征服者の現在位置に交通路で隣接する敵節点を選ぶ。その敵節点に隣接する複数の自国・手下節点から、送る完成体の数を個別に予約できる。同じ節点を出撃元とする命令は一つとし、予約し直すと置き換える。複数節点から同じ敵節点へ送る兵隊は同時に戦場へ入る。継戦中の敵節点にも増援できる。

征服者のいる節点では、［節点が攻撃］と［征服者が出撃］を選ぶ。節点攻撃は指定数の兵隊だけを送り、征服者は留まる。征服者の出撃は本人とポケットの直属完成体を送り、節点の兵隊は残す。見逃された征服者も現在位置から出撃先を選べる。
