## サイズの倍率

絵に強いパースペクティブが付いていると、うまくいかない。  
まずは強いパースペクティブを解除することから。  
望遠で取った設定画にするなど。  


// むずでょの勘
// 設定画は望遠で撮ったような絵がいいな（＾～＾）  
// 直立姿勢のとき、  
// （１）［頭のてっぺんから顎の先までの長さ］と、  
// ［顎の先からへそまでの長さ］を同じにして、  
// （２）［頭のてっぺんからへそまでの長さ］と、  
// ［足の底までの長さ］を同じにしてくれだぜ（＾～＾）  


// むずでょの勘
// * 頭の大きさ： 1.3 倍（1.4倍の方がいい？）
// * 耳の大きさ： 1.4 倍
// * 首から下、股間より上を 3/4 倍
// * 手首から先（つまり手）： 1.2 倍


// ［－＿－］
// 今回の絵を目測すると、整数比ではこのくらいだぜ（＾▽＾）
// - 頭頂〜股：股〜足底 ≒ ３：４
// - 股〜膝：膝〜くるぶし：くるぶし〜足底 ≒ ５：６：２
// 
// ２、３、４，５，６　の数が１つずつ使われるエレガントな比率だぜ（＾▽＾）  


［－＿－］
今回の絵は、目測でこのくらいだぜ（＾▽＾）
- 頭頂〜股：股〜足底 ≒ ７：８
- 股〜膝：膝〜くるぶし：くるぶし〜足底 ≒ ４：５：２
前より上下半身が１：１に近づいて、少しコンパクトになった感じだぜ。
王冠は含めず、股や関節は服の上から推定した近似値だぜ（＾～＾）



// あとで：
素晴らしいぜ（＾▽＾）！  
キャラクター絵としての識別性が、わたしの要件を満たしたぜ（＾▽＾）！  
［物体の形状としての正しさ］と、［キャラクターの視認・識別性］は別なんだな（＾▽＾）
