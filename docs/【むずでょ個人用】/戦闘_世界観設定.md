# 戦闘　＞　世界観設定

## 玩具の兵隊さん

玩具の兵隊さんがいる。  

背の高い帽子を被っているのは［隊長］で、  
それ以外は下っ端の［兵］である。  
稀に、玩具の［クイーン］が出てくるが、それはその国のボス、征服者を表している。  

* ［クイーン］は攻撃できないが、敵兵を自分の兵に変えることができる唯一のユニットである。
* ［隊長］は［兵］を自分の周りに招集し、向きも自在に揃えることができる。つまり［隊］を作れるし、［陣］も作れる。
* ［隊長］と［兵］は同じ攻撃方法を持つ。
    * `短剣` - 敵の正面以外、または正面であっても盾を構えていなければ、倒せる。３回使える。
    * `小銃` - 離れた所を攻撃できるが、味方の背中に当たる可能性がある。３回使える。
* ［クイーン］、［隊長］、［兵］は同じ防御方法を持つ。
    * `盾` - 正面からの攻撃を防ぐ。４回使える。盾を構えながら `短剣` 攻撃もできる。`小銃` で攻撃中は使えない。
    * `壁を背にする`, `壁を横にする` - 壁からは攻撃がこないから。
    * 味方を壁にする

戦場は、１０×１０のマス目で構成される。  
１つの戦場では、２～４つの国が同時に入り込むことができる。  
１つの［兵隊］は１～１２体で構成される。  
下図は、４つの国が入り込んだ戦場での初期配置可能なマスである。

各国は、兵の数がそれぞれ１～１２のときの初期配置パターンを予め登録しておく。  
壁があり、配置を満たせない場合は、配置できるものが選ばれる。  
どのパターンも当てはめられない場合、壁以外の部分について一番多く配置できるパターンが選ばれる。  
それでも配置できない場合は、ゲームシステムに一人して配置される。  
配置の２人目は［隊長］となる。  
また、初期配置に置かなかった場合、  
１人倒れるごとに補充する形で１体が入ってくる。
