# 戦闘　＞　世界観設定


## いつ戦闘になるか

［戦闘］というより、［観戦］である。  
［内政フェーズ］の終わりに［観戦フェーズ］が始まる。［観戦フェーズ］が終わると１ターン終了。  


## 自動戦闘（観戦）

［観戦フェーズ］では、プレイヤーが操作することはできない。  
［新聞屋］の戦況報告を眺める気分。  

ターン制だが、全てのユニットが一斉に動くので、リアルタイムのように見える。  
以下の２つのフェーズがある。

* `行動選択フェーズ`
* `実施フェーズ`

行動選択フェーズでは、以下の２つを選択する。
* ［移動］か［方向転換］か。
* ［短剣］、［小銃］、［盾］、［何もしない］のいずれか。
この後、実施フェーズで実施される。これで、１ターンとする。  


## 戦場は１０×１０マスの盤

戦場は、１０×１０のマス目で構成される。  

まず、［移動］する全ユニット（駒）は、移動方向へ［移動］する。  
［方向転換］する全ユニット（駒）は、向きを変える。  
ここで、  
移動して、他の駒と衝突した駒は、元のマスへ戻る。  
元のマスに戻ったところで衝突したときは、衝突した駒も元のマスへ戻る。  

これで、駒の場所と向きが確定する。  

`短剣`、`盾` の空振りでは、消費しない。  
`小銃` の空振りでは、消費する。  
`盾` は、攻撃を受け止めたときに消費する。  
`短剣`、 `小銃` は、攻撃が当たったときに消費する。  


## 玩具の兵隊さん

玩具の兵隊さんがいる。  

背の高い帽子を被っているのは［隊長］で、  
それ以外は下っ端の［兵］である。  
稀に、玩具の［クイーン］が出てくるが、それはその国のボス、征服者を表している。  

そこが陣（城だったり、町だったり、ただの集まりだったり）であれば、  
［旗］が１本立っている。  


* ［クイーン］は攻撃できないが、敵兵を自分の兵に変える［説得］ができる唯一のユニットである。説得は広範囲に効く。あまり期待できない。
* ［隊長］は［兵］を自分の周りに招集し、向きも自在に揃えることができる。つまり［隊］を作れるし、［陣］も作れる。
* ［隊長］と［兵］は同じ攻撃方法を持つ。
    * `短剣` - 敵の正面以外、または正面であっても盾を構えていなければ、倒せる。３回使える。
    * `小銃` - 離れた所を攻撃できるが、味方の背中に当たる可能性がある。３回使える。
* ［クイーン］、［隊長］、［兵］は同じ防御方法を持つ。
    * `盾` - 正面からの攻撃を防ぐ。４回使える。盾を構えながら `短剣` 攻撃もできる。`小銃` で攻撃中は使えない。
    * `壁を背にする`, `壁を横にする` - 壁からは攻撃がこないから。
    * 味方を壁にする

１つの戦場では、２～４つの国が同時に入り込むことができる。  
１つの［兵隊］は１～１２体で構成される。

どのパターンも当てはめられない場合、壁以外の部分について一番多く配置できるパターンが選ばれる。  
それでも配置できない場合は、ゲームシステムに一人して配置される。  
配置の２人目は［隊長］となる。  
また、初期配置に置かなかった場合、  
［戦場での参加兵数］を設定しておき、  
それに満たない場合は、補充する形で１体が入ってくる（待機中の増援）。  
もし［征服者］が侵攻した場合は、最後に［クイーン］（征服者と同じ）が入ってくる。


## 勝敗条件

攻撃がしばらく認められないときは戦意が無いとして、両者退却する。  
防衛戦のときは、攻撃側が退却する。  

旗を取られた場合は、旗を取った国の勝利となる。  

旗の無い［辺戦］では、戦意が認めなければ、両者退却する。  
片方が退却した場合は、退却した側での［節戦］への連戦となる。  


## 観戦の種類

* ［辺戦］ - ２点の節点が同時に相手を攻撃した場合、その途中での野戦となる。
* ［節戦］ - 攻撃された側を［陣］とする。


## 戦場

１つの戦場の中に、最大で以下の３種類の地形が現れる。  

* ［野戦］
* ［海戦］
* ［陣戦］

［野戦］は平地だ。  
［海戦］では、［大きな船］と［橋］があり、橋では狭い戦いとなる。  
最大で４つの船が戦場に現れる。  
［陣戦］では［壁］があり、防衛側にやや有利となっている。  

余裕があれば、地形を増やしたい。  
足が遅くなる森や、滑る氷上など色々考えられる。  


## ５国以上の戦い

敵国同士であれば、例えば侵入経路の近い者同士で  
［１対１］と［１対２］の戦いに分けて、  
数が減れば、もう片方の戦いに合流することで、表現できる。
