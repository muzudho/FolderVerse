# ニコニコ生配信の始め方

## N Air を入手

📖 [N Air](https://n-air-app.nicovideo.jp/)  


## N Air にログインする

ニコニコ動画と同じアカウントでログインしてください。  


## ゲーム画面を追加する

例：  
* ゲームを起動し、N Airの「ソース」から「画面キャプチャ」を選ぶ。  
* [Alt] キーを押しながらウィンドウの枠をマウスで動かすと、画面の一部を切り抜ける。
* [Alt] キーを話しながらウィンドウの枠をマウスで動かすと、サイズを変更できる。


## ゲーム音とマイクを確認する

ゲーム音を鳴らし、マイクに話して、音量メーターが動くか確認する。  
ヘッドホンを使うと音の回り込みを防ぎやすいぜ。  


## 放送する番組を作る

タイトルや説明を入力する。最初なら「自作ゲームの配信テスト」など、目的が分かるタイトルで十分だな。  


## プレビューを確認して配信を始める

ゲーム画面と音声を確認してから開始する。

* ［新しい番組を作成する］ボタンをクリックする。
* （［番組開始］ではなく）［配信開始］ボタンをクリックする。
* ［最適化］は行わない。（行うとエンコーダーが対応しない）

* NVIDIA の ［GeForce GTX 1080］を使っているので、 NVENC エンコーダーに対応していない。
* ［設定　＞　配信　＞　エンコーダー］で、［NVIDIA NVENC H.264］を選ぶ。

これで、配信画面を非公開でテストできる。  


終了時は番組が終了したことまで確認する。  


最初は、配信前に30秒ほど録画して再生するといいぜ。  
ゲームが見えるか、自分の声が聞こえるかを手早く確認できる。顔出しは必要ないから、ゲーム画面と声だけで始められるぞ。
