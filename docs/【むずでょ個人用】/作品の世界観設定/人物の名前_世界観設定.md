# 世界観設定　＞　人物の名前


## 名前だけのケース

全員が１つの家族みたいな村社会では、  
苗字が発達しないので、名前だけ。  

それも、社会に身近にあるものを名前にする。  

* `茨`
* `曲がりくねった道`
* `勇気ある者`
* `白い花`
* `鳥の鳴き声`
* `鷹の鋭い目`

このような中から、女の子向けの名前を［征服者の女の子］に選ぶ。  


## 出身地が付くケース

［名前］だけしかないが、別の村で同じ名前を使う人が増えてきたときに、  
村名で区別するケース。  

* `＜ヴィンチ＞村の＜レオナルド＞`


## 名前の種類について

* ［本名］
    * 国民が知ってる［征服者の女の子］の名前
        * ［国民から選らばれた］という体裁を取っている国では、国民っぽい名前をしている。
        * 権力を分割されたという体裁を取っている国では、例えば家筋が分かる名前をしている。
    * 外交のフォーマルな場で、そう呼ばれて構わないという名前
