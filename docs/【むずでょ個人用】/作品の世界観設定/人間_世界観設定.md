# 作品の世界観設定　＞　人間


## 承認欲求と征服欲求の塊

この世界において、［征服者の女の子］という存在が出てくる。  

* ［承認欲求］が強く［自分より下の他者］が必要な女の子。
* ［自分大好き］で自己完結する女の子。
* 目立つために［装飾過剰］を好む女の子。
* ［奇抜］な恰好をして他人から話しかけられることを待っている女の子。
* 他人と変わったことがしたくて［眼帯］をしている女の子（が何人も居る）。
* 構ってほしくて他人の時間を強く拘束する女の子。

相手のためではなく、自分１人のために行動する女の子。  

この世界にはそのような女の子が蓄電できるタイプの電池が存在する。  
この電池は、地球（この世界では「地星］と呼ぶ）を自転させる。  
また何なら近くの星も自転させることができる。  
特に一番強く蓄電できる女の子は、自分を中心に周りの星を公転させることができる。  


## 男の子は何をしているのか

電子のように飛び回っている。  
世界を征服するような存在感は無い。  


## ２０人の征服者

まだ征服していなくても［征服者］と名乗っている女の子がいる。承認欲求が強いので。  
その数は２０人。  
［絶対に承認欲求が強い１人］と、［相手を絶対に承認しない１９人］で構成される。  
相手を承認したら負けだと思っている。  
この女の子たちの話し相手が［玩具］である。  
* 機関車の玩具
* ぬいぐるみの玩具
* 潜水艦の玩具
* 恐竜の玩具
など色々あり、玩具に話しかけることで電池を蓄電する。
［電池］はその［玩具］の中に入っており、残量はスマホのようなもので確認できる。
