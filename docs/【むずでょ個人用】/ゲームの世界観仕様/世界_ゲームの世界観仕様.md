## 仕様　＞　星の形状

球体ではなく直方体。  

* `地賽` - 最小の立方体状。1 x 1 x 1 サイズの面を持つ唯一のもの。
* `地棒` - 棒状。1 x 1 サイズの面を持つ。残った面は２～９のサイズを想定。
* `地盤` - 平面状。（地棒を除き）1 x n サイズ（ｎ＞１）の面を持つ。残った面は２～７のサイズを想定。
* `地箱` - 直方体状。（地棒、地盤のいずれでもない）。どの面も２～５のサイズを想定。

例えば、ｘ、ｙ、ｚについて、ランダムに生成すると、１つ目のｘで２～９の中間の５か６が最も多く出ると、  
この時点で `地賽` は出なく、`地箱` はやや出にくい。  
せっかく設定があるのだから、出やすさをバランス調整したい。  

例えば、  
* 1/15 - `地賽` 約  6.7%
* 2/15 - `地棒` 約 13.3%
* 4/15 - `地盤` 約 26.7%
* 8/15 - `地箱` 約 53.3%
