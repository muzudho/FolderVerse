# 作品世界観設定


## 星の形状

球体ではなく直方体。  

* `地棒` - 棒状。
* `地盤` - 平面状。
* `地箱` - 直方体状。

の３つがあり、どの世界になるかは［ゲーム設定フェーズ］で決まる。  
作品世界内ではそれを総称することは無いが、  
客観的に強いて造語するなら［星の形状］。

［東西南北］は平面地図上の概念であり、  
［星の形状］で絶対位置を表すには使いにくい。  
そこで、以下の呼び方をすることがある。    
* ［正Ｘ］
* ［負Ｘ］
* ［正Ｙ］
* ［負Ｙ］
* ［正Ｚ］
* ［負Ｚ］



### 地棒の世界

［極］と［中］がある。  

［極］には、［北極］／［南極］だけでなく、［東極］／［西極］になるケースもある。  

システム的に［極］にメリットがあるわけではないが、  
特別感がある。  


### 地盤の世界

［正面］と［側面］がある。  

［正面］には、［表］と［裏］がある。
