# 作品世界観設定


## 星の形状

球体ではなく直方体。  

* `地棒` - 棒状。1 x 1 サイズの面を持つ。
* `地盤` - 平面状。（地棒を除き）1 x n サイズ（ｎ＞１）の面を持つ。
* `地箱` - 直方体状。（地棒、地盤のいずれでもない）

の３つがあり、どの世界になるかは［ゲーム設定フェーズ］で決まる。  
作品世界内ではそれを総称することは無いが、  
客観的に強いて造語するなら［地星］。

また、地星に合わせて、 "地球儀" の呼び方が異なる。  

* `地棒儀`
* `地盤儀`
* `地箱儀`

客観的な総称は［地星儀］。


## 東西南北について

［東西南北］は平面地図上の概念であり、  
しかも［南北］は絶対位置であるのに対し［東西］は相対位置である。  
そのため、［極］に居るとき［東西南北］は使いにくい。  
こんな、極以外にいることを前提にした、よく定義されていない概念を使うのは、  
この作品世界内では混乱の元である。  

［地星儀］を見ながら［絶対位置］を表したい。  
定義のできが悪いのは［東西］だ。  
そこで、［東西］は使わず、作品世界内では以下の呼び方をすることがある。    

* 立体六方絶対位置
    * `碗` - ［正Ｘ］
    * `箸` - ［負Ｘ］
    * `頭` - ［正Ｙ］
    * `足` - ［負Ｙ］
    * `腹` - ［正Ｚ］
    * `背` - ［負Ｚ］

👆　右手に端を持っているときの系。  
これを使うときは、［地星儀］を表示する。  

［地星義］の横に、玩具の人形を置いて向きを連動させると、わかりやすい。  
例えば、タイトル画面にいるロボットとか。  


* 展開平面図四方相対位置
    * `東`
    * `西`
    * `南`
    * `北`

👆　極にいても、気にせず使うものとする。  
これを使うときは、［展開図］を表示し、必ず［北］を上にする。  
コンパスローズを表示すると親切。  



## 地棒の世界

［極］と［中］がある。  

［極］には、［北極］／［南極］だけでなく、［東極］／［西極］になるケースもある。  

システム的に［極］にメリットがあるわけではないが、  
特別感がある。  


## 地盤の世界

［正面］と［側面］がある。  

［正面］には、［表］と［裏］がある。  


## 地箱の世界

偏りはあるかもしれないが、極端な面を持たない。  
この作品世界が基本とするのがこれ。  


## 緯度経度について

この世界の星は直方体なので、［緯度］、［経度］は使わない。  
代わりに［緯番］、［経番］を使う。  

［緯番］、［経番］は、（展開図では使わず）［地星儀］表示のときのみ使う。  

［経番］は、［腹］と［碗］の面の境目をスタートとし、［碗］の方へ向かって増えていく。  
［経番］は、［極］面では、まるで同心円のように中心に向かって増えて（減って）いく。
