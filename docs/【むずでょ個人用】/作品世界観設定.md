# 作品世界観設定


## 星の形状

球体ではなく直方体。  

* `地棒` - 棒状。
* `地盤` - 平面状。
* `地箱` - 直方体状。

の３つがあり、どの世界になるかは［ゲーム設定フェーズ］で決まる。  
作品世界内ではそれを総称することは無いが、  
客観的に強いて造語するなら［星の形状］。

［東西南北］は平面地図上の概念であり、  
しかも［南北］は絶対位置であるのに対し［東西］は相対位置である。  
そのため、［極］に居るとき［東西南北］は使いにくい。  
こんなよく定義されていない概念を使うのは、作品世界内では混乱の元である。  

［星の形状］で［絶対位置］を表したい。  
定義のできが悪いのは［東西］だ。  
そこで、［東西］に変えて、作品世界内では以下の呼び方をすることがある。    

* 立体六方絶対位置
    * `碗` - ［正Ｘ］
    * `箸` - ［負Ｘ］
    * `頭` - ［正Ｙ］
    * `足` - ［負Ｙ］
    * `腹` - ［正Ｚ］
    * `背` - ［負Ｚ］

👆　右手に端を持っているときの系。  

* 展開平面図四方相対位置
    * `東`
    * `西`
    * `南`
    * `北`

👆　極にいても、気にせず使うものとする。  



### 地棒の世界

［極］と［中］がある。  

［極］には、［北極］／［南極］だけでなく、［東極］／［西極］になるケースもある。  

システム的に［極］にメリットがあるわけではないが、  
特別感がある。  


### 地盤の世界

［正面］と［側面］がある。  

［正面］には、［表］と［裏］がある。
