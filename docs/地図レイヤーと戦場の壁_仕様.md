# 地図レイヤーと戦場の壁

地図表示は独立した２つのドロップダウンで指定する。
- 地形 / 国セル色分け
- 交通路・節点非表示 / 交通路・節点表示

国セル色分けは独占しているセルのみ国色で塗り、独占でないセルは元の地形色とする。交通路・節点非表示では港の節点記号も隠す。右マウスドラッグによる回転を継続する。

陸の戦場では参加国数に対応した壁配置を種付き乱数で抽選する。既存標準配置に加え、渓谷（２方向、２国まで）、Ｔ字路（４方向、３国まで）、片側峡谷（４方向）、中央通路に集まる配置を使用する。海の配置は従来通り。閉じた辺は入場側に使わない。全ての配置は旗と通路が連結し、各入場側の初期配置領域に１２体を配置できる。後続国は空いている入場側のある戦場へ追加し、満員なら別戦場を作る。
