## ダウンロードして遊ぶ

2026年10月10日時点で、GitHub Releasesに配布版はありません。現在はソースコードから起動する開発版です。配布版を公開したら、ここにダウンロードと起動の案内を置きます。

[配布ページ](https://github.com/muzudho/FolderVerse/releases)

開発環境を用意できる場合は、[開発版の起動方法](../dev/README.md#開発版を起動する)を参照してください。

## 最初の操作

START → 世界作成 → 征服者作成 → 初期配置 → 操作する征服者を選択、の順に進みます。抽選はSTOPで止め、確定ボタンで次へ進みます。

ゲームが始まったら、［移動］で行先を選ぶか、［次のターン］で待機します。ロボットの設定は地図の節点をクリックして開きます。戦闘は自動で進み、最後に結果を確認します。

詳しいボタン操作は[操作ガイド](操作ガイド.md)、ルールは[ゲームの仕組み](../ref/ゲームの仕組み.md)を参照してください。
