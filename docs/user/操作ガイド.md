# 操作ガイド

## 画面の流れ

地図の［現在地へ移動］は、征服者が現在いる節点をビュー中央へ表示する。展開図では倍率を保って現在地の面へ切り替え、位置を中央に寄せる。地球儀では現在の節点が正面中央になるよう回転する。

1. START → 世界作成。寸法は形状ごとの範囲で抽選する（地賽1×1×1、地棒の長軸2～9、地盤の２軸2～7、地箱の３軸2～5）。STOPで固定、左ドラッグで回転。
   寸法のうち2軸が1より大きい世界の名称は「地盤」。
2. 世界確定 → 世界征服者作成。7×5グリッドの外周20マスに人物、中央15マスに世界を表示。
3. 人物のSTOP → 人物確定 → 初期配置の抽選。
4. 配置のSTOP → 国境線と首都の旗を確認 → 初期配置確定 → 世界征服者選択。
5. 顔をクリックして操作する人物を確定。選び直しや配置の確認もできる。


## SEEDの再入力

画面下のSEEDボタンをクリックすると、ゲーム内の電卓風ダイアログが開く。Windows Formsは使用しない。
数字ボタンまたは物理キーボードで入力する。Cは全消去、<は1文字削除、Enterは適用、Escapeはキャンセル。
範囲は0～2147483647。ダイアログ表示中は抽選を停止する。

- 世界SEED：寸法と海・陸の形を再現する。
- 人物SEED：60人×6枚の完成画像から選ぶ20人と国の色を再現する。
- 配置SEED：確定した世界と人物に対して、領地と首都を再現する。

完全に同じ初期状態を再現するには、3種類のSEEDを控え、世界→人物→配置の順に入力する。
人物を変更すると、依存する初期配置をリセットする。
世界の表面セル数は `2 × (Width × Height + Height × Depth + Depth × Width)`。3×3×3なら54。
セル数が20未満の場合、外周には20人全員を表示し、先頭のセル数ぶんが参戦する。残りは待機。
各参戦者には異なる首都が1セルあり、領地は首都につながるセルで構成される。


## スクリーンショット

Ctrl+P（左右どちらのCtrlでも可）で、描画済みのゲーム画面をPNG保存する。
タイトル・世界作成・征服者作成・SEEDダイアログのいずれでも撮影できる。
保存先は開発実行時はプロジェクトルートの `Screenshots/`。配布版では実行ファイルの隣の `Screenshots/`。
画像サイズは現在のウィンドウの描画領域と同じ。余白の背景も含めて保存する。
ファイル名に日時と識別子を付けて上書きを防ぎ、キーを押しっぱなしにしても1回だけ保存する。
文房具UIのデモにある、Draw後のGetBackBufferDataとSaveAsPngによる保存方式を参考に実装。
保存成功後は文房具UI（StationeryUI.MonoGame 0.3.0）の共通シャッター音と0.42秒のシャッターエフェクトを再生する。演出と保存通知はPNGに含めない。音声機器が使えない場合も撮影と視覚演出は動作し、音声エラーは操作ログへ記録する。

征服者作成画面の操作ボタンと3種類のSEEDボタンは下端の1段に配置。
寸法・表面セル数・参戦人数と操作案内は中央の地星儀区画に表示する。

## 配信向けセル数表示とバックグラウンド動作

領地が決まると、顔カード右下に国のセル数と cell を表示する。
数字は顔画像の縦幅の約1/3、cell はその半分の高さ。Comic Sans MS の丸い太字を使用し、
国境と同じ国の色で描き、暗い背景と縁取りで写真上でも読みやすくする。
領地確定前の「参戦」表示は廃止。待機人物は領地抽選後に 0 cell と表示する。

ウィンドウが非アクティブでも、抽選と地球儀の回転を更新し続ける。
クリック・キー操作はアクティブ時だけ受け付ける。SEED入力ダイアログ中の抽選停止は維持する。

## 節点ダイアログ

展開図の節点をクリックすると、その節点のロボット０～12体を４列×３段で表示する。頭・胴・脚の構成、所有国色・番号、個体IDを確認できる。海や他国の節点も調査できる。空の節点は空枠と案内を表示する。×または Esc で閉じる。
下部のタイル型［ロボット製造工場］を押すと工場ダイアログへ切り替わる。自分と自分の配下（手下の手下を含む）の節点で操作でき、他国・上位者・中立の節点では無効。製造パーツ７種類、製造計画の適用、停止／再開、工期±を設定する。計画や工期の変更は製造の進捗をリセットし、継戦中は変更できない。×またはEsc、選択中の工場タイルを押すと節点へ戻る。製造機能は輸送計画画面から移動した。


## 征服者の移動

［移動］を開くと一時的に交通路表示へ切り替え、直接つながる移動先節点（Node）の輪を点滅させる。地図上の節点をクリックして行先を選び、［確定］で1ターンの移動を実行する。選択した節点には白い輪も表示する。一覧をクリックして選択することもできるが、選択だけでは移動しない。同じセル内・隣接セル・面をまたぐ移動と海の節点にも対応する。
確定・×・Esc・［移動］の再クリックで移動画面を閉じ、開く前のグリッド／交通路表示へ戻す。行先が未選択なら確定できない。移動画面を開いている間は待機ターンと表示モードの手動切り替えを受け付けず、拡縮・ドラッグ・展開図のつなぎ替えは引き続き使える。
同行する完成体を１体刻みで選ぶ。［全員］と［０人］も使える。組立・分解・廃棄の予約中の個体は通常の同行・増援から除外する。
［ターン → 次へ］は待機として全体ターンを進める。敵も同時に隣接節点への移動を計画し、移動できる完成体を連れる。戦場参加中のクイーンは新たに出撃できず、継戦辺も越えられない。敵の行動は配置SEEDとターン数から再現する。

生産者・残数は節点に残り、ロボットの出撃で人口は減らない。領有は旗・戦意・生存軍で決まる。征服した節点の役割異動率・移住率は0へ戻す。領地数を再計算し、首都を失っても領地があれば人口最多の自国節点があるセルを新首都にする。
自国の節点がなくなると放浪者になる。征服者は移動・待機でき、中立節点では旗上げできる。直属のロボットは征服者と一緒に移動する。
地図の大きな電池は操作人物、小さな各国色の電池は敵征服者の現在地。ターン結果は地図の下へ表示する。

### タイトルのスタートメニュー

タイトルの「スタート」またはEnterで、中央に小さなメモ紙のスタートメニューを開く。開いている間はスタートボタンを隠す。「続きから」はオートセーブがある場合のみ表示する。「最初から」は通常の人数確認・ゲーム作成へ進む。遊び方のモードは未実装で、上段の配置場所だけ確保している。

メニューはマウス、上下キーとEnterで選択できる。Esc、紙の外側のクリックでタイトルへ戻る。選択肢は文字だけを表示し、マウスを重ねると文字色が変わる。読めないセーブがあっても紙の上にエラーを表示し、「最初から」を選べる。メニューを開いている間は自動デモを始めない。

### 遊び方・ステップ１

START のノートパッドで「遊び方」を選ぶと、図書館で本を読む女性の案内とステップ１～５を表示します。現在はステップ１だけ開始できます（Enterでも開始）。ステップ２～５は準備中です。戻る／Escでノートパッドへ戻ります。

ステップ１は１人プレイ、地賽（1×1×1）、征服者はNo.1～6の基本姿、プレイヤーはNo.1です。地形・セル配置はランダムに準備し、兵隊ロボットは各節点に完成品４体ずつ配置して内政フェーズから開始します。以後の遊び方とオートセーブは「最初から」と同じです。20分は各ステップの推定時間で、時間制限ではありません。

### 世界征服状況フェーズ

初回と全体ターン開始時、内政の前に各国の紹介が自動で流れます。赤カーテンの開閉と1.5秒の待機、地星儀の1.5秒フェードインの後、暫定順位の下位から上位へ、顔・国色・領地と節点を紹介します。手下の前には上位ボスを短く再紹介します。紹介中の着色・節点はその本人のものだけで、手下は含みません。現在地の印と、人間プレイヤーの「プレイヤー１」等も表示します。

共通の前奏に、本人の領地の極地・海・高山の割合に応じた氷音・泡音・風音を重ねます。現時点では人物の背景設定による変化はありません。Enter／Escで紹介を飛ばして終了演出から内政へ進めます。同じ全体ターンのプレイヤー交代では再生しません。「続きから」では、そのターンの状況を改めて紹介します。

### セル数から点数・暫定順位への演出

世界征服状況の右上には、地星儀と向きが同期する方向ロボットの円ウィンドウを表示します。このウィンドウに回転ボタンはありません。

本人のセルを１つずつ着色し、`1 cell`、`2 cells` と数えます。本人分が終わると手下分（混在するセルを含め、配下全体で完全支配した分）を加算します。地星儀の着色と節点は引き続き本人だけです。画面は７×５カレンダーで、左上２×２に地図、その下２×２に計算式を固定します。４つの数値枠は最初に伏せ字で置き、集計後にセル数、Entry No.、点数、暫定順位の順で開きます。最後に、カレンダーの本人の顔を征服セル数に応じた面積で表示します。顔は次の紹介に進んでも残ります。数式は `セル数×100＋Entry No.＝points`。地図の位置・大きさは途中で切り替えません。ゼロセルでも最小枠を残します。上位ボスの短い再紹介では点数演出を繰り返しません。

順位は本人＋手下の征服セル数が多い順、同じなら参加登録番号が大きい順。節点数は順位に影響しません。点数は `セル数×100＋参加登録番号` です。将来100人以上なら係数と表示桁が自動で増えます。

### ステップ１の兵力と開戦予約件数

ステップ１では「ロボット輸送計画」ボタンを表示しません。

「開戦を予約」で確定すると、開戦予約モードのまま次の目標を選ぶ状態へ戻ります。続けて別の節点への予約を設定でき、ハンドルの「×」で閉じます。確定済みの予約は閉じても残ります。同じ格納庫や電池の行き先を変更すると、その出撃元の従来の予約を置き換えます。

開戦予約の出撃元は２行で表示します。２行目には頭・胴・脚がそろった格納庫（電池の行はポケット）のロボットを１列に並べます。パーツの国の色、損傷、安物の縞模様を確認でき、ロボットをクリックして出撃を選択・解除できます。「予約」は別の目標への予約、「出撃」は今回の選択、「不可」は出撃できない機体です。従来の「ロボット出撃」ボタンからの選択も使えます。最後に「開戦を予約」で確定してください。予約済みの侵攻先節点には、地図上に剣と「開戦予約済」を表示します。

新しく始めるステップ１では、全節点の格納庫に頭・胴・脚がそろった自国の正規品・無傷の兵隊ロボットを４体ずつ配置します。最初の内政から派遣数を指定して開戦予約できます。ステップ１では全国家に製造ラインを作らず、「ロボット製造工場」のタブも表示せず、入場できません。セーブから再開してもこの制限を保持します。既に開始済みのプレイの兵力は書き換えません。

地図下のボタンは「開戦予約（なし）」または「開戦予約（2件）」のように表示します。操作できる自国・手下の予約が対象です。同じ侵攻先への複数の出撃元はまとめて１件、別の侵攻先は別件です。味方節点への移動予約は含みません。予約の追加・変更・取消に応じて表示が変わります。

### 装備残数・ステップ１の産業画面・名前入りメダル

戦闘では、盾・短剣・小銃の残数が０になった種類はドット絵と数字を表示しません。残っている種類だけを詰めて並べ、全種類０なら背景も消えます。

ステップ１では産業ルーレットの画面を飛ばします。廃炉や自動組立に必要な産業ターンの内部処理は画面を出さずに済ませ、次の世界征服状況／内政へ進みます。通常プレイの産業画面は従来どおりです。

大地図ビューの征服者の肖像は、国色の二重枠と、その間の淡い粒子状の帯で囲みます。帯の上半分にフルネームを円弧に沿って刻印風に表示します。名前の「・」は表示時だけ半角スペースへ置き換え、複数の空白は１個に揃えます。

### ステップ１の海と陸・メダル刻印の間隔

世界征服状況の地星儀にも地形を表示しています。紹介する国のセルを着色中は国色を混ぜるため、通常の地形色とは異なります。通常生成では海だけ・陸だけになることがありますが、新しく始めるステップ１では海と陸を主地形とするセルが両方ある地賽だけを選びます。開始済み・保存済みの地形は変更しません。

メダルの刻印帯と文字サイズを以前の1.2倍にし、文字の配置半径は132pxです。上部中央を基準に、各文字の幅とは別に５°の文字間隔を設けます。

### 太い彫り込み文字と紹介終了のフェード

メダルの名前は極太相当に太らせ、文字の内側の上左へ影、下右へ明るい縁を付けたデボス（彫り込み）風の表示にしました。以前の２色をずらす簡易表現から変更しています。文字の配置半径は132pxです。刻印帯の幅と二重枠の位置、５°の字間は維持します。

世界征服状況の紹介終了時は、最後に見えていた地星儀を1.5秒かけて暗くし、消えた後は描き直さずに赤カーテンを閉じます。開始時のフェードインは維持します。途中で飛ばした場合も、その時点の明るさから終了演出へ進みます。

### 侵攻先の名前とカーテン

開戦画面の「侵攻先」は節点の地名・地形・地点名で表示し、`Node 数字` のID表記を使いません。長い名前は表示幅に合わせて縮小します。世界征服状況フェーズのカーテンは見出しや案内文字より前面に出て、閉じ切ると文字も含めて画面を隠します。メダルの刻印は半径を130pxから132pxへ戻し、太さとデボス表現・字間を維持しています。

## 2026-10-17 電池を独立した出撃元として表示

電池は実際の節点の横へ表示するUI上の代理。征服者の現在地、交通路、距離、領地・節点数は変更しない。電池へのホバーで拡大し、ポケット内ロボットを表示。担当征服者の電池をクリックするとポケットを開く。電池・他国・ロボットの表示設定にも従う。

開戦予約では格納庫と電池を別行にし、格納庫は指定した兵数、電池は征服者と出撃可能なポケット兵だけを送る。同じ実節点から双方の予約を保持でき、解除も別々。同じ交通路を通る両方の部隊は共通の遭遇戦へ参加する。旧セーブの従来型出撃予約はその兵数を維持する。

### 旗の決着とチュートリアル勲章（2026-10-18）

節戦では、倒れた旗のマスに攻撃側が留まっても構いません。倒した時点から10戦闘ターンの取り返す猶予があり、取り返せないと戦力が残っていても守備側が降伏します。旗を立てたまま連続50戦闘ターン守ると守備側の勝利。倒されると防衛の累計をリセットし、取り返した直後から改めて50ターンを数えます。残りターンと進捗バーを戦闘画面に表示します。辺戦には旗の時間制限を適用しません。

遊び方のステップ１は「開戦しましょう」。プレイヤー１が参加する戦闘を最初に表示します。ステップ１の対象の攻撃戦闘では、変身演出の終了直後に勲章を獲得し、モブが「［開戦］を実績解除しました！」と知らせます。吹き出しは3.5秒後に自動で消え、その間は戦闘再生を待ちます。勲章はタイトルへ戻った後も保存されます。開戦予約を入れただけ、あるいは守備側で参加しただけでは解除されません。実績が未解除で開戦予約のない状態でターン終了を押すと、図書館のモブがこのステップの練習手順を案内します。予約後はターンを進められ、実績解除後は平和なターン終了も可能です。通常のゲームにはこの制限はありません。

ステップ選択の「チュートリアルの勲章をクリアーする」で、チュートリアルの実績だけ消して集め直せます。勲章はゲームのオートセーブと別に保存するため、エンディング後や最初からの開始で消えません。

ステップ１の内政開始時には、モブが「さあ、戦争の始め方を覚えましょう！　［開戦予約］ボタンを押してください！」と案内します。［チュートリアルを見返す］から、開始時・開戦予約時・実績解除時のメッセージを選んで読み直せます。一覧は［閉じる］またはEscで閉じます。
