# チュートリアルのメタ用語一覧

プチステラの案内で、モブ女がプレイヤーに話しかけるときの言い換え案です。メタ用語とは、作品世界の外にある身近な言葉を使って、画面に見えるものや操作を伝える表現です。押すボタンや選ぶメニューは、画面で探せるよう実際の表記を［ ］で示します。

## 地図と画面の操作

| 作品内・画面の用語 | モブ女の言い方 |
| --- | --- |
| 地星儀 | **地球みたいな箱**。初出は「この地球みたいな箱が、世界地図です！」 |
| 展開図 | 箱を開いて、平らに広げた地図 |
| 組立 | 広げた地図を、箱の形に戻す |
| 面 | 箱の一面。位置を示すときは「箱の横の面」「箱の裏側」 |
| 地点 | 地図の上でクリックできる場所 |
| 区画 | 地図を大きく分けた、土地のまとまり |
| 面のつながり | 箱に戻したとき、どの辺とどの辺がくっつくか |
| 方向ロボット | 右上の丸いところにいるロボット |
| 地図を回転 | 地図を回して、横や裏を見る |
| 地図をスライド | 地図を画面の好きな位置にずらす |
| ドラッグ | マウスのボタンを押したまま動かす |
| インスペクター | 地点やロボットの情報が出る横長の画面。閉じる場面なら「いま開いた画面の［×］」 |

## 人物・ロボット・ターン

| 作品内・画面の用語 | モブ女の言い方 |
| --- | --- |
| プチステラ | 今回遊ぶ、小さな世界 |
| 征服者 | 国を動かすキャラクター。自分の操作では「あなたのキャラクター」 |
| 陣営 | あなたのチーム。ほかの陣営は「相手のチーム」 |
| 内政フェーズ | ロボットを作ったり、移動や攻撃の準備をしたりする時間 |
| ポケット | あなたのキャラクターがロボットを連れていくための持ち物入れ |
| 格納庫 | その地点にいるロボットを置いておく場所 |
| 直送便 | 近くの地点にロボットや荷物を届けるトラック便 |
| 移動予約 | 次に行く場所を先に決めておく |
| 開戦予約 | 攻める場所と、戦いに行くロボットを先に決めておく |
| 出撃 | ロボットを戦いに送り出す |
| この陣営のターン終了 | あなたのチームの準備を終えて、予約したことを進める |
| 世界征服 | この世界のすべての面を、自分のチームのものにする |
| セーブ枠 | ゲームの続きが入る保存場所 |

## セリフ例

> この地球みたいな箱が、世界地図です！  
> 箱を開いて、平らな地図にしてみましょう。  
> 右上の［展開図］ボタンを押してくださーい！

> 次は、どこを攻めるか決めましょう！  
> 箱の横や裏にも、攻められる場所があります。地図を回して探してね！

画面を指すときは「いま開いた画面」「左のロボット一覧」のように、その場で見えるものを使います。
