# 節点の近隣特徴オブジェクト

## 表示と意味

節点の位置を覚えるための装飾。戦力・生産・通行・所有権には影響しない。土地征服フェーズ、内政の地星儀と展開図に同じ目印を表示する。細い線で節点と目印の位置をつなぐ。目印は地図の拡大に応じて大きさが変わり、ホバー・選択中の節点では大きくする。

部品は17種類：赤い家、風車、井戸、大木、岩、花畑、三本杉、灯台、桟橋、難破船、岩礁、ブイ、カモメ、ルックの塔、西洋の城、日本の城、凱旋門。風車の羽とカモメの羽は動くが配置は固定。

## 配置と隣接の保証

世界の種と地形・節点・交通路から決定的に生成する。陸に家・城・井戸など、海に岩礁・ブイ・カモメ、岸に灯台・桟橋・難破船を配置する。各節点は通常２個のオブジェクトの組を持つ。同じオブジェクトを２個置く組もあり、その場合は説明に個数を記す。

道や航路で直接つながる節点の組は、必ず異なる。並び順を揃えた種類の組で比較し、既に配置したすべての隣接節点と照合する。２個の組を使い切った場合は３個以上の組へ拡張し、重複した組へはフォールバックしない。新しい絵を増やさずに区別できる数を増やす。

配置点は同じセル内の近傍から選び、節点の中心と既に選んだ目印の点を避ける。狭い場所では節点の傍へ少しずらす。方角は地理上の北・東と節点から配置点への方向で計算し、カメラを回しても説明は変わらない。

## 名前と保存

直接便の左右の格納庫で、節点名のすぐ下に「目印：北側の風車と花畑」などを表示する。通常の節点インスペクターと地図のホバーヒントにも併記する。

シミュレーションの乱数を消費せず、既存セーブに新しい必須フィールドを追加しない。旧セーブでも同じ種と地形から生成する。土地征服で所有国が変わっても配置は変わらず、保存・再読込でも維持される。

## 検証

`tests/NodeLandmarks` は３世界のすべての交通路について隣接する組の相違、全種類の生成、海への陸上建築物の混入防止、節点からの位置のずれ、土地征服から内政への配置継続、保存・再読込の一致を検証する。17種類の一覧、展開図、地星儀、土地征服フェーズを描画して確認する。
