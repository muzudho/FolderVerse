# 自国と手下の操作・セル色分け

地形ドロップダウンに「自国・手下セル色分け」を追加。プレイヤー陣営の親分と、その配下（孫配下も含む）の独占セルだけ各国色で表示する。他国および独占でないセルは地形色を維持する。地星儀と展開図に共通。

君臨画面の左右ボタンで、未行動の自国・配下の征服者へ操作を切り替える。移動・ポケット・輸送などは操作中の征服者を対象にする。次のターンで各人の行動を確定し、陣営全員の行動後に全体ターンを進める。電池なし・解放・捕虜は操作候補から除外。他国の征服者は操作候補に含めない。

手下の君臨画面は本人画像より上に直属の親分画像と「○○の手下です」を表示する。この操作切替は複数の征服者を扱うための機構で、ネットワーク対戦そのものは実装しない。
