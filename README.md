# Folder Verse

MonoGame製のゲーム試作。Visual Studioで `FolderVerse.slnx` を開いて実行する。

## 画面の流れ

1. START → 世界作成。寸法は1～5。STOPで固定、左ドラッグで回転。
2. 世界確定 → 世界征服者作成。7×5グリッドの外周20マスに人物、中央15マスに世界を表示。
3. 人物のSTOP → 人物確定 → 初期配置の抽選。
4. 配置のSTOP → 国境線と首都の旗を確認 → 初期配置確定 → 世界征服者選択。
5. 顔をクリックして操作する人物を確定。選び直しや配置の確認もできる。

## SEEDの再入力

画面下のSEEDボタンをクリックすると、ゲーム内の電卓風ダイアログが開く。Windows Formsは使用しない。
数字ボタンまたは物理キーボードで入力する。Cは全消去、<は1文字削除、Enterは適用、Escapeはキャンセル。
範囲は0～2147483647。ダイアログ表示中は抽選を停止する。

- 世界SEED：寸法と海・陸の形を再現する。
- 人物SEED：60人×6枚の完成画像から選ぶ20人と国の色を再現する。
- 配置SEED：確定した世界と人物に対して、領地と首都を再現する。

完全に同じ初期状態を再現するには、3種類のSEEDを控え、世界→人物→配置の順に入力する。
人物を変更すると、依存する初期配置をリセットする。
世界の表面セル数は `2 × (Width × Height + Height × Depth + Depth × Width)`。3×3×3なら54。
セル数が20未満の場合、外周には20人全員を表示し、先頭のセル数ぶんが参戦する。残りは待機。
各参戦者には異なる首都が1セルあり、領地は首都につながるセルで構成される。

タイトル・世界作成・征服者作成・SEEDダイアログのいずれでも撮影できる。
保存先は開発実行時はプロジェクトルートの `Screenshots/`。配布版では実行ファイルの隣の `Screenshots/`。
画像サイズは現在のウィンドウの描画領域と同じ。余白の背景も含めて保存する。

## 完成画像による人物抽選

imagegenで60人それぞれ6つの角度・ポーズを描いた、合計360枚の完成画像を使用する。
目・耳・眼鏡類のランタイム合成は廃止。従来のオリジナル画像と差分素材は保管する。
現在の素材は Content/Images/Portraits/sheet-01.png ～ sheet-10.png。
各シートは6列×6行で、1行が同じ人物の6パターン。1シート36枚、10シート360枚。
抽出した個別PNGは同ディレクトリーの tiles/ 以下。描画はシートの該当区画を直接読む。

目・耳・眼鏡類は人物ごとにランダムな共通特徴を指定し、各画像で性格・表情・状況をランダムに指定。
顔の角度とポーズを変え、見える目は視聴者へ向ける指定。線目・眠気・笑顔・瓶底眼鏡では目が見えない場合がある。
表情・状況は生成時のキーワードで、ゲーム内でその行動を演じる処理ではない。
manifest.json に360枚の指定を保存。prompt-01.txt ～ prompt-10.txt に実際の生成プロンプトを保管。
生成画像ではキーワードの細部が完全には一致しない場合がある。

60人から20枠を抽選するため、毎回出ない人物がいる。75％の確率で、20人全員が異なるベースになる抽選を行う。残り25％では従来の姉妹を含む抽選を行い、同じ人物は異なる画像で最大6人まで登場する。10,000 SEEDの確認では全員別ベースが7,538回（75.38％）。
同じ完成画像は同じ回で重複しない。双子から6つ子まで別々の国の色を持つ。
顔にマウスを置くと、中央に人物番号・画像番号・テーマ・表情と状況の指定・姉妹人数を表示。
人物SEEDは画像選択と国の色を再現する。31ビットの範囲を引き続き使用する。
人物生成方式を変更したため、過去の差分合成版の人物SEEDとは結果が異なる。
世界と配置の生成方式は維持。完全再現には3種類のSEEDを順番に入力する。

描画確認画像は Screenshots/PortraitReview/completed-01.png ～ completed-10.png。
## 配信向けセル数表示とバックグラウンド動作

領地が決まると、顔カード右下に国のセル数と cell を表示する。
数字は顔画像の縦幅の約1/3、cell はその半分の高さ。Comic Sans MS の丸い太字を使用し、
国境と同じ国の色で描き、暗い背景と縁取りで写真上でも読みやすくする。
領地確定前の「参戦」表示は廃止。待機人物は領地抽選後に 0 cell と表示する。

ウィンドウが非アクティブでも、抽選と地球儀の回転を更新し続ける。
クリック・キー操作はアクティブ時だけ受け付ける。SEED入力ダイアログ中の抽選停止は維持する。
## 世界征服者選択

7×5のカレンダー区画を維持し、各区画を4×4に分割した28×20（560マス）のサブグリッドを使う。
各参戦者の顔の面積は領地の割合で決める。辺の長さは floor(sqrt(496 × 国セル数 / 世界セル数))、
最小1、最大20。面積は1、4、9、16…400という平方数になる。
サブグリッドのマスはカレンダーと同じ長方形比率で、顔は縦横同じマス数を占める。
大きな顔から詰め、幾何的に収まらないときは大きな顔を一段縮小して再配置。
全参戦者が重ならず収まることを優先するため、比率の表現は近似。余りマスには画像を置かない。
領地がない待機人物はプレイヤーとして選べない。

顔へのホバーで左上へ10×10px移動し、元の位置にドロップシャドウを描く。
10pxは1920×1080の論理画面での寸法で、ウィンドウの拡縮時は他の要素と同率で拡縮する。
クリックで WorldSetup.PlayerSlot に国のスロット番号を記録し、その人物を「あなた」と表示する。
選び直すボタンで再選択できる。人物・世界・初期配置を作り直すと操作人物の指定を解除する。
プレイヤー確定後は「世界征服状況へ」ボタン、または Enter で状況画面へ進む。

生成画像のシートは行高さが微妙に不均等で、特にシート07はずれが大きかった。全10シートを測定して等分クロップを廃止。シート07は実際の境界
0,158,315,473,631,791,1024 px に修正。全シートの切り出しに2pxの内側余白を設けて区切り線の混入を抑える。
原本シートは変更せず、個別PNGを同じ切り出し規則で再抽出する。
段の高さが大きく異なる最下段のベース06・18・30・42・60は、内蔵imagegenで正方形の6枚（3列×2行）に再構成した。修正画像は Content/Images/Portraits/base-XX-normalized.png、使用プロンプトは normalization-prompts.json に保存。ゲームはこの5人だけ修正版を使用し、ほかの顔も表示先の比率に合わせて切り出し、縦横同率で拡大縮小する。元シートは保存する。

title-logo.png は組み込みimagegenでタイトル画像からロゴ・副題・飾りを透過抽出したもの。
元の論理画面位置で不透明度14%の背景として世界作成・征服者作成・選択画面に描く。
生成指定は Content/Images/title-logo-prompt.txt。タイトル画像原本は保持する。

選択画面の地球儀はカレンダー2×2マス＝サブグリッド8×8の64マスを占める。
この固定サイズの地球儀も顔と一緒に配置する。残る496マスで人物の平方サイズを配分する。

最後にホバーした人物の領地を国境と同じ色で全面塗りし、照明に依存しない明るさで穏やかに点滅させる。
キャラ確定後は自分の国をハイライトする。配置確認へ戻ると解除する。

## 世界征服状況

左側にはカレンダー2×2マスの肖像と金色の額縁、征服者名、政治体制（全員「独裁者」）、首都名、領地数を表示する。
右側は地球儀と同じ地形を使う6面の展開図。自国のセルが最も多い面を中央に置き、自国の色を点滅させる。
左右回転ボタンで90度ずつ回転し、矢印キーで中心面を移す。「自分の国へ」「首都の面へ」「北を上に」で表示を戻せる。セルのクリックでは中心面・向き・配置を変えない。
同じ英字が付いた辺同士は地球上でつながる。セルへのホバーで都市名と征服者名を表示する。

つなぎ替えられる外周の辺にカーソルを合わせると黄色く強調する。その辺をクリックすると、地球上で隣接する面と、その面につながる枝を切り離し、約0.85秒かけて移動・回転させて接続する。
中心面と全体の回転は維持する。接続済みの辺と、接続後に面が重なる辺はつなぎ替え対象にしない。アニメーション中は追加の辺・セル操作を受け付けない。
セルの中心をクリックしても辺操作にならないよう、面の内側は辺の判定から除外する。ズーム・パンで広げた地図でも同じ操作ができる。
通常面の北は +Y。北極面の上は +Z、南極面の上は -Z を基準とする。

地形上の面名帯は表示しない。極面の陸地は雪色、英字は離れた辺だけに表示する。
マウスホイールでカーソルを中心に0.5～8倍に拡縮し、スペース＋左ドラッグで地図を移動する。「自分の国へ」で拡縮と位置も戻る。
外周の番号は角度ではなくセル単位の経番・緯番。座標は GeoJSON と同じ（経番,緯番）の順。
経番0は +X/+Z の縦の角から東へ最初の列。東回りを正とし、一周の後半は負になる。緯番0は側面の中央行（偶数高さでは北側の中央行）。北が正、南が負。
極面は外周から内側へのリングごとに緯番を進め、リング内の経番を赤道の番号範囲へ割り当てる。極面の外側には番号の組を示す。全セルの座標は一意で、地図の回転では変わらない。
首都・ホバー都市・征服者現在地に座標を表示する。各征服者は最初は首都におり、現在地は首都とは別に保持する。
操作人物の現在地には、生存の印となる電池アイコンを点滅表示する。

## セルの人口とターン更新

自国の陸地セルをクリックすると、左半分に人口設定パネルを開く。×または Esc で閉じる。
健康な若者を戦闘員・生産者・残数の3区分で管理する。陸地の首都は 240,000 人（10,000 / 190,000 / 40,000）、ほかの陸地は60,000～180,000人をSEEDから生成する。海セルは人口0。
地形はセルの地形サンプルの最多種で判定する。海と判定されたセルへの移住はできない。

役割の異動は残数から戦闘員・生産者へ移す率を設定する。正値はターン開始時の残数に掛け、負値は開始時の該当職種に掛けて残数へ戻す。
正値の合計は100％以内。職種ボタンで移住を設定する区分を選び、北・東・南・西へ移す率をそれぞれ指定する。各区分の移住率合計も100％以内。
移住先は同じ国の隣接陸地セルのみ。面をまたぐ辺でもつながりを使う。方向は地図の回転に依存せず、極面では既存の基準経線の向きに従う。

［ターン → 次へ］で全セルを更新する。役割変更後の人数を元に移住を同時に計算し、その後、移住後の生産者数×若者の生産率で残数を増やす。到着者は同じターンには再移住しない。
異動・移住の人数は小数切り捨てで、残りは元の区分・セルに留まる。生産の小数はセルごとに持ち越す。初期生産率0.00001％なら生産者190,000人から毎ターン0.019人分が生まれ、53ターンで1人になる。
異動・移住は初期値0％。設定はセルごとにゲーム実行中保持し、配置を作り直すと人口・設定・ターン数を初期化する。
［−］［＋］の刻みは役割1％、移住0.1％、生産0.00001％。Shiftを押すと10倍、Ctrlを押すと100倍の刻みになる。

## 征服者の移動と簡易戦闘

［移動］で同行戦闘員数と北・東・南・西の行き先を選ぶ。移動は面をまたぐ隣接セル1つだけで、クリックするとターン終了。海セルにも移動できる。
同行人数は現在地が自国の場合に、そこの戦闘員から取り出す。100人刻み、Shiftで1,000人、Ctrlで10,000人、［全員］と［０人］も使える。
［ターン → 次へ］は待機としてターンを進める。どちらの操作でも敵が同時に1セル移動する。敵は現在地の戦闘員の半数を連れ、弱い隣国や自国へ戻る方向を優先する。行動は配置SEEDとターン数から再現する。

全員の同行戦闘員を出発セルから取り出し、人口を更新してから移動先ごとに戦闘する。同じ国の援軍は守備兵へ合算する。
攻撃側の人数を合算して守備側と相殺し、攻撃側の損失は各国の人数比で配分する。端数は小数部分が大きい国から配分し、合計人数を一致させる。
例：守備1,000人に900人と600人が攻め込むと、攻撃側の損失は600人と400人、残り300人と200人になり、300人の国が占領する。
残兵最多の国が領有し、その色へ変更する。同数の残兵なら国番号が小さい国を優先し、全員0人なら元の領有国を維持する。0人だけの移動では無人セルも占領できない。
占領できなかった残兵は出発セルへ戻す。そこを失っていれば残った自国セルへ戻し、自国がなければ戦闘員は残らない。征服者本人は移動先に留まる。
生産者・残数はセルに残る。征服したセルの役割異動率・移住率は0へ戻す。領地数を再計算し、首都を失っても領地があれば人口最多の自国セルを新首都にする。
自国の拠点がなくなると放浪者になる。征服者は消えず、募集・征服はできず、移動または待機だけを続ける。
地図の大きな電池は操作人物、小さな各国色の電池は敵征服者の現在地。ターン結果は地図の下へ表示する。

## 地形経路・拠点・グリッド

［グリッド / 航路］は押すごとに切り替わる排他的な表示ボタン。旗と電池は独立して点灯・消灯できる。
各セルの地形は10×10。海抜0.52未満は海、0.52以上0.72未満は陸、0.72以上は山。山は壁で、一部の山には世界SEEDで決まる狭い峠がある。
辺の海・陸・山の連続区間ごとに、その区間の中央へ通過点を置く。共通の3D辺を使うため、展開図をつなぎ替えても隣接セルへの通過点は変わらない。険しい山や上陸できない海岸の通過点は閉鎖される。
航路表示では国による地形の面塗りとセル境界線を消し、拠点を国の色の丸印で示す。グリッド表示では従来の面塗りを表示する。航路は階段状の折れ線を通行可能領域内で整理してから、滑らかな曲線で描く。境界の通過点マーカーは表示しない。セル境界への接続は両側で辺に垂直な接線を持つ3次ベジェ曲線を優先し、山の壁などで通れない場合だけ元の安全な経路を残す。描画経路の起点は拠点中心とし、同じ通行領域にあるほかの拠点にも枝を接続するため、拠点の丸印は経路ノードに一致する。海路は水色、陸路は黄色、山の峠はオレンジ。壁・閉鎖された地形境界を横切る短縮や曲線は採用しない。

移動は隣接セルへ1ターンに1回。セル内を歩く操作はなく、到着した通過点が次の経路探索の起点になる。海にいる間は海路、陸や峠にいる間は陸路を使う。山で東西が分断されていれば、同じセルでも入口によって出られる方向が違う。
現在地は「都市名（経番,緯番,南東側・海）」のように表示する。電池は実際のセル内位置に置く。初期位置は所属拠点の中心（丸印・経路ノード）にそろえる。拠点中心にいる間は現在地からの追加経路を重複して描かず、移動後は到着した入口の地点を保持する。

同じ地形でつながる領域をセル内拠点として管理し、各拠点が国・人口・旗を持つ。陸の人口パネルはクリックした自国拠点を対象にする。移住は同じ国の拠点まで陸路がある場合に有効。
戦闘は到着した拠点に対して行う。同じ拠点への同時攻撃は兵数を合算し、損害を兵数に応じて割り振る。同じセルの別拠点は巻き込まれない。
一部の拠点を奪ったセルは未占領（部分占拠）。各拠点の色と旗、通行可能領域の面積割合を表示する。全拠点が同じ国になったときだけ完全占領としてセル征服数に数え、国の色の外周を表示する。拠点が一つでも残ればその国は存続する。
セルの接続は拠点ごとに孤立・行き止まり・Ｉ字・Ｌ字・Ｔ字・十字に分類し、出られる方角を併記する。セルにカーソルを合わせると、海と陸など各接続パターンを表示する。

世界の天候・旱魃・風の魔法などの効果範囲はセル単位、征服者の所在・移動・戦闘は拠点と経路単位とする設計。天候や魔法の効果処理は今後追加する。

各セルは世界SEEDから再現できる固有の都市名を持つ。海・沿岸・草原・丘陵の地形に合わせた語をカタカナで組み合わせる。
海セルは面をまたぐ隣接関係で最寄りの陸地都市を探し、「都市名・方角」という集合地点名を付ける。
方角はその都市の北方向を基準にする。すべて海の世界には独立した名前を付ける。
同名になる海域には追加の語を付けて区別する。征服者名は人物SEEDから再現する。

語彙の出典は Wiktionary。読みはゲーム向けの近似で、合成名は架空の地名。
