# 共通のPP頭＋動的な２国旗の２Ｄ試作

2026年11月10日。index.htmlをブラウザーで開く。サーバー・インストール不要。A国は青緑/赤の斜めストライプと猫、B国は紫/黄のチェッカーとハート。色・模様・紋章を操作可能。交換、初期化、共通素地の表示に対応。

## 原画と描画

- pp-head-neutral.png：imagegenでhead-study-v002を参照し生成した中立灰色のポリプロピレン頭。透明背景、顔はクリーム。ユーザー承認済みの既存原画を上書きしない新しい試作用素地。
- base-image.js：同じPNGをdata URLとして埋めたもの。file://でもCanvasの画素読取が制限されないよう使用。PNGを差し替える場合はこの埋込データも更新する。
- prototype.js：１枚の素地を両国で共有し、実行時Canvas合成。無彩色の表面をマスクし、色面にグレー由来の陰影と白い反射を適用。顔は色差と保護領域で除外。右下の紋章は独立レイヤー。
- WorldSetup.CountrySettings.csの斜めストライプ/チェッカー、CountryEmblemArt.csの猫/ハート判定をJavaScriptへ移植したサブセット。ゲームのC#生成器と直接接続はしていない。旗の縦横比はこの試作では3:2のみ。

## 制限

色域からの簡易マスク、曲面に見せる近似座標、32セルの紋章という検証用実装。ゲーム用には明示的な着色マスク・UV・反射画像と共有国旗データの接続が必要。全５模様/全紋章/全旗形への対応、９素材の着色変換、ゲーム画面/保存形式への組込みは未実施。今回は２国への動的な対応を確認する独立した試作。

## 検証

tests/RobotFlagPrototype/browser-check.cjsをNode 22とローカルChromeで実行。CDPはローカルTCPを使わず匿名パイプ。２国の表示差、交換による画素同値、顔と目の不変、初期化、色入力での再描画、共通素地同値、390pxで横あふれなしを検証。スクリーンショットで顔周囲と国旗の縁取りを修正して再確認。出力はartifacts/tmp/delete-after-2026-11-13/flag-head-prototype/。
