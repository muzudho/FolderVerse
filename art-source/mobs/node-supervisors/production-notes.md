# 節点の現場監督モブ女

2026-10-12 制作。14職種、built-in image_gen。全員無名、目を描かず顔上部を影で表現。白い無地の服をゲーム側で国色に染色。原画と最終プロンプト、SHA256を保存。

港は港湾監督、海は船長・艦長・海賊、極地面は極地探検隊長、山は工事監督。陸は人口規模による市長・町長・村長に加え、節点IDによる仮の施設役（修道院・病院・学校・保育所・店舗）。これら施設自体を新設する仕様は未実装。各節点の担当は固定。

節点設定はオート・緩やかオート・マニュアル。生成された節点は緩やかオート。マニュアルは設定を維持するが設定済みの生産・輸送・組立は通常どおり実行する。オートは不足する自国パーツを補う製造プラン、休業、空き枠、自動組立、同国の隣接節点への完成兵輸送を調整。進行中の製造を途中で変更しない。緩やかオートは工場の設定項目を順に調整し、円グラフは残留を含め最大5%ポイント/ターンで調整。

調練の現地に任せるは格納庫の現場順序で選出する。調練は各征服者直属で独立し、送り出しと自動組立の条件を守る。廃棄指定や未完成パーツの個別輸送計画はオートによる変更対象にしていない。

検証：NodeAutomation / NodeAutomationUi / MixedRobots / RobotCampaign / RobotTransport PASS、ビルド警告0・エラー0。UI描画で国色染色、額縁と上司、ポケット隣の調練とボタン列、自動設定選択を確認。デモは従来の紹介用操作に工場表示・実際の節点判断の呼び出しを追加。
