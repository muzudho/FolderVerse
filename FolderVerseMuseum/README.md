# FolderVerseMuseum

FolderVerse の旧機能を、単独で起動して見たり触ったりできる形で保存する図鑑です。ゲーム本体とは別の実行プロジェクトで、ゲームのセーブや設定を読み込みません。

## 起動

.NET 9 SDK が入った環境で、このディレクトリから実行します。

```powershell
dotnet tool restore
dotnet run --project .\FolderVerseMuseum.csproj
```

起動メニューから「方向のロボット」または「ロボットパーツ」を開きます。「戻る」か Esc でメニューに戻ります。

## 展示 01 · 旧「方向のロボット」

元の立体モデル、箸と碗、背面のゼンマイ、XYZ軸の色付きネジを保存しています。展示のソースは `Exhibits/OrientationRobot/` にあり、ゲーム側の描画コードから独立しています。

- 左ドラッグで自由回転
- X・Y・Zで各軸を30度回転。Shiftを押しながらで逆回転
- Rで初期姿勢に戻す
- Escでメニューに戻る

## 展示 02–04 · 魚・猿・犬の方向のロボット

`1` で旧型、`2` で魚、`3` で猿、`4` で犬に切り替えます。採用六面図（魚 v005・猿 v002・犬 v006）をもとに、丸い面、碗の内側と底、箸、前足や前びれを立体に起こしました。モデルのソースは `Exhibits/OrientationRobot/AnimalToyMesh.cs` です。

## ロボットパーツ · 安物、正規、高級

旧仕様の頭・胴・脚の輪郭と高級品の金縁を `Exhibits/RobotParts/` に保存しています。格納庫には展示用の色で三組を並べています。同じ段の別の枠へ左ドラッグすると、その部位だけを交換できます。「リセット」か R で初期配置に戻ります。

上のタブで、旧仕様の「頭/胴一体型」「胴/脚一体型」も３等級ずつ見比べられます。一体型は接合した状態で展示します。
